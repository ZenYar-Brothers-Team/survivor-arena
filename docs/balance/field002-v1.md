# FIELD-002 «Королевский тракт» — срез данных v1

Ревизия: `field002-v1`, 2026-09-26. **Approved 2026-09-26** пользователем с тремя корректировками
([DECISION-0063](../decisions/0063-field002-slice-v1.md)). Это production data среза, не проверенный в игре баланс.
Текущее исполнение — только [STATUS](../implementation/STATUS.md). Таблица — [field002-v1.json](field002-v1.json)
(генерируется из [baseline v1](field001-baseline-v1.md) и [enemies-v1](enemies-v1.md) по правилам ниже), проверка:
`python -X utf8 docs/balance/validate_field002_v1.py`.

## Корректировки пользователя

1. На FIELD-002 кроме шести врагов первой карты есть новые: **ENEMY-008 Конный разведчик** (с первой волны),
   **ENEMY-009 Щитоносец ополчения**, **ENEMY-006 Арбалетчик**; их контексты в Content Design начинаются с FIELD-002.
2. **Каждое следующее поле вводит новый тип врага уже в первой волне** — разница карт чувствуется с первой минуты.
3. **Путники на всех картах из общего пула** всех реализованных, роли в забеге не повторяются; фиксированная тройка
   FIELD-001 была тестовой. Пока реализованы три (по одному на роль), пул на обоих полях совпадает с ними.

## Волны: чем FIELD-002 сложнее первой карты

**С 2026-09-29 волны заменены ребалансом [field-rhythm-v2](field-rhythm-v2.md) ([DECISION-0095](../decisions/0095-field002-003-rhythm-v2.md)); раздел ниже исторический.**

Исходный 24-фазовый каркас сохранён для FIELD-002; после [DECISION-0076](../decisions/0076-wave-cap-and-field001-rhythm.md) он больше не обязан повторять обновлённый FIELD-001. Mid-boss остаётся в 7:30, босс — в 13:30; ритм
проверен. Поверх него:

|---|---|---|
| HP обычных врагов | ×1 | ×1.12 |
| Урон контакта и снарядов | ×1 | ×1.08 |
| Частота появления | базовая | +10%; в передышках ещё +25% |
| Технический лимит живых | единый 200 | единый 200; не балансный множитель |

первой карты, но и растёшь быстрее. Одновременно живых ordinary не больше единого технического предела 200.

## Поле

Тот же масштаб: 200×200, стены 1, старт (0,0), спавн радиус 12 и прежний opening spawn. Вместо 64 одиночных
препятствий — **24 группы камней и колонн (100 штук)** в ряд по 3–5: короткие стенки, между которыми идут
коридоры. 10 групп в кольце 10–34 units от старта, остальные дальше; свободный круг 8 units у старта. Камень
1.6×1.2, колонна 0.9×0.9, блокируют только игрока. Раскладка детерминирована (seed в JSON). **С 2026-09-27 ряды расставляются заново каждый забег, по одному в каждой из 5×5 ячеек — [DECISION-0068](../decisions/0068-per-run-obstacle-layouts.md); список в JSON только исторический.**

## Путники

Общий пул всех реализованных Путников; число 0–3 по общим вероятностям; типы выбираются по одному равновероятно
среди ещё не выбранных, чья роль в забеге не встречалась. Масштаб K при r=2 (×1.1 к HP/урону).

## Реализация и арт

- Новый код: атака босса в конце рывка и повторный залп ниже порога HP; выбор Путников без повторов ролей (сейчас
  совпадает с прежним, понадобится с IP-30).
- Арт тракта (дорога, камень, колонна, декор, миниатюра) и тела двух боссов — per-ID gates. До них поле рисуется
  утверждённым артом FIELD-001 (камни — пнями, колонны — короткими плетнями) с собственной геометрией и
  коллайдерами, боссы — явными placeholders.
