# Сеты SET-002…020 — данные v1

Ревизия: `sets-v1`, 2026-09-26. **Approved 2026-09-26** пользователем с двумя правками чисел
([DECISION-0061](../decisions/0061-sets-data-v1.md)).
Подготовлено по поручению пользователя 2026-09-26 («готовь дальше пакет сетов»). Это данные для
approval, не production JSON и не проверенный в игре баланс. Текущее исполнение — только
[STATUS](../implementation/STATUS.md).

Состав: 15 сетов без чисел (SET-002/003/005/007/008/009/011/012/013/014/015/016/018/019/020).
Пять сетов стартового этапа (SET-001/004/006/010/017) уже утверждены в
[baseline v1](field001-baseline-v1.md#пассивные-предметы-и-сеты) и здесь не меняются.
Рецепты, роли и механики — из [Content Design](../Content_design.md#sets) без изменений; здесь
заданы только пороги уровней и числа эффектов. Машиночитаемо — [sets-v1.json](sets-v1.json),
проверка: `python -X utf8 docs/balance/validate_sets_v1.py`.

## Общие правила (из CD и baseline v1)

- Бонус «+X%» складывается с бонусами уровня умения и пассивок по DECISION-0021; set-to-set цепочек нет.
- Баф компонентов действует только на перечисленные умения; set-атаки не считаются активацией умения,
  не ускоряются action speed и получают generic damage/knockback и size/range персонажа один раз.
- Бонус скорости снаряда не меняет дальность: lifetime уменьшается пропорционально (как «L3 speed без роста
  дальности» у камня). Дальность растёт только от бонуса range.
- «Не раньше уровня N» — минимальный уровень персонажа без Книг, если брать только компоненты и сам сет.

## Что потребует нового кода при реализации

Framework IP-11 уже умеет: StatBuff, SkillTransform (damage, action speed, KB, size, range), LevelHeal,
RewardProc, IndependentAttack по шаблону умения. SET-005/007/012 и set-атаки SET-015/016/018/019/020
собираются из существующих семейств (снаряд по направлению движения или в случайную сторону, взрыв при
истечении, slow в controls, область вокруг игрока).

Новые узкие адаптеры, без новых общих систем:

- скорость снаряда как канал SkillTransform (SET-002, SET-011);
- бонус отскоков диска и обратного пути бумеранга (SET-002, G-04);
- параметры цепи: цели, jump range, падение урона (SET-003);
- дополнительное пробивание (SET-009);
- подмена каждого N-го снаряда и взрыв при остановке (SET-008); бонус радиуса только взрывам (SET-008/015);
- веерный разряд от первой цели (SET-013);
- скорость вращения орбиты (SET-014).

## Доступ, арт и отложенное

- Unlock без изменений (DECISION-0050): SET-002/003/011/016/020 — после FIELD-001; SET-005/008/015 —
  FIELD-002; SET-009/012/013/018/019 — FIELD-003; SET-007/014 — FIELD-004. Проверка в игре — dev-кнопкой
  «Unlock all» до появления полей.
- Иконки всех 20 сетов утверждены. Для set-атак предлагается без нового растра: увеличенный спрайт
  соответствующего умения с set-оттенком (копьё, сфера, лёд, камень); SET-013 — процедурные дуги как у
  Цепной молнии; SET-015 — общий взрыв сферы. Спрайт сферы и копья есть; осколок льда и камень есть.
- Реализация IP-19 блокируется IP-17 только там, где сет использует умения без утверждённого world art
  (SET-007/008/014/015 — спираль, крест, мина, мусор); их визуальная проверка — после арта.
