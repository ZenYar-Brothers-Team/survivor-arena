## Механика

Алтарь — зона из основы DECISION-0134 с фиксированным местом. Два варианта:

1. **Цикл** (`ZoneLifetimeMode.Cycling`): алтарь стоит на месте всегда, но эффект включён только в окне `pulseVisibleSeconds` (с плавными краями `pulseFadeSeconds`) внутри длинного цикла `pulsePeriodSeconds`; у каждого своя случайная фаза. Не перемещается (в отличие от мерцающих зон). Любой непрерывный вид эффекта может быть алтарём: Haste, Regeneration, Protection, ArcanePower, Slow, Rift.
2. **Накопление** (`ZoneEffectKind.Charge`): пока игрок внутри включённого алтаря, заряд растёт от 0 до 1 за `chargeSecondsToMax`; вне алтаря стекает за `chargeDecaySeconds`. Бонус игроку = заряд × (`chargeSkillDamageBonus`, `chargeActionSpeedBonus`) и держится, пока заряд не опустеет; заряды нескольких алтарей складываются. Алтарь вне активного окна (DECISION-0134) забывает заряд, смерть игрока обнуляет все. Только постоянный или циклический.

Алтари и спящие зоны остаются слабо нарисованными, чтобы их можно было найти; заряжающийся алтарь становится ярче по мере заряда. Расстановка по общим правилам зон; для алтарных карт зазор `minGap` большой (тест 24), чтобы они были далеко друг от друга. Работают только в активном окне вокруг игрока (экран плюс по половине экрана).

## Тестовое поле «Тест 07»

`FIELD-DEV-ALTARS` по соглашению DECISION-0132: арена 160×160, земля FIELD-006, пять маленьких руинных иллюстраций как препятствия, спавн FIELD-001. Девять алтарей: по два «ветра» и «исцеления», один «защиты», один «силы» (цикл 90 с, окно 22–24 с) и три «накопления». Источник чисел `docs/balance/field-dev-altars-v1.json`; все числа placeholder.
