# DECISION-0134 — Основа зон с эффектами и тестовое поле «Тест 06»

Дата: 2026-10-01. Статус: Approved по прямому поручению пользователя («подготовить основу по коду для зон с эффектами, для магической карты… накидай шесть разных вариантов эффектов… арт отдельно»; зоны могут быть постоянными и мерцающими, мерцающая зона появляется в новой случайной точке).

Related: [DECISION-0132](0132-dev-blob-test-field.md) (соглашение о тестовых полях), [план разнообразия геометрии](../implementation/proposals/2026-10-01-field-geometry-variety.md) (FIELD-006 «зоны с эффектами» остаётся Proposed), [DECISION-0003](0003-player-only-field-collision.md).

## Граница

Это код и логика, не дизайн FIELD-006. Карточка FIELD-006, GDD и Content Design не меняются; числа эффектов — placeholder для проверки логики на тестовом поле, баланс и итоговый набор эффектов утверждаются отдельно. Арт зон отдельный (сейчас цветные диски).

## Модель

Зона — круг на земле. Шесть видов (`ZoneEffectKind`): Slow (замедляет игрока и, по параметру, врагов), Haste (ускоряет игрока), Regeneration (регенерация здоровья в секунду), ArcanePower (урон активных умений и скорость действий), Rift (урон в секунду игроку и/или врагам), Portal (парные зоны, вход переносит игрока рядом с партнёром, общая перезарядка).

Жизненный цикл (`ZoneLifetimeMode`): **Permanent** — зона всегда на месте; **Pulsing** — цикл `pulsePeriodSeconds`: плавно проявляется, стоит, плавно гаснет (`pulseVisibleSeconds` включает оба затухания, `pulseFadeSeconds`), потом невидима. У каждой зоны своя случайная фаза. Эффект работает, пока видимость не ниже 0.5. **В начале каждого нового цикла мерцающая зона перемещается в новую случайную точку** (пока невидима) по тем же правилам размещения; позиция детерминирована сидом, зоной и номером цикла. Портал только постоянный (пара не может переехать вместе).

Правила размещения (`ZonePlacementRules`, общие для первичной расстановки и перемещения): внутри арены с отступом `edgeMargin`, вне круга `startClearRadius`, зазор `minGap` между кругами, расстояние `obstacleClearance` до контура любого препятствия (портал дополнительно держит свободным свою точку выхода и пару не ближе `portalMinPairDistance`). Если набор не помещается, генерация повторяется с производным seed (до `maxRestarts`), иначе ошибка. Расстановка заново при каждом запуске (свежий seed; `referenceSeed` при `UseReferenceSeeds`).

## Исполнение

- `Game.Zones` (`Assets/Game/Zones`): определения с валидацией (значения чужих видов запрещены), генератор, `ZoneRuntime`. Без сцены: игрок и враги подключаются через `IZonePlayerTarget` / `IZoneEnemySource`.
- Эффекты игрока идут одним модификатором характеристик с ключом `zones` (`CharacterStats.SetModifier`): движение, урон умений, скорость действий, регенерация; модификатор снимается при выходе из зоны, смерти и `Dispose`.
- Враги: замедление через `EnemyRuntime.ApplyControl` (канал `zone`), урон копится и применяется порциями (≈5 раз в секунду, чтобы не было реакции на попадание каждый кадр); обход врагов только если активна зона, которая их затрагивает (`PerfGuard` «Zones.TickEnemies»).
- `ZoneRuntimeDriver` (Bootstrap) тикает зоны только пока забег `Running` (пауза не двигает время зон) и рисует placeholder-диски, прозрачность которых следует видимости.
- Конфигурация — блок `zoneLayout` презентации поля (эффекты и количества), источник `docs/balance/field-dev-zones-v1.json`, выпуск через генератор. ID эффектов `FIXTURE-ZONE-*`.

## Тестовое поле «Тест 06»

`FIELD-DEV-ZONES` по соглашению DECISION-0132: условие `dev`, ниже FIELD-001…010, арена 120×120, земля FIELD-006, пять маленьких руинных иллюстраций как препятствия, спавн FIELD-001. Зоны: по два Slow (постоянные), Haste (мерцающие), ArcanePower (мерцающие), Rift (мерцающие), один Regeneration и одна пара Portal (постоянные).

## Последствия и открытое

- Для дизайна FIELD-006 нужно решить: итоговый набор эффектов, числа, режим жизни каждого, нужны ли враги в Haste/Arcane, видимость зон на мини-карте и арт.
- Возможное расширение: влияние зон на снаряды, интерфейс (иконка статуса при нахождении в зоне), события для телеметрии.
