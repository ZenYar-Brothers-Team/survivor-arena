# DECISION-0066 — Данные боссов BOSS-003…010 и MIDBOSS-003…010 v1

Status: Proposed
Date: 2026-09-27
Related IP: IP-21 (IP-13/IP-15 framework), потребители IP-23/IP-24
Related content IDs: BOSS-003…010, MIDBOSS-003…010

## Context

Карточки 16 боссов утверждены, но в них нет урона снарядов, таймингов, скоростей, XP и момента появления (G-14),
поэтому IP-21 не может их реализовать. Пользователь 2026-09-27 поручил подготовить эти данные. Ориентир — прогрессия
FIELD-001, следующие поля сложнее первой ([enemies-v1](../balance/enemies-v1.md), DECISION-0062).

После первой редакции пользователь попросил сделать боссов разнообразнее: «луч, который на весь экран бьёт,
зоны, которые заполняются со временем, и он бомбит по ним… не сильно сложное, но поразнообразнее». Это меняет
утверждённые карточки (добавляет атаки) и вводит новые общие механики — отсюда редакция 2.

## Alternatives considered

- Ждать ручного задания каждого числа — блокирует IP-21, IP-23 и IP-24.
- Уложить карточки только в существующий framework — пришлось бы выбросить повторы залпов, серии рывков по фазе,
  атаки назад и взрывной веер, то есть исказить утверждённые карточки.
- Предложить данные по правилам из BOSS-001/002 и явно перечислить нужные расширения схемы (выбрано).

## Decision (proposed)

Утвердить [данные bosses-v1](../balance/bosses-v1.md) и [таблицу](../balance/bosses-v1.json) как production data:

- карточные числа без изменений; урон снарядов — доля контактного урона (прицельные 0.55, кольца 0.45,
  тяжёлые 0.70); XP 150 + 30·(N−1) и 60 + 15·(N−1); появление 7:30 и 13:30;
- телепорт DECISION-0059 у всех финальных боссов, удар 20 + 2·(N−2);
- **новые семейства атак боссов** F1 «Зона» (заполняющийся круг: на игроке, вокруг игрока, по следам, вокруг себя,
  безопасные круги; горящая земля), F2 «Луч» (на весь экран, предупреждение линией, несколько углов, поворот) и
  F3 «Призыв» (обычные враги поля вокруг игрока, лимит живых). Урон: зона 0.8, луч 0.9, горящая земля 0.3/s от
  контакта. У каждой атаки есть предупреждение, от неё можно увернуться на базовой скорости, и она не убивает
  с одного удара персонажа со 100 HP;
- каждому из 16 боссов добавить одну фирменную атаку из F1…F3 к атакам карточки;
- шесть расширений схемы E1…E6 для поведения из карточек.

## Consequences

- После approval G-14 для этих ID закрыт. Game Design получает общее правило F1…F3, карточки Content Design —
  фирменные атаки. IP-21 реализует F1…F3, E1…E6 и 16 encounters. Body/projectile art — отдельные per-ID gates,
  до них используются явные placeholders. Зоны и лучи рисуются процедурно.
- BOSS-001/002 и MIDBOSS-001/002 этим решением не меняются.
- В игру боссы попадут вместе с полями и волнами (IP-23/IP-24); время появления там может быть уточнено.
- Проверка таблицы: `python -X utf8 docs/balance/validate_bosses_v1.py` (PASS 2026-09-27).
