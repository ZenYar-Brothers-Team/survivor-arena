# DECISION-0122 — от 1 до 5 Путников на карту и равномерная перемешка типов

Status: Approved
Date: 2026-09-30
Related IP: IP-29, IP-30
Related content IDs: FIELD-001-TRAVELERS, FIELD-002-TRAVELERS, FIELD-003-TRAVELERS
Изменяет число Путников на забег из [DECISION-0035](0035-traveler-encounter-rules.md) / [DECISION-0063](0063-field002-slice-v1.md) («0–3 без повторов ролей»).

## Decision

1. Число Путников на карту — **от 1 до 5** по дискретному распределению. Расписание получает `minCount`; `countProbabilities[i]` — вероятность
   `minCount + i` (любая длина ≥ 1, сумма 1). Production для FIELD-001…003: `minCount` 1, вероятности `[0.10, 0.25, 0.30, 0.25, 0.10]` (среднее 3;
   значения выбраны исполнителем, правятся данными в [travelers-v2](../balance/travelers-v2.json)). Fixtures остаются 0…3.
2. Тип Путника — его роль (боевой, небоевой, защитник). Выбор идёт **группами по одному Путнику на тип** в случайном порядке типов:
   полная группа содержит все типы по разу, последняя неполная — различные типы. 5 = 3 + 2, 8 = 3 + 3 + 2, 1 = один случайный.
   Алгоритм не зависит от числа: работает для любого `count`, включая 8–10.
3. Внутри типа Путники берутся из перемешанного «мешка»: конкретный Путник не повторяется, пока не показаны все Путники его типа; затем мешок
   пополняется заново (первый из нового мешка не совпадает с только что показанным). Без `roleOf` каждый Путник — свой тип.
4. Время появления каждого выбирается независимо и равномерно по окну [0, T − 120]; масштабирование K, награда Книга и пул из десяти не меняются.
   Правило «роли не повторяются в забеге» (DECISION-0063) заменено пунктом 2: роли повторяются между группами.

## Consequences

- `TravelerScheduleData.minCount`, `TravelerScheduleDefinition.MinCount/MaxCount/Draw`, генератор расписаний, `FixtureTravelers.json`, тесты расписаний и производства.
- Одновременно на карте может быть до 5 живых Путников (лимит пула врагов не затронут, Путники вне cap); UI списка и стрелок создаются по числу живых.
- Не пересчитаны: performance-замеры «3 Travelers», PlayMode-smoke, читаемость 5 Путников на экране.
- Game Design (пул Путников) и Content Design (общий раздел Путников, пул FIELD) обновлены 2026-09-30 по прямому поручению пользователя.

## Approval

Утверждено пользователем 2026-09-30 в чате: «от одного до пяти на каждой карте», алгоритм максимально равномерной перемешки по группам из трёх, действует при любом числе.
