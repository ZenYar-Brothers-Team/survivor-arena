# DECISION-0073 — Плейтест 2026-09-27: список сетов, прыжок босса, пропсы полей, ослабление умений

Status: Approved (прямое поручение пользователя 2026-09-27; конкретные коэффициенты выравнивания выбраны исполнителем по числовой модели, пересмотр — обычной правкой данных)
Date: 2026-09-27
Related IP: IP-11/IP-19 (sets UI), IP-21 (bosses), IP-23 (fields), IP-17/IP-32 (skills, balance)
Related content IDs: SKILL-001…016 (кроме не реализованных), BOSS-001…010, FIELD-001…003

## Context

Отзыв пользователя после плейтеста:

1. В списке сетов и их частей во время игры видны сеты, не открытые мета-прогрессией
   (нарушение уже утверждённого правила UI/UX «Стартовая прогрессия»: показывать только meta-открытые сеты).
2. Сеты, которые уже не собрать из-за слотов, должны уходить вниз, в раздел упущенных.
3. Дистанцию, после которой босс делает прыжок (телепорт DECISION-0059), увеличить на 25%.
4. Для всех карт есть новые объекты; их нужно встроить в генерацию, чтобы появлялись все.
5. Первое поле слишком простое: выровнять умения по силе и ослабить их примерно на 30%.

## Decision

### 1–2. Сеты в забеге

- Pause Build, draft-подсказки и development-список рецептов показывают только сеты из draft pool
  текущего забега (meta-открытые либо добавленные development-командой).
- Сет **упущен**, если он не получен и его рецепт больше нельзя выполнить: отсутствующих компонентов
  одного типа больше, чем свободных слотов этого типа (6 active / 6 passive), либо отсутствующий компонент
  больше не может быть предложен (banish, нет в pool, нулевой draft weight персонажа). Уже взятый компонент
  ниже порога остаётся достижимым через улучшения.
- Упущенные сеты идут последними под заголовком «MISSED SETS» (Pause Build — отдельный раздел со всеми
  упущенными, development-список — после остальных). Правило видимости не меняет eligibility сетов в draft.

### 3. Прыжок босса

`farDistance` телепорта у всех финальных боссов (BOSS-001…010): 5 → **6.25 units** (+25%).
Остальные параметры DECISION-0059 (2 s, landing 1.5, radius 3.5, telegraph 0.6) не меняются.
Боссы, держащие дистанцию, по-прежнему стоят внутри порога (валидатор bosses-v1 PASS).

### 4. Пропсы полей в генерации

Играбельны FIELD-001…003; их одобренные пропсы (пакет `field-obstacles-2026-09-27`) уже были привязаны,
но FIELD-002/003 — к фиксированным позициям одного-двух паттернов, поэтому встречались редко или не
встречались. Теперь кусок паттерна может задавать `visualIds` — список вариантов; генератор выбирает вариант
для каждой поставленной копии отдельным seeded-потоком (геометрия и collider для сида не меняются) и
гарантирует, что каждый вариант появляется в забеге хотя бы раз (заменяет визуал препятствия, чей текущий
визуал повторяется).

- FIELD-002: все камни рядов — boulder / milestone / bench; концы рядов дополнительно wagon / barricade
  (крупные пропсы только на концах, чтобы не перекрывать соседей).
- FIELD-003: стены — wall / ruined arch; завалы — rubble / broken urns / fallen capstone / collapsed well.
- FIELD-001 не менялся: hay bales и handcart уже отдельные паттерны с весом 10 (~29 штук на поле).
- Пропсы FIELD-004…010 не подключаются: у этих полей ещё нет production field data (граница прежнего art evidence).

### 5. Умения: выравнивание и ослабление

Числовая модель (`crowd DPS` при плотности 0.12 и 0.25 врага/unit², средний по L1–L6; упрощённая
геометрия попаданий, knockback/slow не учитывается как урон) показала выбросы: SKILL-010 и SKILL-015
(многократные AoE-удары) в 2–3 раза выше медианы; слабее всех из чистого урона — SKILL-005, SKILL-013, SKILL-002.
Урон каждого умения умножен на один коэффициент на всех уровнях (относительные тексты уровней карточек
остаются верными; меняется база):

| Умение | Коэф. | База было → стало |
|---|---:|---|
| SKILL-001 Бросок камня | 0.70 | 20 → 14 |
| SKILL-002 Веер игл | 0.84 | 9 → 7.56 |
| SKILL-003 Орбитальные клинки | 0.70 | 14 → 9.8 |
| SKILL-004 Импульсная волна | 0.80 | 8 → 6.4 (контроль, урон вторичен) |
| SKILL-005 Ветряное копьё | 0.95 | 34 → 32.3 |
| SKILL-006 Бумеранг | 0.70 | 16 → 11.2 (недавний отзыв DECISION-0069 сохраняется) |
| SKILL-007 Цепная молния | 0.70 | 22 → 15.4 |
| SKILL-010 Небесный удар | 0.45 | 55 → 24.75 (L1 всё ещё убивает ENEMY-002, 24 HP) |
| SKILL-013 Ледяные осколки | 0.90 | 8 → 7.2 |
| SKILL-014 Взрывные сферы | 0.70 | 18 + 26 → 12.6 + 18.2 |
| SKILL-008 Рикошетный диск | 0.70 | 18 → 12.6 |
| SKILL-009 Магматическая мина | 0.60 | 40 → 24 |
| SKILL-011 Спираль осколков | 0.70 | 12 → 8.4 |
| SKILL-012 Пульсирующий луч | 0.75 | 10 → 7.5 за tick |
| SKILL-015 Крест клинков | 0.45 | 30 → 13.5 |

Итог модели: суммарный урон стартовых 10 умений −35% (медианное умение −30%, выбросы сильнее); разброс
средних (max/min) 8.7× → 5.6×, коэффициент вариации 0.78 → 0.51. Cooldown, радиусы, knockback, slow, сеты,
пассивки и враги не менялись; ослабление глобальное, поэтому поля 002/003 тоже становятся сложнее.
Сет-атаки не масштабировались и относительно усилились — проверяется в прогоне.
