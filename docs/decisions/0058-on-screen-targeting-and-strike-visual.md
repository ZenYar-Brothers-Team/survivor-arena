# DECISION-0058 — Цели атак игрока только на экране; визуал удара с небес

Status: Approved (поручение пользователя 2026-09-25; числа визуала выбраны исполнителем, пересмотр — обычной правкой данных)
Date: 2026-09-25
Related IP: IP-08, IP-17, IP-12A
Related content IDs: SKILL-001, SKILL-002, SKILL-006, SKILL-007, SKILL-010, SKILL-013, SET-017

## Context

Пользователь 2026-09-25:

- «Выбор противника или точки для удара/атаки игрока не должен выходить за пределы экрана. Если на
  экране никого нет, то можно оставить предыдущее направление или случайную точку. Это должно быть
  правилом для всех атак.»
- Удар с небес: «столб света шёл чуть раньше, чем круг», «круг сожми немного. Персонажи же не вид
  сверху имеют».

До решения цели выбирались по всему полю в пределах targeting radius (Content Design SKILL-010
прямо говорил «не зависит от границ экрана»); без цели ближайшего/случайного врага атака не
срабатывала и ждала.

## Decision

### Правило экрана

Экран — прямоугольник ортографической gameplay-камеры, центрированной на персонаже (DECISION-0001),
при текущем aspect ratio. Враг считается видимым, если его позиция внутри прямоугольника.

| Место выбора | До | После |
|---|---|---|
| Ближайший враг (SKILL-001/002/006/007/013) | ближайший на поле в radius | ближайший видимый в radius; нет — выстрел в предыдущем направлении |
| Случайный враг (SKILL-010, SET-017) | случайный на поле в radius | случайный видимый в radius; нет — случайная точка экрана в radius |
| Следующие удары SKILL-010 L4/L6 | новый враг или пропуск | новый видимый враг, иначе случайная точка экрана в radius |
| Разные цели снарядов (SKILL-001 L3/L6) | лишние снаряды не вылетали | лишний снаряд летит по направлению раскладки |
| Рикошет (SKILL-001 L4) | ближайший на поле | ближайший видимый, иначе рикошета нет |
| Прыжки цепи (SKILL-007) | ближайший на поле | ближайший видимый, иначе цепь заканчивается |

«Предыдущее направление» — последнее направление атаки этого умения, в начале забега — его
начальное направление из данных. Случайная точка берётся из seeded RNG умения. Radius умения
остаётся balance-data и действует вместе с экраном. Проверка попаданий (луч, область, мина,
снаряд в полёте, взрыв) экраном не ограничивается: это не выбор цели. Атаки врагов, боссов и путников
правило не затрагивает. Атаки сетов идут через тот же выбор цели и подчиняются правилу так же. Self- и movement-direction умения цель не выбирают и не меняются.

### Удар с небес (SKILL-010, SET-017)

`SkillWorldEffects.json`: `pillarLeadSeconds` 0.15 — столб света появляется за 0.15 s до вспышки и
гаснет вместе с ней.

Круг на земле при камере 3/4 выглядит эллипсом, поэтому по уточнению пользователя («сожми область
урона, другие параметры атаки не меняй») сжата и сама область урона. Strike получил параметр
`verticalScale` 0.7 (baseline: `SKILL-010.shared.verticalScale`, `SET-017.effects[0].verticalScale`;
по умолчанию 1 — круг). Горизонтальная полуось — прежний radius, вертикальная — radius × 0.7:
SKILL-010 L1 1.6 × 1.12 units, SET-017 2.2 × 1.54 units. Враг задет, если ближайшая к центру точка его
коллайдера лежит в эллипсе. Telegraph и вспышка рисуются этим же эллипсом из данных умения, а не из
презентационного профиля. Damage, radius, telegraph, knockback, cooldown, targeting не менялись.

## Consequences

Код: `TargetViewportRect`, `ITargetViewport`/`CameraTargetViewport`, `ViewportCombatTargetQuery`,
`IActiveSkillAimArea`; `SceneEnemyTargetProvider`, `ActiveSkillInstance` (fallback),
`SceneActiveSkillEffectExecutor` (отдельный selection query для выбора, прежний query для попаданий),
ricochet через launcher, `SetEffectHost`, composition root с `Camera.main`. Без viewport (EditMode
fixtures) поведение прежнее. Визуал: `SkillWorldEffectProfile.PillarLeadSeconds/GroundScaleY`,
presenter держит столб до вспышки; `StrikeEffect.VerticalScale` и `EnemyDamageArea.Apply(verticalScale)` для эллипса.
Документы: Game Design («Управление, бой и выживание»), Content Design (Active Skills, SKILL-010, SET-017).
Тесты: `ScreenTargetSelectionTests`, `ProductionSkillPatternTests.StrikePillar_…`, `EnemyDamageAreaCirclesTests.Apply_FlattenedArea_…`, `verticalScale` в production catalog tests.
Ощущение (частота «пустых» выстрелов, вид эллипса) проверяется прогоном пользователя.
