# DECISION-0067 — Данные поля FIELD-003 v1

Status: Proposed
Date: 2026-09-27
Related IP: IP-23 (поле), IP-24 (волны), IP-20 (ENEMY-010), IP-30 (Путники)
Related content IDs: FIELD-003, ENEMY-010, BOSS-003, MIDBOSS-003

## Context

Боссы FIELD-003 реализованы (DECISION-0066), но поля, его геометрии и волн нет (IP-23/IP-24). Пользователь
2026-09-27 поручил начать с FIELD-003. Ориентир — прогрессия FIELD-001, каждое поле сложнее предыдущего
(DECISION-0062/0063).

Правило DECISION-0063 «новый тип врага в первой волне» не выполнимо по карточкам: все враги с контекстом FIELD-003
уже есть на FIELD-002. Пользователь выбрал ENEMY-010 Гвардейского стрелка (альтернативы: Охотник на чудовищ, оба,
исключение для поля).

## Decision (proposed)

Утвердить [данные field003-v1](../balance/field003-v1.md) и [таблицу](../balance/field003-v1.json) как production data:

- карточка ENEMY-010: контексты FIELD-004…008 → FIELD-003…008;
- волны на каркасе FIELD-001:
  - HP ×1.24, урон ×1.16, частота +20%, всплески ×1.3 (первые два ×1.5 сверх этого);
  - две минуты становятся фазами давления;
  - стрелки — 28% появлений;
  - лимит живых не выше 220, чтобы лимит со всплеском не превышал стресс-цель 250;
- поле: 16 кластеров руин форта (56 обломков стен, 51 завал) с проходами не уже 4 units, свободный круг 10 units у
  старта, вода визуальная;
- боссы BOSS-003/MIDBOSS-003 по bosses-v1; общий пул Путников, K при r=3.

## Consequences

- После approval IP-23/IP-24 реализуют FIELD-003 генератором, по образцу FIELD-002. Content Design: контекст
  ENEMY-010 и enemy pool FIELD-003.
- Арт поля — per-ID gates; до них прежний утверждённый арт (плетень, валун).
- Проверка таблицы: `python -X utf8 docs/balance/validate_field003_v1.py` (PASS 2026-09-27).
