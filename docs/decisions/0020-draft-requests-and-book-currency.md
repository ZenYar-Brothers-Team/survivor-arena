# DECISION-0020 — Очередь драфтов и валюта за пустую Книгу

Status: Approved

Date: 2026-09-21

Related IP: IP-06, IP-07, IP-10, IP-10A, IP-11, IP-25, IP-28, IP-31

## Context / approval

В ответ на предложение short/empty/Book/FIFO правил пользователь добавил дозаполнение сетами (DECISION-0019) и валютную компенсацию, затем уточнил: «только за пустую книгу в момент ее подбора». Это закрывает G-01/G-03 для framework IP-07. Production ID Книги, сумма компенсации и pickup параметры остаются отдельными content/balance данными.

## Decision

- Общий драфт имеет три визуальные позиции. После обычных предложений и дозаполнения сетами 1–2 карточки отображаются вместе с неактивными позициями «Нет доступного варианта». Повторов нет. Обычный пустой level-up завершается без выбора и без валюты, сохраняя заработанные XP/level.
- Книга использует обычный eligible pool active/passive/set и общий остаток reroll/banish забега. Она не даёт XP/level, не заменяет следующий level-up и не восстанавливает counters/banishes.
- При принятии подбора Книги проверяется наличие доступных вариантов после всех eligibility filters, с учётом гарантированного дозаполнения сетами. Если вариантов нет, Книга расходуется, разовая валютная награда немедленно отражается в состоянии текущего забега и событии награды. Следующего level-up ждать не нужно; пустое окно не открывается.
- Единица авторинга компенсации — целое положительное количество мета-валюты в JSON. Fixture значение не утверждает production баланс. IP-07 является producer начисления; IP-25 сохраняет этот уже начисленный результат в профиль идемпотентно, не создавая вторую награду. Политика незавершённого забега по-прежнему принадлежит G-15/IP-25.
- Источник награды определяется при принятии подбора. Непустая в этот момент Книга ставит один запрос в общую очередь. Если ранее принятые выборы или banish затем исчерпают его pool, запрос завершается без нового начисления: это не второй подбор пустой Книги. Аналогично reroll/banish не являются новым основанием валютной награды.
- Одна FIFO-очередь хранит requests с ID, origin LevelUp/Book, earned level либо source pickup ID/run ID. Несколько уровней одного XP award добавляются подряд по возрастанию до внешних callbacks. Pool очередного выбора вычисляется при его открытии. Открытый выбор не вытесняется.
- При успешном принятии Book request Книга расходуется один раз. Повтор того же pickup life ID в текущем забеге не создаёт request или валюту. World pickup обязан быть принят в Running; API для уже принятых rewards может завершить постановку в очередь при draft pause. После terminal новые requests запрещены.
- Draft pause удерживается на всю очередь; снятие последней draft pause не снимает Manual или другие причины. Каждый intent содержит revision открытых предложений: устаревший/повторный выбор не применяется к следующему request или reroll.
- Victory/defeat/stop/retry отменяет текущий и ожидающие requests без автоматического выбора и без возврата Книги. Применённые selections, заработанные XP/level и начисленная валютная сумма остаются в immutable outcome. Shutdown отписывает producers, закрывает старые sessions и снимает только свою pause reason.

## Verification

Проверить 0/1/2/3 предложения после set backfill; FIFO нескольких уровней и Books; short UI, origin/next request, pure current→new preview; stale/double intent; pause ownership и terminal callbacks. Для Книги проверить immediate currency, отсутствие XP/level, dedup pickup, старый run, ordinary empty без валюты, queued nonempty→empty и banish→empty без повторной компенсации. Amount хранится в JSON; producer totals доступны без IP-31 recorder.
