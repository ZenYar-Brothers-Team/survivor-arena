# DECISION-0118 — закрытые карты, масштаб интерфейса, мышь в драфте

Дата: 2026-09-30. Решения пользователя в диалоге; проверки и статус — в
[STATUS](../implementation/STATUS.md). Изменяет [DECISION-0092](0092-unlocks-collection-ui.md)
в части карт и дополняет [DECISION-0038](0038-settings-and-field-difficulty.md).

## Решение

1. **Закрытая карта** (Meta → «Открытия» и Field Select) показывает сильно размытый
   thumbnail и «?» вместо названия. Открытая карта показывает изображение и название.
   Правило DECISION-0092 «карты сохраняют названия и изображения» отменяется.
2. **Field Select показывает все десять карт.** Карты без игрового определения
   (FIELD-004…010) выводятся закрытыми, невыбираемыми заглушками с размытым thumbnail,
   «?» и условием открытия.
   Это не делает их играбельными: доступность запуска и gameplay-каталог не меняются.
3. **Сложность (значки мечей) с карточек Field Select убирается**: значение остаётся в данных поля,
   но игроку не показывается. Отменяет уточнение DECISION-0087 про пять мечей.
4. **Field Select — два ряда по пять карточек.** Высота картинки следует ширине карточки
   (пропорции фонов 512×341) и уступает место, только чтобы оба ряда остались на экране;
   сетка центрируется по вертикали.
5. **Настройка «Масштаб интерфейса»** (Settings → Изображение): Авто / 100% / 125% / 150%
   (200% отвергнут пользователем). По умолчанию Авто: наибольший шаг, помещающийся по высоте
   экрана (1080p → 100%, 1440p → 125%, 2160p → 150%). Применяется сразу ко всем UI-панелям;
   сохраняется в settings schema v3 (v1/v2 читаются, масштаб = Авто).
6. **Карточки драфта выбираются только мышью.** Клавиатура (стрелки, WASD, Tab, Enter, Space)
   не меняет просмотр и не подтверждает выбор: карточки не получают клавиатурный фокус.
   Причина — нестабильное поведение: навигация фокуса то переключала просмотр, то нет.
   Отдельная настройка для клавиатурного выбора не вводится. Отменяет keyboard activation
   из DECISION-0112.

## Границы

Раскладка остаётся рассчитанной на 1920×1080 логических пикселей; отдельная раскладка для
разрешений выше 1080p не создаётся. Экономика, условия и профиль не меняются.
