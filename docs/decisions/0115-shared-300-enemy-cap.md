# DECISION-0115 — Общий технический предел 300 обычных врагов

Status: Approved
Date: 2026-09-30
Related IP: IP-14, IP-24, IP-27, IP-32
Supersedes: значение `maxAliveEnemies=200` в DECISION-0076 и сохранение этого значения в DECISION-0105. Остальные правила этих решений действуют.

## Основание

Пользователь поручил поднять одновременный предел до 300 и уточнил, что лимит должен быть один для всех полей.

## Решение

- Все production timelines FIELD-001/002/003 используют `maxAliveEnemies=300`. Новые поля должны наследовать тот же общий предел, пока он не изменён отдельным решением. Генератор проверяет равенство значений исходных пакетов.
- Лимит относится к обычным врагам спавнера, в том числе к continuous и burst. Боссы, мини-боссы и Путники остаются вне regular capacity по DECISION-0105.
- При полном лимите продолжает действовать бесшумная замена самого дальнего обычного врага. Cadence, составы волн, здоровье и награды этим решением не меняются.
- Увеличенный потолок требует проверки спавна и пула на 300 объектах и отдельной оценки кадрового времени в плотном игровом эпизоде. Успешный тест пула сам по себе не доказывает стабильный FPS.

## Approval

Пользователь, 2026-09-30: «Давай ограничение по числу одновременно доступных противников на поле сделаем 300»; «Пусть лимит будет один на все поля».
