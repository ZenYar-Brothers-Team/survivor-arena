# DECISION-0003 — Геометрия поля ограничивает только игрока

Status: Approved

Date: 2026-09-14

Related IP: IP-02, IP-04, IP-13, IP-16, IP-23

Related content IDs: FIELD-001…010 как Draft compatibility targets

## Context

Внешняя граница прототипа физически блокировала врагов, которые могли появиться снаружи и затем бесконечно двигаться в стену. Будущие поля также содержат внутренние стены, коридоры и другие препятствия, но IP-13 не предусматривает обязательную навигацию вокруг них.

## Decision

По умолчанию граница поля и обычные препятствия окружения ограничивают только перемещение персонажа игрока. Враги, снаряды, эффекты умений, опыт и остальные игровые сущности проходят через такую геометрию. Исключение возможно только для отдельной явно описанной механики контента.

## Consequences

- Враги не требуют pathfinding только ради базовой геометрии поля и не застревают с другой стороны стен.
- Граница и препятствия используют player-only collision mask.
- Геометрия полей формирует маршрут и позиционирование игрока, но не маршруты толпы.
- IP-02, IP-04, IP-13, IP-16 и IP-23 фиксируют одинаковую collision semantics.
- Scene/physics tests проверяют блокировку игрока и свободный проход остальных сущностей.

## Approval

Пользователь явно утвердил правило 2026-09-14 сообщениями о проходимой границе и последующим согласием применить ту же корректировку к дальнейшей разработке.
