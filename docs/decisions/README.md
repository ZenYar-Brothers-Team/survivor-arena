# Design and implementation decisions

Этот каталог хранит решения, которые нельзя корректно выразить простой сменой статуса IP-модуля: утверждённые отклонения от первоначального scope, новые системные правила, междокументные конфликты и миграции стабильных ID.

Обычные технические детали и локальный рефакторинг сюда не записываются. Пока решение не принято, оно не изменяет Game Design или Content Design автоматически.

## Когда создавать запись

- реализация требует нового системного правила;
- код вынужденно отклоняется от acceptance criteria или контракта данных;
- меняется ответственность между Game Design, Content Design и IP;
- меняется или мигрирует стабильный content ID;
- пользователь явно утверждает спорное решение, влияющее на несколько слоёв.

## Именование

`NNNN-short-title.md`, где номер не переиспользуется. Для новой записи скопировать [`_template.md`](_template.md).

После принятия решения необходимо обновить все затронутые канонические документы и добавить ссылку на запись в `docs/implementation/STATUS.md` у соответствующего IP.
