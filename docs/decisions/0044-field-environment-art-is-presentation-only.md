# DECISION-0044 — Арт окружения не меняет геометрию поля

Status: Approved
Date: 2026-09-22
Related IP: IP-12A, IP-16, IP-23

## Основание

Для первой проверки FIELD-001 нужен небольшой визуальный набор поверх уже работающей fixture-арены. Замена сцены или создание новой production geometry одновременно с подбором палитры смешало бы визуальную оценку с изменением столкновений и доступности пространства.

## Решение

Первый FIELD-001 kit подключается отдельным visual-only runtime поверх существующей арены. Ground использует один tiled renderer. Плетень обозначает четыре уже существующие границы. Пень накрывает существующий `Obstacle_Fixture`; его collider и player-only collision contract не меняются. Кусты и трава являются редким декором без collider и расставляются детерминированно по seed с небольшими вариациями позиции, масштаба, отражения и поворота.

Presentation config хранит typed references на роли `Tile`/`Prop`, размеры и параметры расстановки. При завершении забега runtime уничтожает созданный visual root и восстанавливает скрытый placeholder. Этот пакет не объявляет production geometry FIELD-001 готовой и не закрывает IP-23.

## Следствия

- визуальный review можно повторять без изменения gameplay geometry;
- декор не создаёт ложных physics costs и не участвует в pathing;
- новая production geometry позже заменит fixture binding, сохранив сами approved sprites при необходимости;
- до пользовательского gameplay-scale review пять изображений остаются в стадии Review.
