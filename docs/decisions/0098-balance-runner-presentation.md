# DECISION-0098 — Показ автоматических забегов по запросу

Status: Approved (user direction)
Date: 2026-09-29
Related IP: IP-34
Related content IDs: —

## Context

При проверке standalone-сборки автоматический забег открыл окно игры и включил
звук. Для массовых измерений это мешает пользователю работать параллельно.
При этом пользователь хочет сохранить возможность посмотреть конкретный запуск.

## Options considered

- Всегда показывать окно: удобно для просмотра, мешает фоновым сериям.
- Никогда не показывать окно: удобно для серий, лишает возможности наблюдать
  конкретный забег.
- Скрытый запуск по умолчанию с явным показом одного эксперимента.

## Chosen option and why

По умолчанию локальный runner запускает отдельный Unity player без видимого окна
через `-batchmode` и выключает звук только в этом процессе до загрузки сцены.
Параметр `--visual` включает окно для конкретного эксперимента; звук остаётся
выключенным, пока дополнительно не указан `--audio`. `--audio` без `--visual`
недопустим. Выбранный режим сохраняется в manifest/experiment metadata.

Это тот же production gameplay player loop, сцена и разрешённые скорости 1/2/3/5.
Режим не обещает ускорения на скорости железа, deterministic replay, отдельного
headless/server симулятора или визуальной оценки ботом.

Так массовые серии не отвлекают пользователя, а просмотр остаётся доступным
без изменения игровой логики или отдельной сборки.

## Consequences

Пилоты и проверки без отдельного запроса не открывают игру и не воспроизводят
звук. Для визуального просмотра нужен явный запуск отдельного эксперимента;
пользовательские настройки обычной игры не меняются.

## Revisit triggers

Если появится запрос на покадровый визуальный review, запись видео либо
распределённые workers, потребуется отдельное решение о ресурсах и поведении
этого режима; текущий opt-in не обещает эти возможности.

## Approval

Пользователь попросил не запускать игру визуально и со звуком по умолчанию,
затем уточнил: «давай заложим возможность показывать визуально. Я могу для
конкретного запуска попросить сделать визуальный показ».
