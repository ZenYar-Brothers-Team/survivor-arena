# DECISION-0078 — Общая ранняя прогрессия активных умений

Status: Approved
Date: 2026-09-27
Related IP: IP-08, IP-17, IP-27, IP-32
Related content IDs: SKILL-001…016
Extends: DECISION-0077 для SKILL-002/013; пользовательские уточнения для SKILL-003/010
Supersedes: ранние L1–L3 primary-параметры из DECISION-0053/0060; L4–L6 и финальные значения не меняет. SKILL-010 radius позднее пересмотрен DECISION-0079.

## Основание

По прямому отзыву пользователя стартовые версии активных умений должны быть
заметно проще и слабее, а первые два улучшения — давать ощутимый рост и к L3
возвращать прежнее состояние L3. Ранее этот принцип был применён к вееру игл и
ледяным осколкам, затем отдельно уточнён для Небесного удара и Орбитальных
клинков. Пользователь распространил его на все active skills. Для Броска камня
отдельно задано более мягкое ослабление L1 в 1.5 раза, потому что он уже слабее.

## Общий принцип

- L1 сохраняет узнаваемую механику, но главный параметр покрытия/дальности/
  длительности/числа целей уменьшен примерно вдвое.
- L2 возвращает прежнюю базовую силу и сохраняет прочие положенные L2 bonuses.
- L3 догоняет прежнее состояние L3, включая качественные прибавки этого уровня.
- L4–L6, cooldown, targeting, controls и финальная сила не меняются.
- Камень использует `14 / 1.5 = 9.33` damage на L1, а не половинные 7.
- Chain и ricochet стартуют минимум с двух целей/попаданий, иначе их основная
  механика не была бы представлена на L1.

## Следствия

Выбор нового умения даёт рабочую, но компактную версию механики; L2 и L3 имеют
более заметный визуальный и игровой эффект. Все прежние late-build свойства,
set recipes, L4 qualitative transitions и L6 maxima сохранены. Требуются точные
all-level catalog tests, регенерация production JSON и ручная оценка того, не
стали ли отдельные L1 слишком узкими или короткими на реальной скорости.
