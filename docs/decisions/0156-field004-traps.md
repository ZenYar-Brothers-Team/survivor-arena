# DECISION-0156 — Ловушки лагеря: турели-проджектайлы, бочки и ярость

Status: Approved (набор и правила пользователя, чат 2026-10-03) / Proposed (стартовые числовые значения для плейтеста)  
Date: 2026-10-03  
Related IP: IP-23 (FIELD-004), IP-12A (арт — отдельным проходом)  
Related content IDs: FIELD-004 (ловушки и их карта только здесь); TRAP-001…TRAP-013, TRAP-BARREL (`docs/balance/field004-traps-v1.json`)

## Context

Пользователь запросил для карты FIELD-004 «Рыцарский лагерь» набор ловушек. Карточка поля и `Game_design.md` ловушек не описывают
(эти документы без явного одобрения не меняются), поэтому правила фиксируются здесь. Механика не конфликтует с зонами FIELD-006,
алтарями FIELD-007 и катастрофами FIELD-010: это декор с лёгким эффектом, а не новый тип поля.

## Decision

**Общие правила.**
- Ловушки расставляются случайно на каждый забег (seed из `FreshRunSeed`, в тестах — `referenceSeed`), в отдельном бюджете: число
  обычных препятствий поля они не уменьшают. Сейчас готовятся только для FIELD-004; остальные поля ловушек не имеют.
- Турели стреляют только проджектайлами и бьют только игрока. Корпус турели и бочки — player-only физическое тело (как основание
  алтаря): игрока блокирует, врагов, навыки и снаряды не блокирует. Турели неуязвимы.
- Радиус активации, ярости и отсечения снарядов — один: одна ширина экрана от игрока. Турель вне радиуса не стреляет.
- Снаряд заканчивается при попадании в игрока, препятствие или край арены, на собственной дальности, при возврате к турели
  (бумеранг) и при выходе за радиус от игрока. Тела турелей и бочек снаряды не блокируют.

**Ярость.** Пока турель активна, её скорострельность растёт линейно от ×1 до ×3 за 60 секунд непрерывной активности.
При выходе игрока из радиуса ярость сбрасывается мгновенно до ×1, незавершённая подготовка залпа отменяется, ещё не вылетевшие
выстрелы серии отменяются; текущая перезарядка сохраняется. Ускоряется только пауза между залпами; телеграфия и задержки внутри
серии остаются прежними. Потолок живых снарядов на сцену — параметр данных; залп, не помещающийся в потолок, пропускается целиком.

**Турели (13).** Данные описывают паттерн списком групп выстрелов (угол, боковое смещение, задержка), режимом направления
(`fixed` — поворот размещения, `aim` — на игрока в момент начала телеграфии, затем фиксируется) и изменением направления от залпа к
залпу. Телеграфия — подсветка головки, для линейных ловушек — линия прицела.

| ID | Название | Паттерн |
|---|---|---|
| TRAP-001 | Копейный ряд | стоит под углом, 4 параллельных копья по ширине |
| TRAP-002 | Крест | 4 копья по осям |
| TRAP-003 | Диагональный крест | как Крест, чередует «+» и «×» от залпа к залпу |
| TRAP-004 | Круг клинков | 8 вращающихся клинков, летят наружу и возвращаются |
| TRAP-005 | Арбалетный столб | один болт на игрока, длинная линия прицела |
| TRAP-006 | Трезубец | три болта веером на игрока |
| TRAP-007 | Спиральная | серия из 14 медленных шариков по спирали |
| TRAP-008 | Кольцо | кольцо из 16 мелких шариков (изначально 32), короткая дальность |
| TRAP-009 | Баллиста | редкий тяжёлый быстрый болт, долгая телеграфия |
| TRAP-010 | Маятник | две противоположные стороны, направление поворачивается от залпа к залпу |
| TRAP-011 | Занавес | 4 мелких медленных шарика в ряд поперёк, щели проходимы |
| TRAP-012 | Шипастая глыба | один крупный очень медленный шипастый шар |
| TRAP-013 | Рассыпная | 7 мелких медленных шариков веером серией |

Убраны из обсуждавшегося набора: Мортира, Органная очередь, Рикошетная; «Кольцо с щелью» заменено на плотное «Кольцо».
Спрайтов снарядов четыре: копьё, болт (направленные, быстрые, без вращения), клинок и шипастый шар (круглые, вращаются в
плоскости вида сверху, медленные классы). Качения как 3D-эффекта нет.

**Бочки.** Один вид, два состояния: обычная (2 из 3) и взрывная (1 из 3). До зажигания фитиля они неотличимы. Взрывная
срабатывает, когда игрок подходит на радиус срабатывания: показывается круг угрозы радиуса взрыва, затем взрыв бьёт игрока,
оказавшегося в радиусе. Игрок может выбежать из радиуса до взрыва. Бочка после взрыва исчезает вместе с телом.

**Размещение.** Тело держит зазор от старта, края арены, всех контуров препятствий и других тел ловушек; турель с фиксированным
направлением требует свободного пространства перед первым выстрелом. Если место не найдено за заданное число попыток, ловушка
пропускается (на утверждённой арене пропусков нет — проверяется тестом).

**Числа.** Все значения (урон, скорости, радиусы, интервалы, число ловушек: 40 турелей и 30 бочек, радиус срабатывания бочки 2.4,
взрыв 2.2, фитиль 1.2 с) — стартовые, подобраны от скорости игрока и урона вражеских снарядов; подлежат настройке по плейтесту.
Размеры снарядов: мелкие радиус 0.16–0.18, средние 0.30–0.45, крупный 0.95 (≈ две-три ширины персонажа в диаметре).

## Уточнение 2026-10-03: placeholder-вид, вращающийся крест на старте

По прямому указанию пользователя («проджектайлы пока прямоугольниками, ловушки тоже, но другим цветом, размер не важен; встрой
одну вращающуюся ловушку, которую сделали в 3D, на стартовом экране; всё на основной карте, не в тестовой»):

- Временный вид: турели и бочки — прямоугольники (турели синие, головка светлее), снаряды — жёлтые прямоугольники (направленные
  вытянуты по полёту, круглые — квадраты, вращающиеся в плоскости). Круги угрозы остаются дисками. Данные и логика не меняются.
- TRAP-002 «Крест» получает параметр `spinDegreesPerSecond = 40`: пока турель отдыхает, головка медленно поворачивается; на
  телеграфию и залп она останавливается, и копья летят по позе, в которой она остановилась. Параметр допустим только для `fixed`.
- Одна ловушка TRAP-002 стоит на стартовом экране: `startTraps` (смещение 5.5, 2.0 от старта; при занятом месте та же дистанция
  обходится по кругу с шагом 30°). Она входит в число (3) ловушек TRAP-002, а не добавляется сверху.
- Только эта ловушка рисуется 3D-префабом `trap-002-cross.prefab` (прототип арт-сессии, `Art/Prototypes/field004-trap-cross`): модель
  лежит на плоскости XZ, наклоняется к камере на `tiltDegrees` (54°), сдвигается к камере на `depthOffset` (3), чтобы спрайты земли
  её не перекрывали; `RotatingHead` поворачивается на `−HeadAngle` вокруг локальной Y. Остальные ловушки остаются прямоугольниками.
- Обновление модели 2026-10-03: вместо Unity-прототипа подключена скорректированная Blender-версия (rev 3, `Art/Prototypes/field004-trap-cross-blender`):
  `export_unity_fbx.py` → `Assets/Art/Prototypes/Field004TrapCrossBlender/trap-002-cross-blender.fbx` → `TrapCrossPrefabBuilder`
  (Editor, `Game.Traps.Editor`) собирает префаб, сопоставляя имена материалов Blender с материалами TrapCrossMatte (контур — реальная
  оболочка геометрии, `outline-shell`; верх ступицы — `hub-steel`), и переключает запись `cross` библиотеки. Старый префаб остаётся нетронутым.
- Префаб лежит вне Resources, поэтому он подключён через `Resources/Content/Presentation/TrapPrefabLibrary.asset` (список ссылок
  «ключ → префаб»); цифры модели — в `models` пакета ловушек. Поле остаётся FIELD-004: это основное производственное поле, не `Тест NN`.

## Уточнение 2026-10-03 (3): раскладка по экранам, порядок генерации, размер препятствий

По прямому указанию пользователя («тестовую штуку на стартовом экране оставь; в целом на каждом экране хотя бы две ловушки — в основном
две, иногда одна, достаточно редко три; препятствия расставлять после ловушек; крупные препятствия на этой карте уменьшить»):

- **Плотность.** `trapLayout.density`: арена режется на ячейки размером в один экран (17.8×10, число ячеек округляется, размер
  подгоняется, без узких остатков), каждая получает 1/2/3 ловушки с весами 2/7/1 (≈20% / 70% / 10%); тип выбирается по весу, в этом
  режиме `count` типа — только вес. Вокруг старта (радиус 14) случайных ловушек нет. Правило только для FIELD-004. Параметр `minGap`
  снижен до 1.0, чтобы три ловушки помещались в ячейку и витрина встала по периметру.
- **Витрина.** Раскладка по периметру стартового экрана FIELD-004 сохраняется как временная; прежняя одиночная стартовая ловушка
  заменена ею. Принудительных «краевых» препятствий у стартового экрана у FIELD-004 нет, конфликта с кругами ловушек нет.
- **Порядок.** Ловушки и бочки генерируются раньше препятствий; препятствия обходят их тела через `FieldObstacleExclusion`
  (круг = тело × масштаб модели + зазор), как у алтарей FIELD-007. Снаряды по-прежнему заканчиваются о контуры реальных препятствий.
- **Карта и препятствия FIELD-004** (`field004-v1.json`): арена 100×100 вместо 200×200; крупные препятствия уменьшены примерно на
  треть (забор 3.6×0.72 → 2.4×0.55, пни и палатка 1.5–2.1 × 1.15–1.6 → 1.0–1.4 × 0.85–1.1), ячейка раскладки 48 → 25 (девять
  лагерных расстановок на карте). Первая–третья карты и их размеры не менялись; ловушек на них нет.
- **Нагрузка.** Сотни турелей: далёкие целиком выключаются (тело, кольцо, модель создаётся лениво), симуляция остаётся лёгкой
  (проверка расстояния). Вблизи при радиусе в экран одновременно активны порядка десяти ловушек — плотность подлежит плейтесту.

## Уточнение 2026-10-03 (4): повороты голов, враги, препятствия лагеря

По прямому указанию пользователя:

- **Враги.** Ловушки не бьют противников, а снаряды ловушек не останавливаются о противников: симуляция снарядов знает только игрока,
  препятствия карты и край арены; тела турелей и бочек — player-only (`excludeLayers` всё, кроме Player). Правило закреплено тестом.
- **Спиральная (TRAP-007) вращается.** Голова турели-серии (есть выстрелы с задержкой: Спиральная, Рассыпная) во время залпа
  поворачивается вместе с вылетающими выстрелами (`TrapPlacement.HeadTargetDegrees`: направление залпа + угол последнего выстрела).
- **Целящиеся турели** (Арбалетный столб, Трезубец, Баллиста, Занавес, Шипастая глыба, Рассыпная) поворачиваются к игроку не в момент
  выстрела, а чуть позже: после залпа голова держит позу `aimResumeDelaySeconds` = 0.35 с и только потом снова следит за игроком.
- **Препятствия лагеря (FIELD-004).** Забор — только горизонтальный (вертикальные повороты убраны у всех трёх расстановок), меньше
  (1.8×0.45), коллайдер забора — основание спрайта (`fenceBaseContact`: полная видимая ширина, заданная толщина, опирается на нижний
  непрозрачный ряд), игрок не проходит сквозь колья, но обходит верхушки. Палатка убрана из препятствий (расстановка TENT-POST
  переименована в CART-POST), телега больше (2.0×1.4).

## Уточнение 2026-10-03 (5): порядок отрисовки снарядов, размер «Копейного ряда»

- **Снаряды поверх ловушек.** 3D-модели сдвинуты к камере по глубине (`depthOffset`), поэтому спрайты снарядов на z=0 скрывались за ними;
  снаряды теперь рисуются ещё ближе к камере, чем самая «глубокая» модель (`z = −(depthOffset + 2)`).
- **Наконечники.** Копьевидные наконечники и болты ловушек (TRAP-001/002/003/005/006/009/010) покрашены двумя тонами снарядов-копий
  (светлый (0.60, 0.60, 0.62), тёмный (0.38, 0.39, 0.44), сняты со спрайта снаряда): заряженное и выпущенное копьё — один предмет.
  Светлая сторона — верхняя в системе головы, граница фиксирована по граням материалами (без динамической тени). Лезвия колеса и шипы
  кургана остаются светлой сталью.
- **Красная обводка снарядов.** Вокруг силуэта каждого снаряда ловушки — тонкая яркая красная кайма (цвет (1, 0.05, 0.04, 0.95), ширина
  2.5 экранных пикселя): шейдер `SurvivorArena/SpriteDilatedOutline` расширяет альфу самого спрайта на заданное число экранных пикселей (через производные UV, поэтому кайма одной толщины и круглая при любом размере окна и повороте; при ширине в долях холста на большом окне появлялись «звёздочки») и рисует его позади
  снаряда (плоский цвет, текстура даёт только форму). Огромные диски-свечения (были в промежуточном варианте) убраны.
- **«Кольцо» (TRAP-008)** — вдвое реже: 16 шариков вместо 32 (шаг 22.5°); просвет между соседними 0.65 при диаметре игрока 0.7,
  то есть кольцо всё ещё сплошное, но заметно разрежено.
- **Ещё крупнее (2026-10-03).** «Копейный ряд» ещё +15% (масштаб 0.9 → 1.035), пушка с огромными шарами (TRAP-012 «Шипастая глыба»)
  доведена до того же масштаба 1.035; вторая сторона наконечников, сливавшаяся с железом, теперь чуть светлее первой: (0.38, 0.39, 0.44) → (0.66, 0.66, 0.69) при первой (0.60, 0.60, 0.62).
- **«Копейный ряд» (TRAP-001)** — модель в 1.5 раза больше (`scale` 0.6 → 0.9, вместе с ней растут коллайдер, кольцо состояния и зазор
  для препятствий); остальные модели не менялись.
- **Правки 2026-10-03 (вечер).** Частокол (`Fence`) убран из паттернов препятствий FIELD-004 (остаются ящики, манекены, жаровни, телега).
  «Занавес» (TRAP-011, четыре медленных шара) увеличен до размера копейного ряда (scale 1.035); у него (шаг 1.1) и у копейного ряда
  (шаг 0.7) залпы сжаты плотнее. Ножи («Круг клинков») в 1.5 раза меньше (радиус 0.35 → 0.2333). Фиксированные головы со ступенчатым
  поворотом (TRAP-003, TRAP-010) тоже поворачиваются чуть позже выстрела (`aimResumeDelaySeconds` 0.35). «Копейный ряд» ставится
  в случайное из восьми стандартных направлений; наводящиеся ловушки наводятся как раньше.
- **Девелоперская миникарта** показывает ловушки (красные ромбы) и бочки (точки, взрывные оранжевые) — `IMapPreviewSource.Traps`.
- **Нарративный размер (2026-10-03).** Масштаб модели следует размеру снаряда (0.55 + 0.25 × S); снаряд вылетает из дула модели
  (радиус тела × масштаб модели), а не с фиксированного расстояния. Пушка с огромными шарами подбирается по размеру жерла: шар
  радиусом 0.75 (было 0.95), масштаб модели 1.55, чтобы шар не был вдвое шире дула.
- **Витрина убрана (2026-10-03).** Временный набор «13 ловушек по периметру стартового экрана + 2 бочки» удалён из данных и генератора:
  ловушки и бочки только расставляются по экранам; старт (радиус 14) свободен.
- **Старт, бочки, шансы (2026-10-03).** Стартовая зона открыта для ловушек (`startClearRadius` 0). Бочки генерируются отдельно: ровно

## Consequences

- Код: модуль `Game.Traps` (определения, генератор размещения, чистая симуляция `TrapRuntime`), сценный `TrapRuntimeDriver` в
  Bootstrap с placeholder-визуалом по ключам, `FieldEnvironmentPresentationDefinition.TrapLayout`, подключение в `GameplayCompositionRoot`.
- Данные: авторский пакет `docs/balance/field004-traps-v1.json` → генератор (`fields.py`) → `ProductionFieldEnvironmentPresentation.json`
  (`trapLayout` только у FIELD-004).
- Тесты: `TrapDefinitionTests`, `TrapPlacementTests`, `TrapRuntimeTests`, `ProductionField004TrapsTests`.
- Арт: placeholder-фигуры заменяются отдельным проходом по [брифу](../art/briefs/field004-traps-art-v1.md); логика и коллайдеры не меняются.
- Не сделано: звук ловушек, отдельный player-facing UI. `Game_design.md`/`Content_design.md` не менялись.
- Открыто: плейтест чисел (плотность, урон, темп ярости); нужна ли короткая задержка сброса ярости, если игрок будет «качать»
  границу радиуса; распространять ли ловушки на другие поля.

## Approval

Набор турелей, бочки, правило радиуса (одна ширина экрана для активации, ярости и отсечения), ярость ×3 за 60 с с мгновенным
сбросом, неуязвимость и отсутствие блокировки врагов, отдельный бюджет и «пока только одно поле» — утверждены пользователем в чате
2026-10-03; запрос «Ну, давай такой набор оставляем. А, реализуй. Арт потом добавим отдельно». Числовые значения не утверждались.
