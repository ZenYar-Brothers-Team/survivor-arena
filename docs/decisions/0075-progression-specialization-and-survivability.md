## Context

Пользователь: уровни в начале забега растут слишком быстро; стартовому умению каждого персонажа нужна
существенная специализация (итоговая мощь ≈×2); зелья должны лечить больше; враги — бить на ~30% слабее;
регенерация — слабее. Поиск достижимой точки для пикапов не нужен: пикап может остаться внутри препятствия
и быть недоступным — «это не страшно».

## Decision

### Стоимость уровней

`C'(L) = round(C(L) × (0.8 + 2.2 × e^(−(L−1)/7.64)))`, неубывающая, где прежняя `C(L) = 4 + floor(1.5 × (L − 1))`.
Первый уровень стоит 12 XP вместо 4 (×3); множитель плавно снижается (до L5 суммарно ×2.5, до L11 ×1.9,
до L21 ×1.36) и к L40 сумма та же: 1257 XP против 1258, поэтому уровень к концу забега практически прежний.
Выше L40 уровни немного дешевле (последнее значение 74 вместо 92).

### Специализация стартового умения

Поле персонажа `startingSkillBoost` — бонусы только к его стартовому умению на весь забег, через тот же канал
skill-модификаторов, что у сетов (складываются аддитивно с пассивками). Без пассивок итог ≈×2:

| Персонаж | Стартовое умение | Бонус | Итог |
|---|---|---|---|
| CHAR-001 Клёпка | SKILL-001 | +60% damage, +25% action speed | 1.6 × 1.25 = 2.0 |
| CHAR-002 Бугор | SKILL-003 | +60% damage, +25% size | ≈2 |
| CHAR-003 Шепотка | SKILL-005 | +60% damage, +25% action speed | 2.0 |
| CHAR-004 Тётка Шмыга | SKILL-009 | +60% damage, +25% action speed | 2.0 |
| CHAR-005 Бабка Искра | SKILL-007 | +45% damage, +40% action speed | 2.03 |
| CHAR-006 Гром | SKILL-010 | +45% damage, +25% size | ≈2 (больше целей в AoE) |
| CHAR-007 Дед Вертун | SKILL-006 | +60% damage, +25% action speed | 2.0 |
| CHAR-008 Тётушка Светляк | SKILL-012 | +60% damage, +25% range | ≈2 |
| CHAR-009 Иголка | SKILL-013 | +60% damage, +25% action speed | 2.0 |
| CHAR-010 Старшой Ночка | SKILL-015 | +60% damage, +25% range | ≈2 |

В production сейчас только CHAR-001; остальные значения — канон карточек для их будущей реализации.
Экран выбора персонажа показывает бонус рядом со стартовым умением.

### Выживаемость

- `hostileDamageMultiplier` = 0.7 в run setup: весь урон врагов, боссов и враждебных Путников по игроку ×0.7
  (умножает базовый incoming damage игрока; числа карточек врагов остаются базой).
- PICKUP-001 лечит 30 HP вместо 18.
- Регенерация вдвое слабее: PASSIVE-002 L1–L6 0.1/0.2/0.35/0.5/0.7/1.0 HP/s (было 0.2…2.0), SET-006 +0.3 HP/s (было 0.6).

### Дроп пикапов

Зелье и Книга остаются в точке выпадения с seeded-разбросом, в том числе внутри препятствия; поиск
достижимой точки не выполняется. Точка лишь зажимается в границы поля (отступ `placementSkin`), чтобы дроп не
оказался за оградой. Размещение Путников не меняется.
