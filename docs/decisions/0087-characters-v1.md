# DECISION-0087 — Персонажи CHAR-002…010: заметные характеристики и блокировки драфта

Status: Approved  
Date: 2026-09-28  
Related IP: IP-22, IP-12  
Related content IDs: CHAR-002…010

## Context

CHAR-002…010 имеют утверждённые карточки и подготовленные body, но в игре только CHAR-001: числовые веса драфта
(gate G-14) не заданы. Пользователь 2026-09-28 попросил: у каждого персонажа заблокировать пару активных умений и
пару пассивок, чтобы разные персонажи собирали разные сеты; и сделать отличия по главным характеристикам заметными
(+30…+50%) с ослаблением для баланса. Сейчас веса персонажа действуют только на активные умения, а карточные
отличия составляют 5–30%.

## Decision

Утверждён пакет [characters-v1](../balance/characters-v1.md):

1. Веса драфта: «повышенные» активные и три пассивки по образу персонажа ×1.35 (как у CHAR-001), «пониженные»
   активные и две пассивки на персонажа — 0. CHAR-001 без изменений.
2. GDD «Персонажи»: веса персонажа распространяются и на пассивки, как задумано (authoring baseline v1 уже
   содержит `passiveDraftWeights`). Заблокированный вес исключает предмет из
   level-up, Книги, reroll и делает сеты с ним недостижимыми для этого персонажа.
3. Новые базовые характеристики CHAR-002…010 из таблицы пакета заменяют карточные значения.
4. Условия открытия, цены, стартовые умения и их специализации не меняются.

## Consequences

- Game Design: строка про веса персонажа дополняется пассивками.
- Content Design: характеристики и Draft weights карточек CHAR-002…010.
- Код: вес персонажа для пассивок в `DraftPool` и валидации определения; генератор персонажей.
- Данные: `ProductionCharacters.json` с CHAR-002…010, portrait/icon crop и motion profiles.
- Тесты: per-character snapshot, блокировки, недостижимость сетов.

## Approval

Утверждено пользователем 2026-09-28 в чате («Утверждаю сделанные правки»), включая уточнение о повышенных весах пассивок.
