# DECISION-0160 — FIELD-010: мягкая палитра и отсутствие чужих препятствий

Дата: 2026-10-03. Основание: прямое поручение пользователя убрать препятствия других карт, приглушить плитку, снизить яркость и дёрганость эффектов; разрешён другой оттенок.

## Окружение

Сохраняется открытая арена из [DECISION-0157](0157-field010-screen-events.md). Собственный утверждённый набор опасностей FIELD-010 — 13 экранных событий. Отдельного production-набора физических препятствий для неё пока нет; чужой пень, ограды, кусты и прочие объекты не подставляются. Если поле имеет собственную явную раскладку, используются только её объекты; screen-event arena без раскладки отключает scene fixture art и collision. Границы арены сохраняют collision; Shutdown восстанавливает исходный collider пня.

Основная плитка сохраняет утверждённый PNG и получает RGB-множитель `groundTint = #A29AA8` только на FIELD-010. Параметр — непрозрачный `#RRGGBB`, компоненты 0…255; белый цвет при отсутствии override — нейтральное поведение других полей. Например, исходный белый пиксель становится RGB(162,154,168). Authoring: `field.groundTint` в [field010-screen-events-v1.json](../balance/field010-screen-events-v1.json), generator → production environment presentation → ground SpriteRenderer. Исходный raster, GUID, персонажи и UI не меняются.

## Эффекты

Уточнение [DECISION-0159](0159-field010-strike-motion-and-audio.md): pulse Hz/depth = 0/0 (мерцание отключено), вращение круга 170→45 °/с, прокрутка полос 6→1.4 мировых единиц/с, кольцо 0.8→0.15 циклов/с, наружные полосы 3.5→0.9 мировых единиц/с. Раскрытие 0.12→0.18 с; длительности ударов остаются прежними.

Strike artwork получает приглушённый лиловый RGB-множитель `#B5A9BF` вместо белого; раньше strikeColor задавал лишь заливку. Alpha рисунка удара 1→0.58, заливки 0.34→0.12. Предупреждение сохраняет красный язык опасности: alpha рисунка 0.5→0.8 по прогрессу, заливки 0.08→0.14. Неподвижная граница удара alpha 0.32; безопасный край 0.65, коридор 0.10. Диапазоны параметров остаются из DECISION-0159; alpha — доли 0…1. Геометрия, урон, частота угроз, время предупреждения и звук не меняются.

## Проверка

Регрессия проверяет отсутствие чужого пня и его невидимого коллайдера в реальной FIELD-010 сцене. Цвет пола применяется только этой карте. Существующие graphics captures показывают все 13 событий и пять последовательностей движения на новом полу; пользовательская оценка комфорта/читаемости остаётся отдельной от automated checks. Новые PNG не создаются, art packet plan должен оставаться без изменений.
