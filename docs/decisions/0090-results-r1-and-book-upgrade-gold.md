# DECISION-0090 — Results R1 и золото за улучшение из книги

Дата: 2026-09-28. Решение утверждено пользователем: макет Results принят,
«за открытие книги с получением уровня тоже добавим золота, 20».

## Решение

Results использует принятый макет: исход, время/уровень/убийства, награда за
уровень/книги/итог. Справа сначала новые открытия (сеты, активные/пассивные
умения, персонажи, карты), затем собранные сеты. Изображение и имя каждого;
для открытия дополнительно тип. Общая прокрутка только коллекции; кнопки
«В меню» и «Ещё забег» закреплены. Существующие selection/retry/save gates сохраняются.
UI получает типизированный snapshot и saved receipt именно данного RunId,
не разбирает summary string и не начисляет награды.

Книга не повышает XP-level персонажа: «получение уровня» здесь означает
полученное из Book draft улучшение. При успешном выборе начисляется 20 монет
в run book total. Обычный XP draft не даёт эту надбавку. Пустая при подборе
книга остаётся отдельным вариантом за 50 монет, не 70. Повтор pickup/submit,
reroll, banish и отмена выбора не начисляют 20 повторно; без успешного выбора
надбавки нет. Запись результата по RunId идемпотентна.

С учётом последующей [DECISION-0098](0098-earned-level-run-reward.md)
суммарная награда = 5 × (L − 1) + 20 × U + 50 × E, где L — достигнутый целый уровень
не ниже 1, U — число успешных Book-выборов, E — число пустых при подборе книг;
U/E — неотрицательные целые. Например, L20, U3, E2 дают 255 монет.
`MetaEconomy.bookUpgradeReward` — неотрицательное целое число монет за выбор,
production 20; fixture 0 (нейтральное отключение). Сохранённые старые receipts
не пересчитываются, schema профиля не меняется.
