## Основание

В завершённом прогоне `091d834ec84d420ba40ae50066cc1c05` Небесный удар был получен на 9:03,
но дал 15359.31 applied damage (23.83% всего урона) и 56.04 observed equipped DPS — больше любого
другого умения этого билда. Пользователь поручил уменьшить всю прогрессию роста радиуса.

Стартовая прокачка всё ещё ощущается медленной. Пользователь уточнил, что менять количество выпадающего
XP не нужно: стоимость улучшений в начале должна быть примерно на 20% ниже, а суммарная стоимость к концу
забега — примерно прежней.

## Решение

### SKILL-010

- Основной impact radius L1–L6: `0.8 / 1.3 / 1.8 / 1.8 / 1.8 / 1.8` world units вместо
  `0.8 / 1.6 / 2.24 / 2.24 / 2.24 / 2.24`.
- Третий удар L6 использует `×1.35` radius вместо `×1.5`: итоговый radius `2.43` вместо `3.36`.
- Damage, cooldown, targeting radius, число ударов, telegraph, knockback и vertical scale не меняются.

Полное поведение по уровням после изменения:

| Уровень | Урон за удар | Основной radius | Удары за активацию | Что добавляет уровень |
|---:|---:|---:|---:|---|
| 1 | 24.75 | 0.8 | 1 | Один удар после telegraph 0.6 s. |
| 2 | 24.75 | 1.3 | 1 | Radius растёт, knockback 0.45 → 0.54. |
| 3 | 32.175 | 1.8 | 1 | Урон +30%, radius достигает финального основного значения. |
| 4 | 32.175 | 1.8 | 2 | Второй последовательный удар через 0.3 s по другой цели, если она есть. |
| 5 | 32.175 | 1.8 | 2 | Action speed +33%; telegraph каждого удара 0.45 s. |
| 6 | 32.175 | 1.8 | 3 | Третий удар: radius ×1.35 = 2.43 и knockback ×1.5 = 0.81. |

В начале telegraph каждого удара фиксируется своя точка. В пределах одной активации выбираются разные враги;
если новой цели нет, используется случайная точка на экране. Смерть уже выбранной цели не отменяет удар и не
перенаводит его. Базовый cooldown — 4.5 s; бонус action speed уровня 5 уменьшает фактический интервал активаций.

### Стоимость уровней

Сохраняется экспоненциальная форма. Для перехода с уровня `L` на `L+1`, где `L = 1…60`:

`B(L) = 4 + floor(1.5 × (L − 1))`

`R(L) = round(B(L) × (0.92 + 1.48 × e^(−(L−1)/5.5)))`

`C(1) = R(1)`; для `L > 1`: `C(L) = max(C(L−1), R(L))`.

`B` и `C` измеряются в XP units; `round` округляет до ближайшего целого, а `max` сохраняет
неубывающую стоимость. Первые десять значений: `10/11/14/14/16/17/18/19/20/21` XP.

- Сумма L1–L10: `160 XP` вместо `200 XP`, ровно −20%.
- Сумма L1–L39 для достижения L40: `1257 XP`, без изменения.
- Сумма L1–L36 для достижения L37: `1094 XP` вместо `1111 XP` (−1.5%), поэтому поздний уровень
  остаётся практически прежним.
- Последний явный threshold L60 — `85 XP`; после массива повторяется 85 XP. Это не вводит level cap.

Количество dropped/collected XP, награды врагов, lifetime drops и XP modifiers не меняются.

## Проверка и повторный прогон

Обязательны generation check, baseline validator, production catalog tests SKILL-010 и run setup,
затем полный безопасный Unity smoke. В повторном ручном прогоне сравнить время L5/L10, итоговый уровень,
долю/DPS SKILL-010 и наличие лагов отдельно: эта настройка баланса не считается исправлением performance-проблемы.
