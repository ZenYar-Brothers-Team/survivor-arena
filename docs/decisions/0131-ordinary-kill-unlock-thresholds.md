# DECISION-0131 — Пороги открытий за убийства обычных врагов

Status: Approved
Date: 2026-09-30
Related IP: IP-25, IP-26
Related content IDs: FIELD-002, FIELD-005, FIELD-007, SKILL-009, SKILL-015, PASSIVE-010, SET-008, SET-011

## Decision

Пороги всех открытий за накопительные убийства обычных врагов увеличиваются
в шесть раз относительно DECISION-0125:

| ID открытия | Поле убийств | Было | Стало |
|---|---|---:|---:|
| FIELD-002 | FIELD-001 | 500 | 3000 |
| FIELD-005 | FIELD-004 | 1500 | 9000 |
| FIELD-007 | FIELD-006 | 2000 | 12000 |
| SKILL-009 | FIELD-002 | 300 | 1800 |
| SKILL-015 | FIELD-004 | 500 | 3000 |
| PASSIVE-010 | FIELD-002 | 350 | 2100 |
| SET-008 | FIELD-002 | 700 | 4200 |
| SET-011 | FIELD-001 | 500 | 3000 |

Прогресс сохраняется между начатыми забегами, включая поражение и Quit.
Альтернативы через прохождение предыдущего поля остаются. Условие четырёх
побед над MIDBOSS-008 и достижения по урону/монетам, цены и прочие открытия
не меняются. Эти восемь порогов заменяют соответствующие значения DECISION-0125.
