# DECISION-0087 — Силуэты неполученных героев и компактная сетка полей

Status: Approved
Date: 2026-09-28
Related IP: IP-12, IP-16, IP-26
Related content IDs: playable roster (including CHAR-001/002), FIELD-001…010 (presentation only)

## Context

В review стартовых экранов пользователь попросил показывать неполученного Бугра
силуэтом и убрать описания окружения полей. Агент предложил компактную сетку:
thumbnail, название, сложность, короткая причина блокировки, отдельный Start Run.
Пользователь разрешил: «То, что описал, можно делать».

## Decision

- Неполученный герой — одноцветный силуэт без деталей внешности и в каталоге,
  и в крупном просмотре. Выполненный unlock без покупки не раскрывает body.
  После получения используется исходный цветной sprite и обычные сведения.
  Уточнение пользователя 2026-09-28: до получения в выборе персонажа остаются
  только силуэт и «?». Имя, роль, умение, характеристики, постоянные бонусы и
  причина блокировки скрыты и на карточке, и в крупном просмотре, и в footer.
  Это заменяет прежнее разрешение показывать имя и сведения закрытого героя;
  правила покупки и экран Meta этим уточнением не меняются.
- Field Select — компактная сетка без большой правой панели и без описаний
  плетней, бочек, огородов и другого окружения. Карточка содержит thumbnail,
  название, сложность 1–5 и состояние доступа. Для выбранного закрытого поля
  видна краткая причина блокировки в общей строке под сеткой.
  Уточнение пользователя 2026-09-28: вместо цифр сложности — пять мечей,
  заполнены первые N, остальные приглушённые/контурные; N берётся из difficulty.
  Числа и баланс полей не меняются.
- Целевые десять полей помещаются целиком на 1280×720 и 1920×1080. Браузерный
  кандидат использует 5×2. Если каталог расширится, допускается вертикальный
  scroll самой сетки; footer остаётся неподвижным. Размеры не меняют minimum resolution.
- Клик/Enter/Space выбирает карточку для просмотра; отдельный Start Run подтверждает
  доступное поле. Locked нельзя запустить; Back сохраняет выбранного героя.
  Access/unlock/purchase по-прежнему принадлежат существующим owners.

## Consequences

Уточняются UI §§4–5, character/field/UI presentation contracts и Art Direction.
Description metadata не удаляется из schema/catalog; она просто не отображается
на выборе поля. GDD, CD, баланс, цены и progression rules не меняются.

Это не approval конкретного нового menu art, parallax layers или чистовой отделки
кнопок. Их browser preview не считается Unity implementation/verification.
Исполнение и gates учитываются только в [STATUS](../implementation/STATUS.md).

## Approval

Пользователь явно утвердил описанные изменения 2026-09-28. Финальная визуальная
приёмка обновлённого макета и дальнейший Unity-перенос — отдельные шаги.
