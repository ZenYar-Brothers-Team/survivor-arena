# DECISION-0043 — Небольшой seeded-разброс world drops

Status: Approved
Date: 2026-09-22
Related IP: IP-06, IP-12A, IP-28, IP-29

## Основание

Пользователь указал, что несколько наград, выпавших в одной точке, полностью закрывают друг друга. Для XP, Зелья и Книги нужен небольшой дополнительный случайный разброс без дорогого поиска уникального места и без изменения механики подбора.

## Решение

Перед проверкой доступности каждый world drop получает смещение, равномерное по площади диска заданного радиуса. Используется отдельный seeded RNG: визуальное размещение не расходует последовательность бросков drop chance и воспроизводится при одинаковом seed. Текущий fixture radius — `0.30` world units.

XP применяет разброс к death position. Зелье и Книга применяют его к запрошенной spawn position, после чего существующий placement adapter переносит результат в ближайшую доступную точку при выходе за поле или попадании в препятствие. Разброс не меняет pickup radius, reward identity, вероятность выпадения, порядок обработки или authoritative source position в enemy lifecycle.

## Визуальная подача

XP, Зелье и Книга используют отдельные `SpriteRole.Pickup` sprites. Один дешёвый visual-only bob/pulse работает на дочернем transform, замораживается вместе с gameplay и полностью сбрасывается при pool reuse. Collider/root не двигаются и не масштабируются этой анимацией.

## Проверка

Проверяются ненулевое смещение внутри radius, разные позиции последовательных drops из одной точки, независимость reward lifecycle, pause и pool reset. Финальная читаемость и величина разброса подтверждаются gameplay review.
