# DECISION-0098 — Награда только за уровни после старта

Status: Approved

Date: 2026-09-29

Related IP: IP-25, IP-26
Related content IDs: MetaEconomy

## Context

Персонаж начинает забег на уровне 1. Прежняя формула `5 × L` начисляла
5 монет даже при немедленном завершении без получения опыта.

## Decision

По прямому уточнению пользователя начальный уровень не учитывается:
`R = 5 × (L − 1) + 20 × U + 50 × E`, где L — достигнутый целый уровень
начатого забега (L ≥ 1), U — число успешных улучшений из Книг, E — число
пустых при подборе Книг. При L1 и U=E=0 награда 0; при L2 — 5 монет.
Book-награды остаются независимыми: L1 с одним успешным Book-выбором даёт 20.
Все terminal reasons начатого забега используют одну формулу.

## Consequences

Коэффициент в MetaEconomy не меняется. Saved receipts прежних RunId не
пересчитываются; новый расчёт применяется к новым результатам. Results показывает
уже сохранённые составляющие. Обновляются Game/Content/UI design, IP-25/26,
ProfileService и тесты на L1, L2, смешанную Book-награду и повторное сохранение.

## Approval

Пользователь 2026-09-29: «если с самого начала завершить забег то дается
5 монет. Начальный уровень не должен учитываться».
