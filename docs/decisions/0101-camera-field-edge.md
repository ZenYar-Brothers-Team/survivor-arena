# DECISION-0101 — Камера останавливается у границы поля

Status: Approved for gameplay trial
Date: 2026-09-29
Related IP: IP-02, IP-26

## Context

Физическая граница поля уже останавливает игрока, но камера продолжала
центрироваться на нём и показывала пустое пространство за текстурой поля.
Пользователь попросил остановить камеру у края, оставить игроку возможность
упереться в границу экрана и возобновлять слежение после отхода внутрь поля.

## Decision

Базовый центр ортографической камеры без задержки следует за игроком по каждой
оси, пока её видимая область целиком помещается на поле. Затем координата камеры
ограничивается независимо по X/Y. Для квадратного поля со стороной `S` world
units и видимыми половинами ширины/высоты `W/H` world units допустимый центр:
`x ∈ [−max(0,S/2−W), +max(0,S/2−W)]`, аналогично для Y с `H`.
При возвращении игрока внутрь этого интервала слежение сразу продолжается.
Пример: при `S=200`, `H=5`, `W≈8.9` правый центр камеры не выходит за `91.1`;
край кадра остаётся на `x=100`. Физическая граница игрока не меняется.

Screen Shake смещает камеру только на время рендера и использует то же ограничение,
чтобы тряска не открывала пространство вне поля. Положение по Z сохраняется.
Правило уточняет [DECISION-0001](0001-player-centered-camera.md): игрок
центрирован, пока для этого хватает пространства поля.

## Consequences

Поведение у четырёх сторон и после отхода проверяется автоматически. Видимость
художественной границы и ощущение упора требуют просмотра в игре.

## Approval

Пользователь 2026-09-29 прямо поручил ограничить движение камеры у края поля и
возобновлять слежение после отхода игрока от границы.
