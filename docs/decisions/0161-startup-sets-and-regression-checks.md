# DECISION-0161 — стартовые low-tier сеты и актуальные regression checks

Дата: 2026-10-03. Основание: поручение разобрать общие сбои тестов; пользователь прямо подтвердил «Оставить пять сетов открытыми сразу».

## Стартовые сеты

Уточнение [DECISION-0138](0138-low-tier-sets.md): SET-023 «Дорожные сборы», SET-024 «Набитая рука», SET-026 «Круговая оборона», SET-030 «Размах руки» и SET-034 «Ледяной град» открыты сразу (`initial`, price 0), дополнительно к SET-001/004/006/010/017. Остальные цены и условия не меняются. Уже выданные unlocks не отзываются. Новый профиль имеет 10 стартовых сетов. Прохождение FIELD-001…004 добавляет прежние field-based сеты, поэтому общее число открытых сетов становится 11/12/13/14.

`MetaEconomy.json` уже содержит эти условия; исправляются отставшие тесты, без изменения gameplay/экономики. Магазин показывает 85 non-dev сущностей: 10 героев, 10 полей, 30 умений/пассивок, 35 сетов. При fresh profile закрыто 25 сетов. Тесты отдельно проверяют конкретные стартовые ID и проекцию каталога в магазин; число карточек не должно использовать старое ограничение 70.

## Проверки интерфейса и геометрии

DEV-панель намеренно не принимает NavigationSubmit/keyboard focus, чтобы не перехватывать клавиши игры. Smoke checks используют pointer down/up для DEV кнопок; отдельный guard подтверждает отсутствие keyboard focus и сохранение Space pause. Product input contract не меняется.

Designed field cards остаются на первом экране, DEV поля расположены ниже в своей секции и доступны прокруткой. Smoke проверяет эти две группы по их назначению, включая достижимость последней DEV карточки; правило отдельной секции из [DECISION-0132](0132-dev-blob-test-field.md) сохраняется.

Локальные UV повёрнутого моста сравниваются с абсолютным допуском 0.00001 мировой единицы вместо побитового равенства float; expected геометрия и safe width не меняются. Например, длина 24 после проекции под 45° может отличаться на единицы последнего разряда float.

Состояние выполнения и результаты прогонов находятся только в [STATUS](../implementation/STATUS.md) и связанном evidence; исправление теста не означает визуальную или игровую приёмку новой механики.
