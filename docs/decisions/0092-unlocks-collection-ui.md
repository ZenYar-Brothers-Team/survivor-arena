# DECISION-0092 — полная коллекция открытий

Дата: 2026-09-29. Пользователь принял показанные страницы и разрешил продолжение:
«Все хорошо, комментарий про силуэты отменяем, можно делать дальше».
Исполнение и проверки — в [STATUS](../implementation/STATUS.md).

## Решение

Перенести [согласованную композицию](../implementation/proposals/2026-09-29-ui-meta-r1.md)
в существующую вкладку Meta → «Открытия». Показывать весь каталог, включая начальные
открытия. Фильтры типа: все, персонажи, карты, умения (активные и пассивные), сеты.
Фильтры состояния: все, не открыто, можно купить, открыто. «Можно купить» означает
доступную сейчас покупку по модели профиля, включая достаточный баланс.

Три колонки при 1080p, две при 720p; одна общая прокрутка. Шапка, фильтры,
счётчик открытого/общего/показанного и возврат закреплены вне коллекции.
Группы: персонажи, карты, начальный контент и пакеты за прохождение полей.
Карточка содержит изображение, тип, имя, короткое условие либо статус открытия,
а для платной покупки — цену и отдельную кнопку. Пустой фильтр объясняется текстом.

Правило силуэта и «?» сохраняется только для неоткрытых персонажей.
Предложение распространить его на карты и сеты пользователь отменил до реализации.
Новые изображения карт не генерируются; при отсутствии thumbnail используется
номер карты в простой рамке из согласованного макета.

## Границы

Экономика, условия, профиль и момент выдачи открытий не меняются. Наличие карточки
поздней карты не снимает prerequisites её игрового каталога. View фильтрует готовые
данные presenter, покупки выполняет существующая служба профиля.
Settings и новые gameplay-каталоги не входят в этот перенос.
