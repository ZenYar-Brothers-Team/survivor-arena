# DECISION-0093 — чистовое оформление Settings

Дата: 2026-09-29. Пользователь принял [макет](../implementation/proposals/2026-09-29-ui-settings-r1.md)
и поручил перенести его в Unity. Исполнение — в [STATUS](../implementation/STATUS.md).

## Принятая композиция

Один экран «Полевой фолиант»: звук слева, изображение и управление справа.
Три громкости с целыми процентами, две кнопки audio preview. Режим выбирается
списком «На весь экран / В окне»; borderless desktop и поддерживаемые оконные
разрешения сохраняют контракт DECISION-0038. Мышь и дрожание камеры — галочки.
Bindings движения берутся из действующих привязок, пауза — Esc/Пробел/ПКМ.

Шапка и footer закреплены; штатное состояние помещается в 1920×1080 и 1280×720.
При переполнении центральная область прокручивается. Подтверждение видеорежима
в отдельном модальном окне, с Keep/Revert и отсчётом существующей settings service.
Фоновые элементы недоступны для ввода до завершения подтверждения/возврата.
Escape обрабатывается существующим shell shortcut без второго обработчика.

## Границы

Сохранение, файлы, pause ownership, rollback, audio routing и исходные defaults
не меняются. Новых настроек, remap, fullscreen exclusive и растрового арта нет.
Тесты используют изолированные memory stores и fake video, не пользовательские
предпочтения. Автоматические captures не заменяют ручной проверки на устройстве.
