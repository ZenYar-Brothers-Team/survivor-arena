# DECISION-0021 — Сложение процентных улучшений уровней active skills

Status: Approved
Date: 2026-09-21
Related IP: IP-08, IP-17
Related content IDs: SKILL-001…016

## Context

Content Design требует накопления изменений L2–L6, но база повторных процентов внутри одного умения нуждалась в уточнении. Пользователю предложены сложение бонусов к базе и последовательное умножение результата предыдущего уровня.

## Decision

Процентные улучшения уровней одного числового параметра складываются и применяются к его базовому значению один раз. Например, SKILL-001: base damage 20, +30% на L2 и +25% на L6 дают `20 × (1 + 0.30 + 0.25) = 31` до внешних modifiers.

Абсолютные значения заменяют прежнее значение. Явные отношения дочерних эффектов к основному («60% damage первого взрыва») сохраняются. Общие правила внешних modifiers, action-speed denominator и snapshot DECISION-0017 не меняются.

## Consequences

IP-08 реализует cumulative resolver без повторного начисления level bonuses при чтении/апгрейде. IP-17 использует тот же контракт для production definitions. Тесты проверяют несколько параметров, L1→L6 и повторное получение уровня.

## Approval

Пользователь утвердил вариант сложения ответом «да, сложение» 2026-09-21.
