# DECISION-0037 — Простая мета-экономика и сохранение профиля

Status: Approved (правила пользователя и явное поручение самостоятельно заполнить остальное)
Date: 2026-09-21
Related IP: IP-01, IP-03, IP-12, IP-16, IP-17, IP-19, IP-22, IP-23, IP-25, IP-26, IP-27

## Approval boundary

Пользователь: «награды за забег = 5*(достигнутый уровень). За пустые книги по 50»;
«За дострочные выходы начисляется. При прерываниях и сбоях тоже, если это ничего
не стоит по реализации»; «Завершить поле - выжить на нем 15 минут»;
«Остальное пропиши сам, при этом склоняйся к вариантам которые проще по реализации».
Цены, минимальный каталог upgrades, дополнительные unlocks и persistence policy
ниже выбраны по этому поручению. Это подготовка правил, не поручение реализовать
следующий IP. Уже утверждённые character/field условия сохраняются.

## Rewards и terminal boundary

R = 5 × L, где L — достигнутый целый уровень ≥1 начатого забега,
R — целая мета-валюта за завершение. Победа, поражение, Quit Run, остановка
начатого run для Retry и обрабатываемая ошибка дают одинаковую награду.
Не начатый run/ошибка подготовки не дают награды и не считаются первым забегом.
Дополнительных множителей поля, времени, kills или победы нет, минимального
времени тоже нет: старт на L1 и немедленный выход дают 5.
Каждая пустая при подборе Книга даёт 50; непустой запрос, опустевший позднее,
не компенсируется (DECISION-0020). B — число таких принятых пустых Книг, целое ≥0.
Results total = 5 × L + 50 × B. Пример: L20 и две пустые Книги — 100 + 100 = 200.
BookCurrency уже начислена внутри run; перенос в профиль выполняется один раз,
не повторным pickup/reward event. Все суммы/levels валидируются с checked arithmetic;
неполный/невалидный reward snapshot не превращается в успешный нулевой payout.

Поле пройдено, если игрок жив при достижении 900 running seconds. Паузы не
считаются; убийство босса не требуется; сокращённый fixture run не открывает
production FIELD. Смерть, принятая раньше terminal victory, исключает прохождение.
Первый принятый terminal snapshot окончателен: последующие Quit/Retry/error его
не заменяют и ничего не начисляют. Метка прохождения и unlocks сохраняются вместе
с reward. «Первый завершённый забег» для CHAR-002 — любой начатый и завершённый
таким snapshot забег, включая досрочный выход, но не ошибка инициализации.

## Минимальная экономика

Канонические значения находятся в разделе «Мета-экономика» Content Design.
Стартовый баланс 0; одна валюта. Сохранены существующие character/field gates.
SKILL-016 и SET-020 открываются прохождением FIELD-001; остальные skills/sets
и все passives открыты с начала (доступность сета в draft всё ещё требует рецепт).
Четыре upgrades: global HP/damage и per-character HP/damage, по пять уровней.
Без дерева, возврата покупок, валютных множителей, скидок или новых combat channels.
Покупки доступны между забегами; новые уровни применяются со следующего run.

## Persistence и предел поддержки сбоев

Один локальный versioned JSON профиль: schemaVersion, currency, уровни upgrades,
купленные/unlocked IDs, completed field IDs, факт первого run, обработанные RunId.
Runtime GUID RunId не зависит от recorder. Награда, unlocks и отметка RunId — одна
транзакция профиля; повторный Results/load/Retry возвращает прежний результат.
Покупка сверяет ID, ожидаемый текущий level и баланс; повтор intent со старым
level или уже купленным ID ничего не списывает. Condition unlock бесплатен,
монотонен, notification создаётся только при новом unlock.

Запись через временный файл и atomic replace с одной предыдущей backup-копией;
успех показывается только после успешной записи. При ошибке purchase откатывается
целиком; при ошибке записи результата snapshot остаётся pending в памяти,
показывается ошибка и Retry Save. До сохранения не разрешены новый run/покупки;
повтор записи использует тот же RunId. Quit Run ведёт в Results без дополнительного
подтверждения. Победа/поражение открывают Results сразу, без нового timed transition.
Обычное закрытие приложения во время начатого run пытается завершить его и записать
результат тем же путём, пока contributors живы. Обрабатываемая ошибка использует
тот же путь, если полный snapshot доступен; иначе показывает ошибку сохранения.

Аварийное завершение процесса/отключение питания не гарантируют награду за текущий
run, включая ещё не сохранённые BookCurrency. Промежуточных checkpoint/autosave
и возобновления gameplay нет: готовой инфраструктуры нет, это отдельная стоимость,
а пользователь разрешил crash support только без неё. Последний успешно сохранённый
профиль сохраняется. При штатном закрытии с ошибкой записи также нельзя обещать payout.

Отсутствующий профиль создаётся с балансом 0 и исходными unlocks. Повреждённый main
восстанавливается из валидной backup с сообщением об откате к предыдущему сохранению
(новейшая транзакция может быть потеряна). Если обе копии повреждены — экран ошибки,
сохранить файлы для диагностики; сброс только отдельным явным действием пользователя.
Более новая неизвестная schema не перезаписывается и не заменяется backup: ошибка
несовместимой версии. Старые версии мигрируют только по явным поддерживаемым шагам,
с backup исходника; неизвестная старая версия также блокируется без скрытого reset.
Initial production schema v1; миграционный механизм проверяется synthetic old schema.

## Consequences и проверки

CG-03/G-15 получили конкретные правила. IP-25 поставляет economy definitions и
profile pipeline; production skills/sets/characters/fields, их прочие данные и art
остаются у соответствующих IP. Integration использует synthetic runtime roster с
отдельными fixture IDs и fake consumers, не делает production ID готовым к игре.
Числа — approved baseline, не результат плейтеста; дальнейший tuning по IP-32.

Обязательны проверки L1/Quit, L20+2 Books=200, pause/900s/death ordering,
не начатый run, повтор terminal/load/Retry/intent, отсутствие двойной Book reward,
недостаток валюты, все unlock mappings, caps, next-run modifiers, atomic save failure,
backup recovery/version rejection/migration и UI result→purchase→next run.
Изменение только документов; Unity checks не являются evidence этой подготовки.
