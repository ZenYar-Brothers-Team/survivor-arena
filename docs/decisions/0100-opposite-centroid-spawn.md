# DECISION-0100 — Смещение спавна против центра массы врагов

Status: Approved for gameplay trial
Date: 2026-09-29
Related IP: IP-14, IP-24

## Context

Игрок заметил, что обычные враги собираются в плотную толпу даже после настройки
их движения. Он предложил чаще создавать новых врагов на стороне кольца,
противоположной центру массы живых врагов, сохранив возможность появления в любой
точке кольца. Расчёт должен оставаться дешёвым. Также пользователь попросил
приблизить обычный спавн к игроку: выбрать расстояние между стартовым появлением
у края экрана и прежним радиусом 12 world units.

## Decision

- Только при выдаче обычных врагов spawner берёт до 16 позиций из своего списка
  живых врагов с равным шагом. Их среднее направление относительно игрока задаёт
  приблизительный центр массы. Одна оценка используется для всей группы за tick.
  Когда врагов нет или направления взаимно компенсируются, угол остаётся равномерным.
- Параметр timeline `spawnOppositeBias` лежит в `[0, 1]`. Для равномерного
  `u ∈ [-π, π]` угол появления равен `oppositeAngle + u − bias × sin(u)`.
  При нуле сохраняется равномерный спавн; при положительном значении растёт
  концентрация напротив центра массы. Преобразование покрывает всё кольцо и
  использует один случайный выбор и один `sin` на врага без повторных попыток.
- Для FIELD-001/002/003 текущее пробное значение `spawnOppositeBias = 1.0`
  (увеличено с `0.8` через `0.9` по отзывам пользователя 2026-09-29).
  Обычный `spawnRadius` уменьшен с 12 до 10 world units. Первые 20 секунд
  по-прежнему используется появление у края экрана с прежним отступом.
- Значения хранятся в authoring balance JSON каждого поля и генерируются в
  production timeline. Fixture timelines используют нулевое смещение.

## Consequences

Влияние на форму толпы и давление на игрока требует просмотра в игре. Статические
и EditMode-проверки подтверждают диапазон коэффициента, воспроизводимость,
покрытие кольца и загрузку новых чисел; они не заменяют плейтест.

## Approval

Пользователь 2026-09-29 прямо поручил внедрить смещение против центра массы
с регулируемой концентрацией и затем уменьшить дистанцию появления до среднего
между стартовым и прежним обычным режимом.
