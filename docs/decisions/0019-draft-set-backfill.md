# DECISION-0019 — Дозаполнение драфта доступными сетами

Status: Approved

Date: 2026-09-21

Related IP: IP-07, IP-10, IP-11, IP-28

## Context / approval

Пользователь уточнил предложение по G-01/G-03: если в драфте остались свободные позиции и есть доступные сеты, не прошедшие проверку шанса, позиции заполняются равновероятным выбором среди этих сетов. Эта запись фиксирует только однозначно утверждённое дозаполнение. Валютная компенсация и очередь позднее уточнены пользователем в [DECISION-0020](0020-draft-requests-and-book-currency.md): только пустая Книга при подборе.

## Decision

1. Сначала формируются предложения по основным правилам: сеты, прошедшие проверку шанса, затем обычные active/passive предложения.
2. Если после этого занято меньше трёх позиций, оставшиеся позиции заполняются доступными сетами, которые не прошли проверку шанса. Выбор равновероятный, без повторов и без повторной проверки шанса.
3. При `n` оставшихся кандидатах вероятность выбора каждого в следующую свободную позицию равна `1/n`. После выбора кандидат удаляется. Заполняется `min(число свободных позиций, число кандидатов)` позиций.
4. Дозаполнение не обходит рецепт и его thresholds, разблокировки, banish или запрет повторного получения сета. Неуспешный бросок, включая `setDraftChance = 0`, сам по себе не лишает сет права на дозаполнение. Уже показанная карточка не повторяется.
5. Если обычные предложения уже заполнили все позиции, дозаполнение не вытесняет их. Если доступных сетов меньше свободных позиций, используются все; дальнейшее short/empty поведение применяется только после этого шага.
6. Появление карточки не активирует сет: игрок по-прежнему должен выбрать его.

## Examples / checks

| До дозаполнения | Доступные сеты с неудачным броском | Результат |
|---|---|---|
| 2 обычные карточки | A, B | Одна дополнительная карточка: A или B с вероятностью 1/2 |
| 1 обычная карточка | A, B, C | Два разных сета; каждый имеет вероятность 1/3 попасть в первую свободную позицию |
| 0 карточек | A, B | Обе карточки сетов; остаётся одна свободная позиция |
| 3 обычные карточки | A, B | Исходные три карточки без изменений |
| 0 карточек | Нет доступных | Действительно пустой драфт; только пустая при подборе Книга даёт валюту (DECISION-0020) |

Проверить отсутствие повторов, исключение banished/acquired/ineligible sets, границы chance 0/1 и одинаковое правило дозаполнения при каждом формировании предложений. Решение не определяет оставшиеся вопросы G-02 о порядке обработки успешных сетов и повторных бросках при reroll/banish.

## Ownership

IP-07 задаёт контракт set-offer provider и проверяет short/empty результат на fake provider; IP-11 реализует set selection и равновероятное дозаполнение. IP-10 не считает запрос пустым до завершения дозаполнения и не возвращает banished set. GDD и UI описывают то же поведение. Production значения шансов и наград не назначаются этой записью.
