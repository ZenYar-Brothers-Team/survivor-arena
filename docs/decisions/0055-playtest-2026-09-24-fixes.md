## Context

Два ручных прогона production FIELD-001 (commit `1e86425`) дали 12 наблюдений. Пользователь
поручил прочитать отзывы и исправить проблемы. Часть наблюдений — дефекты реализации, часть —
прямые пожелания пользователя к approved карточкам (архер, гончая, магнит), которые
пользователь сформулировал сам; конкретные числа он не задал.

## Decision

### Дефекты (канон не меняется)

- **Розовые эффекты (e1e04fc4 OBS-01/02).** Три code-created `ParticleSystem` (попадание снаряда,
  взрыв сферы, пыль смерти) не имели material и рендерились magenta-квадратами. Общий
  `ParticlePresentationMaterial` даёт им sprite-material владельца с мягкой круглой текстурой;
  цвета остаются прежними данными (пыль уже серо-коричневая).
- **Прогресс сетов в паузе (9ae3826e OBS-01).** Карточка показывала только число компонентов,
  выполнивших требование уровня, а список компонентов — лишь в tooltip. Теперь видимые строки:
  «Owned n/m» по наличию компонента (без учёта уровня), затем каждый компонент с ✓/○, текущим
  уровнем и требуемым уровнем; имена неполученных компонентов берутся из пула драфта.

### Презентация по отзыву

- **Небесный удар (OBS-03).** Круг сохранён; к impact добавлен вертикальный столб света
  (`pillarWidth`/`pillarHeight` в `SkillWorldEffects.json`: SKILL-010 0.7×3.2, SET-017 0.9×3.6),
  fade 0.3 s. Hit geometry не меняется.
- **Читаемость вражеских снарядов (OBS-06).** Новое правило Art Production: каждый hostile
  projectile получает пульсирующий coral-red ореол (`threatHalo`: scale 2.6–3.2 от collision
  diameter, alpha 0.55, период 0.35 s, амплитуда 18%) — Art Direction §12 «hostile danger —
  coral/red core, отличие минимум по двум признакам». Камень пращи увеличен визуально
  (visualScale 1.9 → 2.4). Коллайдеры не меняются. Тест требует ореол у всех назначенных врагам visual.
- **Гончая (OBS-07).** Runtime-изображение ENEMY-007 v002 — approved v001, уменьшенный вдвое вокруг
  import pivot (линия земли сохранена). Collision 0.75 по CD не меняется. `art_pipeline.py` не
  может принять этот body без contact values, которых у ENEMY-007 нет (их добавление изменило бы
  коллайдер), поэтому запись/manifest/v002 подготовлены вручную по тому же контракту; stage `Prepared`.

### Изменения approved чисел по пожеланию пользователя

| ID | Было | Стало | Обоснование |
|---|---|---|---|
| PASSIVE-007 | +10…+60% (0.55…0.8 units) | +40/+90/+150/+220/+300/+400% (0.7…2.5 units) | «на макс уровне около четверти экрана»: reference viewport height 10 → 2.5 units; каждый уровень заметно больше предыдущего |
| ENEMY-005 | 1 стрела × 14, cooldown 2.0 | очередь Burst 3 × 7, интервал 0.18 s, отклонение ±6° каждой стрелы, cooldown 2.0 | «3 снаряда по очереди с небольшим случайным отклонением»; урон стрелы снижен, чтобы полный залп (21) был умеренно выше прежнего выстрела, а часть стрел промахивалась |
| ENEMY-007 | recovery 4.5 s, первый dash 4.5 s | 2.5 s / 2.5 s | «пусть собака делает рывки чаще»: почти вдвое чаще при прежних telegraph/скорости рывка |

Отклонение — равномерное в ±spread/2 от текущего прицела на момент выстрела; источник
случайности — отдельный `System.Random` на жизнь врага (seed из LifeId), чтобы соседние лучники
не стреляли одинаково. Canon синхронизирован: карточки CD, baseline v1 (JSON/md), generator.

### Не изменено

- **Взрывные сферы (OBS-04/05).** По коду сфера SKILL-014 — летящий trigger-снаряд с lifetime
  1.8 s без лимита количества и без коллайдера для врагов; очереди «самая старая/новая» нет.
  Вероятная причина впечатления — magenta-квадраты взрыва (исправлены выше). Нужна повторная
  проверка пользователем; если «преграда» сохранится — нужен короткий повтор с marker.
- **Сложность к 2:30 (9ae3826e OBS-02).** Пользователь сам не выбрал способ; один прогон не
  обосновывает tuning ([BALANCE_WORKFLOW](../implementation/BALANCE_WORKFLOW.md)). Отложено до
  следующих прогонов с изменённым архером/гончей, которые уже поднимают давление.

## Consequences

Код: `ParticlePresentationMaterial`, `ProjectileThreatHaloProfile`, strike pillar в
`SkillWorldEffectPresenter`, Burst aim jitter в `EnemyAttackController`, set progress в UI.
Тесты: регрессия material, залп лучника и его разброс, ореол hostile projectiles, прогресс сетов.
Unity-проверка — `check_project.py --scope full` у пользователя; визуальная оценка — в игре.
