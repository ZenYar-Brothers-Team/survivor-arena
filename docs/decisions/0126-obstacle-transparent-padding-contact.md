# DECISION-0126 — Контакт препятствий по видимой форме prop

Status: Approved
Date: 2026-09-30
Related IP: IP-23
Related fields: FIELD-001…003

## Decision

По сообщению пользователя о преждевременном горизонтальном столкновении с
препятствиями после уменьшения героя прямоугольник player-only препятствия
подгоняется к границам импортированной физической формы его prop sprite.
Authored width/height по-прежнему задают номинальный размер и размещение
объекта; прозрачные поля спрайта больше не становятся твёрдой стеной.
Используется bounding rectangle формы, без новых коллайдеров и без чтения
пикселей в забеге. Для спрайта без физической формы остаются его полные границы.
Поворот стены на 90° поворачивает и её подогнанный прямоугольник.

Изменение касается только player-only препятствий FIELD-001…003.
Круги контакта персонажей и врагов по DECISION-0039 и масштаб по
DECISION-0114 остаются прежними. Автоматическая проверка сравнивает контакт
бочки и повёрнутой стены с видимым спрайтом; ощущение контакта при движении
требует игрового просмотра.

## Основание

Пользователь, 2026-09-30: «Посмотри еще коллайдеры, после уменьшения размера
персонажа столкновение с препятствиями (не врагами) происходит слишком рано
по горизонтали, с зазором».
