# DECISION-0133 — Контакт с плотным ядром dev-препятствий

Дата: 2026-10-01. Approved по прямому отзыву пользователя: «Подгони коллайдеры», поскольку часть контура позволяет заходить на рисунок, а часть блокирует движение в прозрачной зоне.

Related: [DECISION-0132](0132-dev-blob-test-field.md), [проверки и арт](../implementation/evidence/2026-10-01-dev-obstacle-soft-edges-and-contact.md).

## Решение

Для FIELD-DEV-BLOBS первоначальные маски исследования больше не определяют контакт. Двадцать контуров авторятся по плотному ядру текущих runtime PNG, с использованием реальных PPU и pivot каждого спрайта. Только позиции случайны; размер и ориентация фиксированы.

Технический проход: alpha ≥235, крупнейшая связная область, заполнение внутренних дыр, морфологическое открытие диском 0.20 world units для удаления тонких связей с пылью, отступ внутрь 0.12 world units, упрощение контура с допуском 0.14 world units. Отдельные камешки, пыль и тонкие корешки за основной массой не становятся препятствиями. Вогнутые участки сохраняются. Эти числа описывают offline подгонку текущих картинок; они не являются глобальным правилом контакта других карт.

Контуры сохраняются в docs/balance/field-dev-blobs-v1.json и выпускаются обычным content generator. В игре alpha не читается; PolygonCollider2D блокирует только Player, как раньше. Дальнейшая содержательная замена арта требует повторной проверки соответствия контура, PPU и pivot.

Плавный край готовится как визуальный переход. Он не определяет внешнюю границу коллайдера. Новые кандидаты проходят визуальный выбор перед заменой runtime по ASSET_PIPELINE.

## Уточнение при сближении палитры с полом

2026-10-01 пользователь разрешил расширять визуальный переход и прямо указал:
«столкновение останется по текущей действительно ограничивающей области».
Набор `ground-match-after-actual-floor-review.png` утверждён словами
«Подключай и комить». Шестнадцать PNG заменяют грунт/край относительно
фактического FIELD-003 фона; четыре колючки сохраняются.

Контуры, PPU и pivot не пересчитываются. Регрессионная проверка сверяет контуры
с immutable `vNNN/concept-01.png`, указанными в пакете
`field-dev-blobs-soft-edges-2026-10-01.json`: это исходный плотный core подгонки.
Новый визуальный грунт за этой областью остаётся проходимым. Автоматическая
повторная подгонка по альфе палитровой замены нарушила бы это указание.
