# DECISION-0150 — Отдельные образы типов алтарей и святынь

Дата: 2026-10-02. Направление и все 14 показанных изображений Approved:
«Хорошо, подтверждаю». Пользователь дополнительно утвердил совпадение фактической
зоны действия с серединой нового плетёного контура.
Связанные IP: IP-12A, IP-23. Поле: FIELD-007.

## Решение

Продолжение [DECISION-0149](0149-field007-mirrored-altars-and-new-shrines.md).
Каждый из десяти типов циклических алтарей и четырёх святынь получает свой Prop.
Прежние основания остаются: круглое светлое с бирюзовыми боковинами для
позитивных; зубчатое фиолетовое с коралловыми вставками для негативных.
Тип алтаря читается по крупному навершию, тип святыни — по центральной реликвии.
Это заменяет прежний запрет индивидуальных наверший в DECISION-0145.

Внешний контур общий для позитивных и негативных: нейтральное плетение
двух плавных линий с петлями, без символов конкретного эффекта.
Последнее уточнение пользователя отменяет промежуточное предложение двух форм.
Цвет остаётся полярностным: бирюзовый #62b8b7 / коралловый #ed756b.
Внутренняя дуга состояния получает более заметную толщину; charge/rest,
локальный свет, pause/shutdown и цвет основания сохраняют прежний контракт.

## Технический контракт

`altarPresentation.boundaryLobes` — число петель, целое 3–12;
`boundaryInsetFraction` — полный радиальный размах плетения как доля радиуса, 0.01–0.1;
`boundaryWeaveAlpha` — множитель alpha второй линии, 0–1.
Authoring: [field007-altars-v1.json](../balance/field007-altars-v1.json).
Параметры стартового варианта: 8, 0.06, 0.65 соответственно.
Фактический радиус R проходит посередине двух нитей при каждом угле θ:
`r1 = R × (1 + d × cos(n × (θ − π/2)) / 2)`,
`r2 = R × (1 − d × cos(n × (θ − π/2)) / 2)`.
Здесь R — actual radius в wu, d — boundaryInsetFraction (0.01–0.1),
n — boundaryLobes (3–12); `(r1 + r2) / 2 = R` для любого θ.
Например, R=5, d=0.06: в пике нити лежат на 5.15 и 4.85 wu,
середина строго 5 wu; в пересечении обе на 5 wu. Равные толщины stroke
симметричны относительно той же середины. Наружные pixels декоративны:
containment, collider, мини-карта, расстановка и gameplay-радиус не расширяются.
Форма не зависит от типа/полярности; на pause координаты и свет стабильны.

Утверждённые символы: ветер — завиток, исцеление — росток, защита — щит,
сила — песочные часы, удары — молния. Святыни: жизнь — зелёное сердце,
опыт — книга с синим камнем, защита — щит, мощь — песочные часы.
Все конкретные pixels выбраны пользователем; substantive правки после выбора не делаются.
Негативная сила усиливает урон врагов; общие песочные часы — выбранный
парный образ силы, а не утверждение о её gameplay-механике.
