# DECISION-0102 — Невидимый периметр поля

Status: Approved for gameplay trial
Date: 2026-09-29
Related IP: IP-02, IP-23

## Context

После ограничения камеры полем пользователь попросил убрать преграды с границ
карт. По [DECISION-0101](0101-camera-field-edge.md) игрок всё ещё должен
останавливаться у края экрана. Видимый забор по периметру создавался отдельно
от коллайдеров четырёх стен сцены.

## Decision

При создании окружения не рисовать четыре спрайта периметрального забора.
Placeholder-рендереры стен сцены остаются скрытыми, а их player-only коллайдеры
остаются включёнными. Внутренние препятствия и их арт/коллайдеры не меняются.
Параметр `fenceHeight`, использовавшийся только для периметральных спрайтов,
удалён из presentation schema и данных.

## Consequences

Сочетание невидимой физической границы и остановки камеры требует ручной проверки
на всех четырёх сторонах поля. Текстуры пола должны доходить до края кадра без
пустого пространства вне карты.

## Approval

Пользователь 2026-09-29 поручил: «убери преграды с границ карт».
