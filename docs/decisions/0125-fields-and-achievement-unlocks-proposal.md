# DECISION-0125 — Смешанные открытия контента и план поздних полей

Дата: 2026-09-30. Статус: Approved для перечисленных ниже открытий по поручению пользователя «по открытиям утверждаю список» и «делай это». Пакет геометрии/волн FIELD-004…010 остаётся Proposed.

Пользователь утвердил список открытий после уточнений: большинство поздних умений и сетов получают индивидуальные условия, часть остаётся наградой за карты, часть покупается за мета-монеты. Следующий раздел фиксирует точное распределение и цены для реализации. Форму обратной связи добавили в отдельные вопросы; её реализация не входит в эту поставку.

- FIELD-004…010: утверждены роли, тема и сложность: 004 = 2, 005/006 = 3, 007/008 = 4, 009/010 = 5. Подготовлены миниатюры, тайлы земли, по шесть вариантов props на поле, боссы, обычные враги и Путники. Нет production geometry, environment bindings и полных 900-секундных расписаний.

Профиль сохранял прохождения и награду, но не накопленные убийства, урон по умению/герою или заработанную валюту за всю жизнь профиля.

Ни одна строка таблицы не разрешает выпускать произвольные числа в production.

## Принцип открытий

Сохранить последовательность доступа: достижение на поле N может открыть только FIELD-(N+1), если поле N уже доступно. Каждое следующее поле имеет два пути: прежнее прохождение 15:00 либо тематическое накопительное достижение на этом поле. Прохождение остаётся достаточным, поэтому персонаж или умение не может стать обязательной покупкой. Достижения переживают поражение и Quit, но засчитывают только фактические события начатого забега; пауза и повторы применения одного RunId ничего не прибавляют. Уже открытый контент не отзывается.

Утверждённые пороги альтернативного открытия полей:

| Открытие | Альтернатива прохождению предыдущего поля |
|---|---|
| FIELD-002 | Убить 500 обычных врагов на FIELD-001. |
| FIELD-003 | Заработать суммарно 500 мета-монет в забегах FIELD-002, независимо от покупок. |
| FIELD-004 | Нанести 250 000 урона active skills на FIELD-003. |
| FIELD-005 | Убить 1 500 обычных врагов на FIELD-004. |
| FIELD-006 | Нанести 400 000 урона умением SKILL-009 на FIELD-005. |
| FIELD-007 | Убить 2 000 обычных врагов на FIELD-006. |
| FIELD-008 | Нанести 750 000 урона персонажем CHAR-005 на FIELD-007. |
| FIELD-009 | Победить MIDBOSS-008 четыре раза на FIELD-008, в разных забегах. |
| FIELD-010 | Нанести 1 000 000 урона умением SKILL-012 на FIELD-009. |

Уточнения пользователя: открытия **смешанные** — за карту, за индивидуальное достижение и за мета-монеты. Большинство поздних умений и сетов остаются индивидуальными достижениями. Стартовый пул 10 active / 10 passive / 5 sets сохраняется. Распределение позднего пула: из 6 active — 1 за поле, 3 индивидуально, 2 за монеты; из 4 passive — 1 за поле, 3 индивидуально; из 15 sets — 4 за поле, 9 индивидуально, 2 за монеты. Точные ID приведены в утверждённом mapping выше. Разные награды за одну карту допустимы, но прежних автоматических пакетов на весь оставшийся пул не будет.

Другие возможные типы индивидуальных заданий для будущих пакетов: убийства определённого типа врага и успешные забеги заданным персонажем. Они не входят в утверждённый mapping выше. Действующие задания используют уже доступный контент и показывают накопленный прогресс; покупка персонажа не становится скрытой обязательной платой за открытие остальных предметов.

Платные открытия: SKILL-011 за 250 монет после доступа к FIELD-004, SKILL-016 за 200 после доступа к FIELD-002, SET-020 за 200 после прохождения FIELD-001, SET-018 за 400 после доступа к FIELD-004. Покупка сохраняется атомарно и тратит **текущий** остаток монет; накопительный заработок для достижений не уменьшается при тратах. Цена показывается вместе с причиной блокировки. Для платного сета доступна покупка после выполнения его полевого prerequisite; при этом рецепт по-прежнему собирается только при наличии компонентов в забеге. Мета-открытие сета не выдаёт его компоненты и не требует предварительно покупать/открывать каждый из них, чтобы не создавать скрытую двойную плату.

Стартовое умение каждого купленного или открытого героя доступно вместе с героем и не требует отдельной оплаты. Если его самостоятельное достижение ещё не выполнено, покупка героя открывает это умение в общем пуле в той же транзакции. Предложенные платные SKILL-011/016 не являются стартовыми умениями существующих десяти героев. Для персонажей сохранить утверждённые цены; если добавлять достижения, они заменяют только prerequisite покупки, не цену.

## Контракт утверждённой реализации

1. Зафиксировать окончательный список условий для каждого из 70 unlock IDs, цены и локализованные формулировки. Распределить поздние active 1/3/2, passive 1/3/0 и sets 4/9/2 между картой/достижением/покупкой; проверить достижимость от нового профиля графом зависимостей, включая стартовые умения CHAR-004/008/010 и рецепты всех 20 SET.
2. Добавить версионированные агрегаты в профиль и идемпотентное применение per-run статистики вместе с receipt. Считать убийства по подтверждённой смерти с ID врага, урон по реально нанесённому HP с owner skill/character, валюту по сохранённой награде; исключить overkill, friendly damage и повтор RunId.
3. При загрузке старого профиля сохранить купленное и открытое; прошлые забеги без надёжной статистики не реконструировать. Прохождения из `ClearedFields` продолжают удовлетворять прежним путям.
4. Показывать в «Открытиях» путь за карту, индивидуальный прогресс либо цену и понятный lock reason; достижение и покупка выдают уведомление только после успешного сохранения. При одновременно достигнутых условиях открыть один раз.
5. Внести approved mapping в GDD/CD и IP-23/24/25/26, затем production JSON из его owning authoring sources. Добавить migration, catalog и UI проверки; проверить FIELD-002/003 вручную, FIELD-004…010 — per-field load/smoke и реальные забеги. STATUS обновлять по фактическим результатам, не по этому предложению.

## Граница решения по полям

Принцип открытия следующего поля — прохождение предыдущего **или** накопительное достижение на нём — утверждён вместе со списком открытий. Конкретные geometry, enemy mix и численные wave schedules FIELD-004…010 остаются отдельными balance/field packets; таблица их первого нового типа выше пока Proposed.

## Отдельный вопрос в списке решений

До реализации определить точку входа (например, меню или экран результата), обязательные поля, возможность приложить данные забега, адрес доставки и поведение при отсутствии сети. Это отдельный UI/сервисный packet, без изменения правил карт и открытий.
