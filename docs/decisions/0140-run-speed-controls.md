## Решение

В DEV drawer Editor/Development Build доступны 1×, 2×, 3× и 5×; в player HUD и Settings переключателя нет. Non-development UI не принимает speed intents; обычный run идёт на 1×. Значение относится ко всему текущему development-забегу: игровое время, физика, движение и расписание событий идут в выбранном темпе. Нормальная скорость 1× нужна для возврата без перезапуска. Пауза сохраняет выбор и при продолжении восстанавливает его. Завершение или выход из забега возвращает `Time.timeScale` к 1×; новый забег начинается на 1×. На паузе и после завершения управление скоростью недоступно.

Состояние скорости принадлежит `RunModel`, применение глобального времени — `RunController`. UI отправляет намерение через presenter/model и показывает выбранную скорость; он не меняет Unity-время напрямую. Это сохраняет существующий контракт UI и паузы. Значения 1/2/3/5 — варианты интерфейса из запроса, а не параметры конкретной сущности.
