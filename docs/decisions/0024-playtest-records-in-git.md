# DECISION-0024 — Записи ручных прогонов в Git

Status: Accepted

Date: 2026-09-21

Related IP: IP-31, IP-32

## Основание

Пользователь одобрил предложение хранить отдельный Markdown на ручной прогон в docs/playtests, нумерованные наблюдения внутри и выбранный raw report для диагностики: «давай так и делать, внеси нужные корректировки. и в описания процессов тоже».

## Решение

Runtime сохраняет прежний локальный packet в AppData. При обработке отзыва пользователь или AI переносит запись в репозиторий по [правилам](../playtests/README.md) и [шаблону](../playtests/TEMPLATE.md). Markdown становится основной редактируемой записью; исходная цитата и snapshot feedback сохраняются. Выбранный raw JSON копируется без изменений со сверкой SHA256. Автоматический export в Git, commit и upload не добавляются.

OBS-NN связывает наблюдение, диагностику, исправление и повторный прогон; успешный экспорт не закрывает gameplay-замечание. IP execution status остаётся только в STATUS. Разрешение на хранение отчёта не является разрешением на tuning или завершением IP-32.

## Последствия

Отзыв и выбранное evidence доступны другим разработчикам через Git. Процесс требует переноса новых локальных заметок в основную запись и увеличивает репозиторий на размер выбранных reports; массовые exports остаются локальными. Game/Content Design и исполняемые файлы не меняются.
