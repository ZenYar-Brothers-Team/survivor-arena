# DECISION-0083 — Player UI, DEV и переработка layout

Status: Approved — только явно подтверждённые требования ниже
Date: 2026-09-28
Related IP: IP-10A, IP-26, IP-27
Related content IDs: none
Supersedes: player-facing placement скорости из DECISION-0054; трактовку
прототипной раскладки как принятого production layout

## Context

После review первого стилевого прохода пользователь подтвердил стиль
«Полевой фолиант», но указал, что расположение, размеры и пропорции временного
интерфейса не были утверждены. Набор действий и переходы между экранами корректны.
Кнопки скорости предназначены только для разработки. Дополнительно пользователь
потребовал размещать здоровье возле персонажа, а не в отдельной экранной панели.

## Decision

1. Visual language DECISION-0081 сохраняется. Его approval не утверждает текущие
   координаты, размеры, компоновку или объём текста. Production layout проектируется
   по информационной иерархии и настоящему контенту, с переиспользованием runtime
   contracts и действий.
2. 1×/2×/3×/5× — development-only controls. Они принадлежат свёрнутому по умолчанию
   DEV drawer по DECISION-0005, не player HUD или Settings. В non-development build
   controls и их UI intents недоступны; обычный забег идёт на 1×. Lifecycle скорости
   (Running/pause/end/reset) из DECISION-0054 сохраняется для development режима.
3. Основной player HP bar располагается возле персонажа и следует за ним. Он не
   дублируется постоянным player HP bar в верхней/нижней панели. Pause / Build
   продолжает показывать current/max HP. Это правило не меняет boss/Traveler HP.
4. Краткий текст на основных карточках и доступ к полным рецептам сохраняются по
   UI/UX §§7–10. Полное удаление длинного описания пользователь **не утвердил**:
   конкретное on-demand presentation остаётся предметом layout proposal.

## Consequences

Синхронизировать UI/UX, единственное GDD-утверждение о player speed,
DECISION-0054/0081 и scope/checks IP-10A/26/27. Foundation smoke проверяет
геометрию и intents; production visual acceptance требует настоящих иконок,
текста, игрового фона и композиции со всеми действиями Pause.

Предложение раскладки и порядка работы —
[UI layout R2](../implementation/proposals/2026-09-28-ui-layout-r2.md).
Его рекомендации не становятся утверждёнными требованиями из-за ссылки на этот ADR.
Execution status и оставшиеся работы — только [STATUS](../implementation/STATUS.md).

## Approval

Пользователь 2026-09-28: «структура кнопок корректная, переходов между интерфейсами
— это в порядке», «кнопки скорости … только девелоперские», «с точки зрения стиля
меня всё устраивает»; отдельно: «здоровье … где-то возле персонажа».
О длинном описании: «это под вопросом, это ещё можно решить».
