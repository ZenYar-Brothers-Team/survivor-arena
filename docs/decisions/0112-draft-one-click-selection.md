# DECISION-0112 — Выбор улучшения одним нажатием

Status: Approved
Date: 2026-09-30
Related IP: IP-10A, IP-26
Source: запрос пользователя 2026-09-30 о выборе улучшения одним нажатием.
Supersedes: действия с карточками Draft / Book из [DECISION-0086](0086-ui-review-density-and-inspection.md).

## Decision

По прямому запросу пользователя отдельная кнопка «Выбрать» убирается. Клик по
доступной карточке улучшения или сета сразу отправляет выбор. Первоначальное
допущение о Enter/Space на сфокусированной карточке отменено
[DECISION-0118](0118-closed-maps-and-ui-scale.md): выбор выполняется мышью.
В режиме исключения нажатие
карточки исключает вариант; кнопка отмены режима и правила Reroll сохраняются.

Наведение курсора обновляет нижнюю область сетов; прежнее правило о переходе
клавиатурного фокуса отменено DECISION-0118.
Когда курсор уходит с карточек, последняя информация остаётся, включая выбранный
рецепт, пока игрок не наведёт курсор на другую карточку или не сменятся предложения.
Клик по рецепту и прокрутка нижней области не выбирают улучшение. При новом наборе
предложений сначала показываются сеты первой доступной карточки.

Существующее разделение View → presenter intent → runtime и проверка revision
сохраняются. Карточки, которых нет или которые недоступны, не отправляют intent.

## Approval

Пользователь, 2026-09-30: «не будет кнопки выбрать, это отвлекает … при нажатии
сразу выбор, а информация про сет идет при наведении … если уводишь вообще с
блоков, то остается последняя информация по последнему сету»; затем поручил
реализовать выбор улучшения одним нажатием.
