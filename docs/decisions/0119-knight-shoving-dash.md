# DECISION-0119 — рывок Рыцаря-странника: фиксированная длина, толчок, проход сквозь игрока

Status: Approved
Date: 2026-09-30
Related IP: IP-30, IP-13
Related content IDs: TRAVELER-008
Изменяет строку TRAVELER-008 в [travelers-v1](../balance/travelers-v1.md) ([DECISION-0088](0088-travelers-v1.md)).

## Context

Рывок TRAVELER-008 (0.65 × 4 × 0.5 с ≈ 1.3 ед.) слишком короткий и не читается. Пользователь 2026-09-30:
рывок должен быть заметно мощнее, около четверти экрана, стартовать из любой точки, лететь сквозь игрока и
за ним, расталкивать в стороны всех, кого зацепит; предупреждение — шире обычного; вычислительно дёшево.
Пользователь принял допущения ассистента: четверть ширины экрана (камера 5 → ≈ 4.5 ед.), игрок получает один
контактный удар и рывок продолжается, толкаются только обычные враги.

## Decision

`TelegraphedDash` обобщается необязательными полями; старые рывки (ENEMY-007, MIDBOSS-001, боссы) не меняются,
потому что без новых полей действует прежний расчёт «скорость × множитель».

| Поле | Смысл |
|---|---|
| `dashDistance` | фиксированная длина рывка; скорость = длина / `dashDurationSeconds`, `dashSpeedMultiplier` не нужен |
| `dashTelegraphWidth` | ширина линии предупреждения; 0 — тонкая линия по умолчанию |
| `dashShoveRadius` | радиус вокруг тела: обычные враги в нём толкаются, тело проходит сквозь врагов и игрока; 0 — выключено |
| `dashShoveDistance`, `dashShoveSeconds` | отбрасывание толкаемого врага, обязательны при `dashShoveRadius` |

Правила:
1. Рывок стартует по кулдауну из любой позиции; направление фиксируется в начале предупреждения (как раньше).
2. Каждый обычный враг в радиусе толкается один раз за рывок вбок от линии рывка (лёгкая доля вперёд); при
   попадании точно на линию сторона выбирается по чётности `LifeId`. Отбрасывание уважает `knockbackResistance`;
   урона и события попадания нет. Боссы, путники и mid-boss не толкаются.
3. На время рывка коллайдер Рыцаря исключает слои Enemy и Player; препятствия и границы остаются твёрдыми.
4. Игрок получает один контактный удар за рывок с `dashContactControls`, рывок не останавливается.
5. Стоимость: один `Physics2D.OverlapCircle` с переиспользуемым буфером за физический тик, только пока идёт
   рывок (≈ 36 тиков раз в 4 с), под `PerfGuard "EnemyRuntime.DashShove"`; не зависит от общего числа врагов.
6. Рывок с `dashDistance` не масштабируется замедлением: длина фиксирована.

Значения ниже изменены [DECISION-0121](0121-wanderer-flee-distance-and-knight-dash-range.md) (дальность 9, полоса 0.53, длина линии 4).

Значения TRAVELER-008: `dashDistance` 4.5, длительность 0.6 с (≈ 7.5 ед./с), предупреждение 0.7 с, ширина 1.6,
радиус толчка 0.8, отбрасывание 1.5 за 0.25 с, кулдаун 4 с. Значения подлежат подстройке после игрового прогона.

## Consequences

- `EnemyMovementProfile`/`EnemyMovementProfileData`/`FixtureEnemyCatalog`, `EnemyMovementController`,
  `EnemyRuntime` (толчок, проход сквозь, широкая линия), пакет travelers-v1, генерация ProductionTravelers.json, тесты.
- Карточка TRAVELER-008 («один длинный прямой рывок раз в 4 с») остаётся верной, Content Design не меняется.
- Не проверено в игре: читаемость широкой полосы, частота рывка из любой точки, взаимодействие с большими толпами.

## Approval

Утверждено пользователем 2026-09-30 в чате: рывок из любой точки, толкаются только обычные враги, остальные
допущения ассистента приняты.
