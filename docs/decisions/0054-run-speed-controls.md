# DECISION-0054 — Скорость игрового забега

Дата: 2026-09-24. Статус: Approved по прямому запросу пользователя «Сделай в интерфейсе возможность ускорения игры в 2, 3 и 5 раз».

## Решение

В игровом HUD доступны 1×, 2×, 3× и 5×. Значение относится ко всему текущему забегу: игровое время, физика, движение и расписание событий идут в выбранном темпе. Нормальная скорость 1× нужна для возврата без перезапуска. Пауза сохраняет выбор и при продолжении восстанавливает его. Завершение или выход из забега возвращает `Time.timeScale` к 1×; новый забег начинается на 1×. На паузе и после завершения управление скоростью недоступно.

Состояние скорости принадлежит `RunModel`, применение глобального времени — `RunController`. UI отправляет намерение через presenter/model и показывает выбранную скорость; он не меняет Unity-время напрямую. Это сохраняет существующий контракт UI и паузы. Значения 1/2/3/5 — варианты интерфейса из запроса, а не параметры конкретной сущности.

## Проверка

EditMode: допустимые значения и сохранение через паузу; presenter intent и HUD; semantic IDs. PlayMode: кнопка HUD, `Time.timeScale` при выборе, паузе, продолжении и завершении; границы кнопок при 1920×1080 и 1280×720. Полная проверка: Unity 6000.6.0f1, 711/711 `Game.*` EditMode и 27/27 PlayMode, 0 skipped; `TestResults/checks/20260924T180701-450922Z/summary.json`.
