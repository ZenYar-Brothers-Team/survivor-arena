# DECISION-0111 — Увеличение дистанции срабатывания прыжка босса

Status: Approved
Date: 2026-09-30
Related IP: IP-21, IP-23
Related content IDs: BOSS-001…010
Supersedes: только `farDistance` из [DECISION-0073](0073-playtest-2026-09-27-sets-boss-fields-balance.md).

## Decision

По просьбе пользователя дистанция, после которой финальный босс начинает прыжок/телепорт к игроку,
увеличена на 15%: `6.25 × 1.15 = 7.1875` игровых единиц. Игрок должен оставаться дальше этой
дистанции непрерывно 2 секунды. Остальные параметры телепорта не меняются.

Значение применяется к BOSS-001…010 в авторских данных полей и пакета боссов.

## Approval

Пользователь, 2026-09-30: «На 15% увеличим расстояние, разрешённое для игрока, при преодолении
которого босс прыгает на игрока».
