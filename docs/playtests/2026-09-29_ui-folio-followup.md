Статус: проверено автоматически, ожидает ручного просмотра.

а `Obstacle_Fixture` скрывается до композиции поля. Production run по-прежнему
создаёт утверждённое окружение при старте забега.

## OBS-02 — управление мышью по умолчанию

Статус: проверено автоматически.

Цитата: «в настройках управления мышью по умолчанию отключить нужно».

Production default остаётся `false`; PlayMode теперь дополнительно проверяет
и модель Settings, и выключенный Toggle. Уже сохранённый явный выбор пользователя
не перезаписывается значением по умолчанию.

## OBS-03 — угловые рамки и линейные волокна

Статус: исправлено, ожидает ручного просмотра.

Цитата: «угловые рамки как-то странновато выглядят ... лучше убрать»; «штришки
белые тоже странновато выглядят».

Углы, верхние/нижние линии, зернистые штрихи и волокна удалены. Сохранены только
спокойные тональные градиенты. Следующий вариант материальной фактуры будет
отдельной визуальной итерацией после обсуждения шаблона, трещин или складок.

## OBS-04 — прыгающая причина покупки

Статус: проверено автоматически.

Цитата: при переключении «Без постоянных улучшений» строка «Не хватает золота»
на мгновение меняется и возвращается.

Во время промежуточного `Saving` карточка сохраняет предметную причину покупки;
служебная блокировка сохранения только отключает действие. Регрессия использует
задержанный store и проверяет текст до, во время и после записи.
