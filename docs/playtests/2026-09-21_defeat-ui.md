## OBS-01 — после поражения нельзя перезапустить забег

- Состояние: проверено автоматическим regression smoke; повторный пользовательский прогон после исправления не получен.
- Исходная цитата: «проверил, всё в порядке. Только вопрос возможно по другой части,
  нормально что сейчас при поражении все кнопки недоступпны, и нельзя перезапустить забег?»
- Ожидание: после успешного сохранения Results доступны Retry и Main Menu.
- Проверенные факты: regression smoke вызывает lethal damage, получает Lost,
  завершённый save и CanStart=true; обе кнопки enabled. До исправления проверка
  cross-panel ordering падает: Results panel sortingOrder=0, HUD panel sortingOrder=0.
- Диагностика: `UIDocument.sortingOrder` действует внутри одной панели. Независимые
  PanelSettings имели одинаковый default order; созданный позднее HUD и его
  terminal overlay перекрывали Results и принимали pointer input. Сценарий Quit
  этого не показывал, поскольку старый HUD overlay отображается для Lost/Won.
- Исправление: в `Assets/Game/UI/{GameplayUiRoot,CharacterSelectScreen,FieldSelectScreen,
  MetaScreen,AppShellScreen}.cs` явно выставлен также `PanelSettings.sortingOrder`:
  HUD 100, selection 200, Results/Meta 300, app shell/settings 400.
- Регрессия: `DefeatResultsSmokeTests.Defeat_SavedResult_IsAboveHudAndRetryStartsFreshRun`
  проверяет фактические bounds/picking Results, fresh Retry с тем же selection,
  восстановленным HP и повторное поражение → Main Menu.
- Ограничение: прежние smoke отправляли NavigationSubmit прямо кнопке и обходили
  межпанельный hit testing. Сам факт enabled/успешного save не доказывал доступность UI.

Общее сообщение «всё в порядке» сохранено как пользовательский отзыв об остальных
проверенных им функциях; конкретное разрешение/перечень действий не уточнены.
Точный автоматический прогон и состояние IP — в [STATUS](../implementation/STATUS.md).

Повторный полный прогон: Unity 6000.6.0f1, 637/637 EditMode и 22/22 PlayMode, 0 failed/skipped. До исправления новый тест падал на cross-panel order, после исправления проходит.
