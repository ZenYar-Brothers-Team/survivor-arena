# Развитие — отзыв 2026-09-29

Источник: сообщения пользователя в чате, reportId/runId не предоставлены.
Реальные сохранения не изменялись. Execution status — в STATUS.

## OBS-01 — пустые портреты и иконки

Пользователь: «Сейчас все портреты, они пустые полностью»; «И в умениях, и в сетах иконки все пустые».
Диагностика: при Meta прямо из Main Menu `Catalog` оставался null до первого
Character Select; MetaPresenter получал null registry. Предыдущий PlayMode helper
сначала открывал Character Select и поэтому маскировал дефект.
Исправление: Meta загружает существующий cached catalog до OpenShop; tests открывают
production Meta без предварительного выбора персонажа и проверяют sprites.

## OBS-02 — порядок улучшений

Пользователь: «перебросы и исключения — самый низ … сортировку … поадекватнее».
Порядок presentation: урон, скорость действий, размер; здоровье, снижение урона,
регенерация, лечение; движение, радиус подбора, опыт; перебросы, исключения.
Цены, ID и effects не меняются. Порядок проверяется MetaShopTests.

## OBS-03 — скачок строк

Пользователь: «Когда я переключаю галочку на без постоянных улучшений, там дергаются строки».
Диагностика: Render очищал и создавал заново roster/upgrade list на каждом profile
Changed, включая Saving/Ready; появление reason меняло высоту карточки,
а показ/скрытие общей строки статуса менял доступную высоту списка.
Исправление: существующие карточки обновляются на месте, кнопки используют свежий
ViewState, место короткого статуса карточки и общей строки резервируется. Regression проверяет identity,
scrollOffset и положение нижней карточки после переключения галочки.

## OBS-04 — лишний вопросик

Пользователь: «Вопросик у силуэта … уберём … Он и так есть уже возле персонажа».
Убран только overlay на изображении, «?» вместо имени закрытого героя сохранён.

## OBS-05 — кажется, что все умения открыты

Пользователь: «В умениях говорится, что все открыты, хотя нужно, чтобы часть закрыта была».
Проверка реального `profile-meta-r1.json` только чтением: 0 золота, нет пройденных
карт; 10 active, 10 passive, 5 sets, CHAR-001/FIELD-001 — ровно DECISION-0050.
Полностью открытый каталог в этом файле не обнаружен. UI сначала показывает
большую группу начальных 20 умений; поздние группы требуют прокрутки.
Уточнение интерфейса: state filters показывают количества, footer — открыто/всего
в выбранной категории. Для «Умения» fresh profile: 20/30 открыто, 10 закрыто.
Regression проверяет точные исходные ID и 10 записей по фильтру «Не открыто».
Прогресс пользователя и утверждённый список не сбрасываются и не переписываются.

Проверки и снимки записываются в [evidence](../implementation/evidence/2026-09-29-meta-feedback.md).

## OBS-06 — синяя сцена за окнами

Пользователь: «На некоторых интерфейсах фон синий за открытым окном».
Meta/results имели только inset-панель без полноэкранной подложки.
Добавлена непрозрачная тёмно-сливовая подложка, видимая только вместе с экраном.
Пауза и окно выбора улучшения сохраняют игровой фон.

## OBS-07 — изображения всех десяти карт

Пользователь: «В картах почему-то не все до сих пор подключены. Там же для всех десяти карт уже там есть».
Все десять background sprites зарегистрированы, но runtime registry запрашивал
только три, связанные с gameplay definitions. Коллекция теперь отдельно запрашивает
иллюстрации всех десяти meta-карт. Общая проекция открытий/результатов использует
готовый background даже без playable definition. Сохранения и доступность запуска
FIELD-004…010 не меняются. Нового растра и переимпорта art packet нет.
