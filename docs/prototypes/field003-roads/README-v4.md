## Как разнообразятся дороги

1. Случайное число разнесённых внутренних точек 13–18. Координатной решётки нет.
2. Короткое связующее дерево соединяет точки; допустимы цепочки и развилки.
3. От одной до трёх дополнительных связей создают крупные обходные маршруты.
   Запрашиваемое число выбирается случайно; невозможная связь пропускается.
   Так меняется сама топология, а не только положение одной постоянной сетки.
4. Свободные концы выводятся на периметр; дополнительно подключаются подходящие
   узлы до шести выходов. Это сохраняет связность даже когда дополнительные
   связи превратили внутреннее дерево в замкнутую сеть без свободных концов.
5. Повороты без развилок сглаживаются. Короткие кольца и независимые близкие
   сегменты отвергаются; Proposed порог исходного графа 160 для циклов, 60°
   для углов, 13 для разрыва между независимыми осевыми сегментами.

Параметры выше — настройки исследовательского алгоритма, не утверждённые
production числа. Проверка циклов в этой серии дала минимум 160.34–222.69.

## Что считается коротким участком

Измеряется путь по оси дороги между настоящими развилками. Промежуточные
сегменты аппроксимации кривой и поворот дороги не создают новую развилку.
В основной метрике книжные ответвления не являются маршрутом отхода; для
нового приоритета дополнительно считается дробление дороги **всеми** входами
в книжные тупики. Таблица использует именно эту дополнительную проверку.

Вход в книгу не размещается ближе 20 к основной развилке; расстояние между
самими входами минимум 26. Это устраняет короткие промежутки, которые иначе
оставались бы даже у хорошей основной сети. Расстояния проверяются по прямой,
затем длины участков пересчитываются по графу. Книжные ответвления сохраняют
длину 2–4H; округлый конец диаметром 12, зазор поверхностей 3, поворот ±18°.
Длины в этой серии выбираются равномерно, без преимущественного выбора коротких.

## Принятый компромисс и ограничения

Ограничение максимального пути 6H снято по прямому разрешению пользователя.
Средняя длина между основными развилками в этих картах около 5.95–7.90H.
**Длинные участки остаются:** максимальные 17.07–26.19H, прежде всего по
периметру. Книжные входы делят их визуально, но не дают альтернативного пути
для отхода. Этот недостаток не скрывается за метрикой «нет коротких участков».
Дальше можно распределять выходы на периметр равномернее, сохраняя разный
внутренний граф, вместо заполнения всей карты мелкими петлями.

Было 0–2 полных отклонённых графа до выбранной раскладки. Время 1.35–2.29 с
измерено на текущей машине для Python построения/раскладки/метрик, без запуска
процесса, отрисовки PNG и Unity. Это не runtime performance claim.

Геометрия поверхностей проверяется дискретно с шагом 0.5; метрики графа — по
осевым линиям после сглаживания. Контактная геометрия игрока, объединение
широких перекрёстков, рывок/награды/спавн ещё требуют runtime-проверки.
Нулевой результат коротких участков относится к шести схемам, не является
универсальным доказательством для любого seed. Большая серия пока не запускалась.
