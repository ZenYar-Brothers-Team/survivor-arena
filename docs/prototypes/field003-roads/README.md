# FIELD-003: разнообразная дорожная сеть, исследование v2

Эта серия сохранена для сравнения. Последующее поручение пользователя:
цель 15 тупиков и сокращение максимального пути между развилками —
[исследование v3](README-v3.md).

После визуального отзыва «соты» предложена более редкая структура с
приоритетом редкости участков <2H — [текущая проба v4](README-v4.md).

2026-10-01. [Концепт и границы](../../decisions/0137-field003-road-network-concept.md).
Геометрическое исследование без изменения Unity сцены, production данных,
арт-ассетов или игрового баланса. Первый прямоугольный каркас отвергнут пользователем.

## Параметры пользователя

Поле 200×200. Высота экрана H=10 мировых единиц (Gameplay orthographic size 5).
Дороги шириной 0.8H=8; тупики шириной 0.7H=7, длиной 2–4H=20–40.
Игрок ходит только по дорогам. Одна большая дорога возле периметра остаётся.
Цель около 20 тупиков, минимум 10; верхнего лимита книг нет. Каждый округлый
конец содержит одну книгу с ровно одним улучшением. Приоритет — разные
внутренние сети, не максимальная упаковка ответвлений.

Допущения исследования: конец диаметром 12, зазор между независимыми
поверхностями 3; длина от кромки основной дороги до дальней точки конца,
включая расширение. При наклонном входе учитывается расстояние до кромки.

## Как строится сеть

1. Одинаковое периметральное кольцо сохраняет обход по краям.
2. Число внутренних точек случайно 8–13, положения свободные в квадрате
   [32,168]², расстояние между ними больше 32. Координатной решётки нет.
3. Минимальное связующее дерево создаёт короткие связи между точками.
   Получаются разные цепочки, развилки и диагональные направления.
4. Каждый лист дерева выводится на подходящую сторону кольца. Число таких
   выходов меняется вместе с формой дерева. Основная сеть получает обходы;
   её свободные концы не остаются случайными тупиками без награды.
5. Отклоняются графы с углами менее 60°, независимыми сегментами ближе 13
   или циклами по осевой линии короче 160. Выходы на кольцо разнесены на 25.
   Проверка циклов учитывает внутреннее дерево и последовательные дуги кольца.
6. Повороты в узлах степени 2 сглаживаются квадратичными кривыми с отступом 7.
   Узлы степени 3 формируют разветвления; окончания отдельных путей допустимы.

Эти числа — настраиваемые Proposed параметры прототипа. Минимальная длина
исходного внутреннего ребра 25, после сглаживания видимый прямой участок может
стать короче; дорожный сегмент между перекрёстками включает всю цепочку.

## Как размещаются тупики

Кандидаты равномерно выбираются по суммарной длине осей дорог, с обеих сторон.
Направление отклоняется от нормали на случайные ±18°, длина выбирается
равномерно в 20–40. Входы разнесены минимум на 20 мировых единиц: это управление
плотностью, а не лимит количества книг. Концы радиусом 6 должны сохранять
зазор 3 до других дорог/тупиков; пересечение с родительской дорогой допустимо
возле входа в радиусе 10. Выход к границам поля отклоняется.

720 кандидатов на раскладку; принимаются все помещающиеся, без остановки
на двадцатой книге. Бюджет поиска не доказывает максимальную вместимость.
Шесть приведённых seed выбраны заранее, не отфильтрованы по числу книг.
Для гарантии минимума 10 в production понадобится rejection/резервирование.

Поверхности и зазоры проверены на сетке с шагом 0.5. Это дискретная проверка
с погрешностью порядка шага, без радиуса игрока, рывка или Unity коллайдеров.
Topology checks используют исходный граф до сглаживания. Полная навигационная
проверка расширенных поверхностей остаётся будущим шагом.

## Вывод и продолжение

Разнообразие сети совместимо с целью около 20 тупиков при заданных размерах.
Следующий шаг — визуальный выбор направления, затем более широкая серия seed
и проверка движения/подбора наград на road-only карте, до подготовки текстур.
Невозможность собрать все книги из этого исследования не следует.

Первая серия (история): ширины 10/7.5, фиксированные две продольные и одна
поперечная дороги, цель 30. Получено 32/32/31 при предпочтении коротких тупиков.
Она подтверждала вместимость, но не удовлетворяла запросу на разнообразие.
