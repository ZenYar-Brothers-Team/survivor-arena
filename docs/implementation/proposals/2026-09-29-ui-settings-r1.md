# Settings R1 — предложение композиции

Композиция принята пользователем 2026-09-29, перенос в Unity разрешён;
[DECISION-0093](../../decisions/0093-settings-folio-ui.md). Статус — только в STATUS.

Владелец: [IP-26](../modules/IP-26-functional-ui.md). Основание — UI/UX §18,
DECISION-0038/0084, существующие SettingsDefaults и AppShellScreen.
Порядок исполнения и приёмка — только [STATUS](../STATUS.md).

## Композиция для согласования

Один экран в стиле «Полевой фолиант», без вкладок и нового фонового арта.
Слева три ползунка громкости с целыми процентами и две кнопки preview.
Справа режим окна и разрешение, ниже управление мышью, дрожание камеры и
краткие реальные bindings движения/паузы. Заголовок и возврат закреплены;
1080p и 720p в штатном состоянии помещаются без прокрутки. При переполнении
прокручивается только центральная область. Неподдерживаемые настройки не добавляются.

Громкость/галочки применяются сразу; выход сохраняет настройки. Видео применяется
отдельно и подтверждается окном Keep/Revert с 10-секундным real-time countdown.
Escape/timeout возвращают прежний режим, фокус возвращается к выбору режима.
Ошибка сохранения даёт короткое сообщение и Retry, не блокирует возврат.
Возврат из Settings, открытых на паузе, не возобновляет забег.

Полный экран означает существующий borderless desktop, не exclusive fullscreen.
Список разрешений при runtime-переносе читается из службы, не из демо-значений.
В макете desktop = 1920×1080, клавиши показаны примером текущего контракта;
в игре остаются actual bindings. Движение мышью по умолчанию выключено.

## Интерактивный reference

`ui-settings-r1/index.html`; запуск `node docs/implementation/proposals/ui-settings-r1/serve.cjs`,
локально `http://127.0.0.1:4185/`. Переключатели над макетом не входят в player UI.
Есть normal/save-error/safe-video, вход из меню/паузы, два разрешения layout,
изменение процентов, mouse movement, video confirmation и timeout.
Никакие реальные настройки, звук или файлы профиля не изменяются.

После согласования — перенос композиции в существующий Unity shell с сохранением
intents и service ownership; проверки видео, сохранения, audio routing и pause
по IP-26. Этот HTML не заменяет runtime-проверку.

## Проверка макета

Проверены 1080p/720p: центральная область без вертикального переполнения;
720p также без горизонтального переполнения. В браузере проверены выбор оконного
режима, подтверждение с countdown, автоматический откат к fullscreen, Retry Save
и смена подписи движения при включении мыши. Syntax check Node PASS.
Снимки: `ui-settings-r1/preview-1080.png`, `preview-720.png`, `preview-confirm-720.png`.
Unity и реальные настройки не менялись; Unity-тесты для HTML не запускались.
