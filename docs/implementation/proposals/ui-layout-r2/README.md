# Полевой фолиант — композиционный макет R2

Открыть [интерактивный макет](http://127.0.0.1:4179/docs/implementation/proposals/ui-layout-r2/index.html),
пока работает локальный preview server. Исходник — [index.html](index.html).

Это reviewable HTML-layout, не игровая реализация. Уточнения пользователя
зафиксированы в [DECISION-0086](../../../decisions/0086-ui-review-density-and-inspection.md).
Макет не закрывает visual acceptance в Unity. Текущий статус и следующие
работы — только [STATUS](../../STATUS.md).

Финальная композиция одобрена 2026-09-28; последняя область персонажа —
100×96 / 140×120 для 720p / 1080p. Повторный browser run: PASS, 38 captures.
Реализация и проверки Unity описываются отдельно от этого HTML-прототипа.

После игрового review уточнены подписи типов: «Активное»/«Пассивное»/«Сет»,
крупнее и без pill. Это уже внесено в Unity; сохранённый HTML показывает
предыдущую редакцию подписей. Его horizontal card-top и recipe icons остаются
референсом; [диагностика переноса](../../../playtests/2026-09-28_ui-card-layout.md).
Следующие правки owned count/зелёных thresholds, очереди без уровней, увеличенной
шапки и целых процентов проверены в Unity; HTML не является актуальным
функциональным эталоном этих уточнений. Контракт — UI/UX и DECISION-0086.

## Что смотреть

- Бой: HP возле персонажа, 6+6 иконок, XP, countdown, acquired set; без wave/инструкций.
  Слоты и XP-блок на 40% меньше только в 720p; масштаб 1080p сохранён.
- Кнопки паузы на HUD нет; Escape / Space / ПКМ сохранены.
- Улучшение: upgrade / passive / set; краткий эффект выбранного сета рядом
  с уровнями компонентов рецепта, без подробных коэффициентов.
- Книга: отдельное раннее состояние, новое умение, origin и очередь 1 из 2.
- Пауза: увеличенное изображение персонажа и 12 компактных слотов слева.
  Справа «Получены» / рецепты / «Упущены» с общей прокруткой. Рецепты в 3 колонки
  при 1080p, 2 при 720p; полученные и упущенные — icon/name с разделителями.
  Нажатие любого сета открывает небольшую справку с кратким эффектом.
  Скорость — процент от общего default baseline, не от старта выбранного героя.
- Управление: только фрагмент Settings с галочкой Off и клавишами паузы.
- Переключатели review: 1280×720 / 1920×1080, начальный / развивающийся / полный билд,
  плотный фон, отдельный синтетический тест 10 связанных / 20 общих рецептов.

В Draft тело карточки по клику или keyboard activation только закрепляет просмотр.
Получение — отдельной кнопкой «Выбрать» на ней, Banish — «Исключить». У остальных
кнопки disabled и не меняют места. Hover/focus не переключают закреплённый вариант.
В карточке число сетов, снизу список имён/прогресса, краткий эффект и компоненты
выбранного рецепта. Текст эффекта совпадает со справкой Pause.
Счётчик и список только для достижимых, ещё не полученных meta-доступных сетов;
упущенные исключены из Draft/Book. Готовые без получения остаются. Проверка
учитывает число недостающих компонентов относительно свободных слотов каждого
типа и недоступность отсутствующих компонентов (banish/pool/weight fixture).
Owned ниже threshold остаётся достижимым через улучшения, по DECISION-0073.
Scroll/смена рецепта ничего не получают. Нет длинного описания и точных вторичных
коэффициентов: «+1 рикошет. Повторный удар слабее». Статусы короткие, готовность
рецепта отличается от получения сета.

## Происхождение и ограничения

Используются существующие production PNG из `Assets/Resources/Art`, текущие
Alegreya Sans Medium / PT Sans и названия из production catalogs. Изображения
не редактируются, не генерируются, не копируются в новые runtime assets;
подготовка нового art packet и `art_pipeline.py --apply` здесь неприменимы.

Фон собран в HTML из ground/props FIELD-001, Клёпки и enemy-001/002. Это
постановочная сцена на настоящих ассетах, **не capture Unity**, не проверка
реального масштаба камеры, density/VFX или actual-content runtime composition.
Сохранённые старые PNG оказались fixture-снимками; Editor параллельной сессии
не использовался. Перенос поверх живого боя остаётся обязательным отдельным шагом.

HP 84/116, время, XP, level и уровни билда — выбранный пример состояния, не
записанный забег. Draft показывает отдельный момент до получения SET-001,
Pause — после. Book — отдельный ранний пример со свободными слотами. Значения
нового умения в Book, кроме урона, базовые; итоговые character modifiers в макете
не вычисляются. По [DECISION-0085](../../../decisions/0085-ui-damage-percent-presentation.md)
абсолютный базовый урон не отображается; upgrade Камня показывает процентный
прирост из catalog с округлением до целого, а не пару абсолютных чисел.
Краткие тексты — UI-copy proposal на основании полных canonical cards, не изменение
механик. Имена и рецепты читаются из catalogs; summary намеренно не копирует их
технические поля. Проектные JSON не записываются.

Контент review: CHAR-001; SKILL-001/002/003/004/006/007; PASSIVE-001/002/004/008/009/011;
в развивающемся билде также SKILL-013; SET-001/004/006/010/017 и их компоненты.
Только meta-открытые startup-рецепты;
TBD поздних сетов не выдаются за production rules.

В тесте плотности — явно подписанные синтетические рецепты на основе структур
пяти разрешённых сетов, не новый каталог и не утверждение, что одно умение
участвует в десяти таких рецептах. В Pause из 20 записей 12 рецептов,
4 компактных acquired и 4 missed. Обычный развивающийся билд показывает четыре
настоящих рецепта.
Draft stress размножает только отфильтрованные достижимые связанные рецепты;
если таких нет, список остаётся пустым. Pause stress — отдельно заданный тест
геометрии, не результат gameplay eligibility. Обычный полный билд показывает
все три missed startup-рецепта, в том числе без взятых компонентов.
Скорость вычисляется из ProductionCharacterBaseline.json и CHAR-001; 120%
проверяется отдельным тестовым значением, без выдуманного production-персонажа.

Пока не моделируются: случайный reroll/banish pool, награды Book, persistence,
настоящий movement, world-to-screen HP-anchor, boss/Traveler overlays, notifications,
полный каталог и 0/1/2-option Draft. Кнопки игровых действий дают сообщение о
действии, не меняя игру. Нажатие слота умения/предмета Pause показывает только
подпись, не полный inspection state; для сетов реализована краткая справка.
Эти ограничения не скрыты за утверждением о готовности UI.

## Согласование с параллельной работой

[DECISION-0084](../../../decisions/0084-mouse-movement-and-pause-shortcuts.md)
владеет движением/сохранением preference и bindings. Клавиатура — default;
мышь включается галочкой, пауза — Escape / Space / ПКМ. Файлы этой реализации
не редактируются макетом.

В HTML Space/ПКМ переключают только бой ↔ ручную паузу. Они не снимают Draft
или Settings. Space на сфокусированном checkbox/button принадлежит этому control;
двойной pause/submit исключён в mock routing. Это UX regression case для интеграции,
не доказательство аналогичного поведения Unity. У HUD и HP нет pointer capture;
mouse movement над HUD и menu focus проверить в actual composition.

Открытая справка сета закрывается крестиком, кликом снаружи, Escape или ПКМ;
тот же ввод не снимает паузу и не выполняет действие под справкой. Явное закрытие
возвращает фокус на сет. Scroll/resize/смена экрана также закрывают справку.

## Повторный запуск

Из корня репозитория (Node.js):

```powershell
node docs/implementation/proposals/ui-layout-r2/serve-preview.cjs
```

Сервер слушает только `127.0.0.1:4179`, read-only GET/HEAD; раздаёт только preview,
необходимые resource folders и шрифты. Порт можно задать через `UI_PREVIEW_PORT`.
Для просмотра нужен браузер, но внешний интернет не требуется. Прямой `file://`
не рекомендуется из-за browser restrictions на чтение JSON.

Проверка (нужен Playwright; `PLAYWRIGHT_MODULE` может указывать его локальный путь):

```powershell
node docs/implementation/proposals/ui-layout-r2/verify-preview.cjs
```

По умолчанию проверка использует установленный Edge headless с временным чистым
профилем и закрывает его в `finally`. Можно выбрать `UI_PREVIEW_BROWSER=chrome`.
Личные профили, вкладки и настройки не используются. Вывод —
`TestResults/ui-layout-r2-set-info/`: 38 PNG и `summary.json`.

Проверяются загрузка assets, границы/text overflow, размеры HUD в обоих разрешениях,
неподвижность confirm, отсутствие overlap с actions, inspect без выбора,
один явный confirm, фильтрация related recipes и нулевой результат, 10/20-рецептный
scroll, 3/2 колонки, компактные acquired/missed, увеличенный персонаж,
справка для всех статусов сетов и её bounds/keyboard/focus/dismiss без второго
действия, краткий эффект возле уровней компонентов, baseline speed, default
toggle, Escape/Space/ПКМ и двухшаговый Banish. Это browser-only checks.

Результаты проведённого review — [evidence](../../evidence/2026-09-28-ui-layout-r2-mockups.md).
