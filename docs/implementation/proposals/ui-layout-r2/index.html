Как смотреть

Клик по карточке открывает её сеты; отдельная кнопка «Выбрать» подтверждает действие. Внизу нажмите на нужный рецепт: справа его эффект и компоненты. В паузе нажмите на любой сет для краткой справки; попробуйте развивающийся билд или тест плотности. В бою ПКМ, пробел и Esc открывают паузу.

Это HTML-макет, не Unity. Иконки, фон и шрифты — из проекта. Режим «10 / 20» использует явно тестовые рецепты только для проверки вместимости. Настройки и игровые действия не меняют настоящую игру.
