# Читаемые состояния алтаря — варианты по референсам

Дата: 2026-10-02. Approved прямым последующим поручением пользователя «свой вариант индикации предложенный реализуй». Мини-карта, random radius и player-only collider — отдельные approved уточнения DECISION-0145. Текущий статус и проверки только в STATUS.

## Референсы и вывод

- [Guild Wars 2 — Capture point](https://wiki.guildwars2.com/wiki/Capture_point), [игровые изображения PvP](https://guildjen.com/beginners-guide-to-gw2-pvp/): наземная область обозначает место, а ownership/progress имеют явное состояние. Для наших алтарей полезна привязка индикатора к земле около основания; цвета команд и нейтральные категории не заимствуются.
- [Path of Exile — Shrine](https://www.poewiki.net/wiki/Shrine), [игровые изображения святынь](https://duskworld.ru/path-of-exile/shrine.php): физический объект связан с источником эффекта и видимым световым акцентом. Для нашей компактной графики предлагается локальный световой акцент на молнии/реликвии вместо большого постоянного облака; отдельные иконки эффектов не заимствуются.

Следующее — авторская адаптация, а не описание того, что буквально делают эти игры. У наших циклических алтарей исходное gameplay расписание и activation threshold сохраняются; visual state следует ZonePlacement.IsActive, а не вводит новые моменты урона/бонуса.

## Предлагаемый вариант

Большой контур отвечает только за радиус действия. Небольшое постоянное кольцо около основания отвечает за состояние/время; размер не зависит от случайного effect radius. При наземной проекции это эллипс с читаемой толстой дугой; body и collider не анимируются.

| Состояние | Объект | Кольцо у основания |
|---|---|---|
| Ожидает / восстанавливается | Камень виден, молния/реликвия не светится, particles нет | Тусклый полный обод и заполняющаяся дуга до следующего включения |
| Включение | Одна короткая вспышка на переходе authoritative inactive → active | Краткий акцент на полном кольце |
| Работает | Постоянный локальный свет навершия; крупный контур действия ярче | Полное кольцо постепенно опустошается до конца активного окна |
| Завершение / награда | Короткий локальный акцент, затем свет гаснет | Переход в заполнение следующего ожидания |

Святыня: готовая к использованию реликвия слабо светится; дуга заполняется только от фактического charge игрока; награда даёт отдельную короткую вспышку; после неё реликвия гаснет и дуга показывает cooldown. Разница «готова» и «активный cyclic effect» может передаваться постоянным слабым/сильным светом, без новой пиктограммы.

Первый просмотр использует отдельный процедурный радиальный свет над навершием без изменения исходного PNG. Body сохраняет постоянный цвет, поскольку основание обозначает полярность. State ring: cyclic radius 0.55 wu, shrine 0.75 wu, вертикальный aspect 0.45, толщина 0.055 wu; центр совпадает с contact offset основания. Crown glow: radius 0.28 wu, центр на 0.85 высоты body; общий тёплый #FFE6A3, alpha готовой святыни 0.25, работающего алтаря/полного заряда 0.7. Переходная вспышка 0.22 с. Все значения авторятся в altarPresentation и валидируются profile constructor. Отдельная raster-маска может понадобиться при дальнейшей художественной доработке; читаемость первого просмотра проверяется на gameplay scale.

Паузa/terminal: кольца и акценты замерзают по run clock; gameplay state не меняется из UI. Цвет основания остаётся бирюзовым/коралловым при любом состоянии. Не вводятся новые cooldown, типы эффектов, нейтральные алтари или режим единственного активного алтаря.
