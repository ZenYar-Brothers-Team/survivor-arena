# Results R1 — браузерный макет

Запуск из корня репозитория:

```sh
node docs/implementation/proposals/ui-results-r1/serve-preview.cjs
```

Открыть http://127.0.0.1:4182/. Переключатели сверху выбирают восемь состояний
и раскладку 1920×1080 / 1280×720. Предпросмотр масштабируется по ширине окна.
При низком окне сама страница прокручивается; внутри игрового экрана прокрутка
есть только у коллекции справа. Кнопки закреплены вне этой коллекции.

Секция «Новые открытия» демонстрирует сет, умение, персонажа и карту с подписью
типа. Это пример оформления, не состав реальной награды или unlock-пакета.

Все числа и открытия демонстрационные. 20 сетов — искусственная проверка
вместимости, не утверждение о достижимом билде. Повтор сохранения моделирует
успех, остальные кнопки выводят пояснение перехода. Профиль не читается и не меняется.

Использованы существующие шрифты и иконки сетов проекта. Новых игровых растровых
ассетов нет. Сервер только для локального просмотра: GET/HEAD, allowlist путей,
привязка к 127.0.0.1. Runtime Unity этим макетом не изменён.
