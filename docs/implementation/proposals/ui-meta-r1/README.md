# Meta R1 — интерактивный макет

## Полная коллекция открытий — 2026-09-29

Новый отдельный вариант: `node docs/implementation/proposals/ui-meta-r1/serve-unlocks.cjs`,
http://127.0.0.1:4184/ (`unlocks.html`). Старый `index.html` сохраняет принятый
макет улучшений и прежний частичный пример; для review открытий использовать новый адрес.

Коллекция читает все 70 записей production MetaEconomy.json: 10 персонажей,
10 карт, 16 активных, 14 пассивных, 20 сетов. Ничего не записывает в профиль.
Предлагаются фильтры Все/Персонажи/Карты/Умения/Сеты и по состоянию, одна общая
прокрутка; умения/сеты сгруппированы по исходному полю. Показ начального контента
и фильтры — предложение композиции, не изменение runtime/условий открытия.
Закрытые персонажи скрывают имя и цветной портрет, оставляя силуэт и «?»;
условие/цена относятся только к открытию. Номера карт — временная текстовая
альтернатива отсутствующему полному набору thumbnails, не новый утверждённый арт.

Проверено в in-app browser:

- 70 карточек, все 60 изображений загружены после исправления пути CHAR-001.
- 1080p: 3 колонки; 720p: 2. Горизонтального переполнения коллекции нет.
- Фильтр сетов: 20; неоткрытых сетов после FIELD-001: 10.
- Покупка CHAR-002 через Enter: 650 → 550, имя раскрывается, «Бугор — открыто».
- Ошибка покупки: 650 сохраняется, показано сообщение об ошибке без открытия.
- Нет золота + «Можно купить»: явное пустое состояние, не фиктивные карточки.
- Всё открыто: 70/70. Control+End достигает конца списка (3906.86 из 3907 px),
  footer остаётся вне scroll. Pointer input отдельно не заявляется проверенным.
- Снимок `preview-unlocks.png`; страница оставлена открытой для review.

Unity/gameplay/persistence не менялись, тесты Unity не требовались и не запускались.
Новые raster assets, import или bindings не создавались. Приёмка — только STATUS.

Запуск: `node docs/implementation/proposals/ui-meta-r1/serve-preview.cjs`.
Адрес: http://127.0.0.1:4183/ — только loopback, демонстрационные данные в памяти.
Игра, профиль и экономика runtime не изменяются. Перезагрузка восстанавливает пример.

Улучшения: 12 типов, индивидуальные уровни двух открытых героев, покупки,
10/6 уровней, независимая цена b×n, отключение бонусов без запрета покупок,
подтверждаемый сброс за 1000. Сетка прокручивается отдельно от героя и footer.
Размеры раскладки переключаются 1920×1080 / 1280×720 с подгонкой под окно.
Сценарии: обычный, недостаточная сумма, ровно 1000, максимум, отключённые бонусы.

Вкладка «Открытия» — ограниченный образец прокрутки с двумя открытыми героями
и 20 сетами, не полный каталог/достижимый профиль. Карты, условия и покупки
открытий в этом макете не реализованы. Существующие raster-файлы только читаются
по прежним путям, новые изображения/Unity bindings/imports не производились.
После feedback карточки улучшений текстовые: иконки пассивок и символы
перебросов/исключений удалены. Портрет героя и коллекция открытий сохранены.
«Свой путь» и пояснение о персональном действии убраны; шапка и карточки уплотнены.
