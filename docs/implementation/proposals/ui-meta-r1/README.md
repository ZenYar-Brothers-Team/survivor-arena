# Meta R1 — интерактивный макет

Запуск: `node docs/implementation/proposals/ui-meta-r1/serve-preview.cjs`.
Адрес: http://127.0.0.1:4183/ — только loopback, демонстрационные данные в памяти.
Игра, профиль и экономика runtime не изменяются. Перезагрузка восстанавливает пример.

Улучшения: 12 типов, индивидуальные уровни двух открытых героев, покупки,
10/6 уровней, независимая цена b×n, отключение бонусов без запрета покупок,
подтверждаемый сброс за 1000. Сетка прокручивается отдельно от героя и footer.
Размеры раскладки переключаются 1920×1080 / 1280×720 с подгонкой под окно.
Сценарии: обычный, недостаточная сумма, ровно 1000, максимум, отключённые бонусы.

Вкладка «Открытия» — ограниченный образец прокрутки с двумя открытыми героями
и 20 сетами, не полный каталог/достижимый профиль. Карты, условия и покупки
открытий в этом макете не реализованы. Существующие raster-файлы только читаются
по прежним путям, новые изображения/Unity bindings/imports не производились.
После feedback карточки улучшений текстовые: иконки пассивок и символы
перебросов/исключений удалены. Портрет героя и коллекция открытий сохранены.
«Свой путь» и пояснение о персональном действии убраны; шапка и карточки уплотнены.

## Браузерная проверка 2026-09-29

- 12 карточек, все изображения загрузились; compact-сетка имеет внутреннюю прокрутку.
- Layout 1080p — три колонки; compact 720p — две, визуальный просмотр выполнен.
- Сумма 899+100: сброс disabled. 900+100: подтверждение показывает итог 0;
  после подтверждения баланс и вложения равны 0.
- Покупка здоровья L4 за 400: баланс 2450→2050; вложения другого героя остаются 0.
- При выключенных бонусах покупка доступна, пояснение видно.
- Сохранён preview.png; макет открыт в браузере для ручной приёмки.

Это не Unity verification, не проверка сохранения/миграции и не арт-пакет.

720p — 6 карточек (3 полных ряда), остальные доступны прокруткой.
DOM-проверка обоих размеров: горизонтального переполнения карточек нет,
изображений в карточках улучшений 0. Snapshot: preview-dense.png.
В состояниях с дополнительными причинами блокировки высота может увеличиваться;
прокрутка сохранена. Unity не менялся, тесты Unity не запускались.

## Выбор героя миниатюрами

Выпадающий список удалён. Слева имя и поднятый крупный портрет, под ним
трёхколоночная сетка маленьких портретов открытых героев с отдельным overflow-y:auto.
Активный герой выделен золотой рамкой/галочкой и aria-pressed; кнопки доступны
через Tab/Enter. В демонстрационном профиле два героя, поэтому фактического
переполнения списка пока нет; новые герои не выдумываются ради заполнения.
