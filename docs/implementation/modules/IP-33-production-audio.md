# IP-33 — Production audio, общий звуковой язык

## Context

- [Звуковая ведомость и bullet hell policy](../../audio/AUDIO_PLAN.md).
- [UI/UX Design, Audio и Settings](../../UI%20%20UX%20Design.md#audio).
- [DECISION-0038](../../decisions/0038-settings-and-field-difficulty.md): Master/Music/SFX, preview, пауза и завершение забега.
- FIELD-001 startup F1-01/04/06/07/08: уже реализованные события умений, врагов, боссов, XP, предметов и composition root. IP-26/F1-03 обеспечивает утверждённый settings subset; полный IP-26 не является prerequisite этого среза.

## Scope

Первый срез интегрирует выбранные CC0-клипы через общий каталог и аудиообработчик событий забега. Музыка обычного боя и одна тема босса переиспользуются для всего roster; атмосфера FIELD-001 звучит только на этом поле. Каждый новый ID босса не создаёт музыкальную дорожку. Снаряды не владеют источниками звука; поток обычных попаданий, смертей и XP агрегируется по времени и числу голосов. Пользователь поручил AI выполнить импорт, код, проверки и документацию; художественный отзыв даётся после прослушивания в игре.

## Acceptance

1. Каждый используемый клип импортируется в Unity и имеет запись с исходным именем, URL, автором, лицензией, преобразованием и SHA-256. Ссылки каталога разрешаются; неиспользуемые клипы не поставляются.
2. Master применяется один раз; Music и SFX управляют своими источниками. Preview Settings продолжает работать на паузе. Музыка и тихая атмосфера продолжаются на паузе; gameplay SFX приостанавливаются, UI сигналы драфта работают; завершение забега останавливает gameplay SFX и атмосферу.
3. Одновременно доступно максимум восемь голосов рядового боя, два резервных голоса для важных/критических сигналов и два UI голоса. На одну семью и на общий поток рядового боя действует cooldown в реальных секундах, независимый от 2×/3×/5× скорости симуляции. Потерянные события не ставятся в очередь.
4. Подключены музыка меню/боя/босса/результата, UI навигация, XP/level-up/драфт, активация умения, попадание/смерть обычного врага, урон игрока, Book/Potion, появление/фаза/попадание босса. Победная тема запускается по `RunOutcome.Victory`, а не по убийству босса.
5. Проверка Unity включает загрузку каталога и production PlayMode smoke; полный затронутый набор проходит. Ручное прослушивание обычной и плотной волны, босса, драфта/паузы и 5× нужно для художественной и громкостной приёмки.

## Out of scope

- Отдельная музыка для каждого босса или каждого поля.
- Новые gameplay-правила, урон, баланс и телеметрия.
- Покадровый звук снарядов или каждого тика эффекта.
- Специальные сигналы для низкого HP и конкретных опасных атак до отдельного event contract и прослушивания; эти требования остаются в общей звуковой ведомости.
