# IP-21 — Production Final Bosses и Mid-bosses

Оперативный статус и evidence хранятся только в [`STATUS.md`](../STATUS.md#ip-21--production-bosses-и-mid-bosses).

## Цель

Реализовать BOSS-001…010 и MIDBOSS-001…010 как data-driven encounters.

## Зависимости

IP-13, IP-15; approval целевых BOSS/MIDBOSS IDs.

## Scope

Approved boss cards; HP/size/contact damage; phases; attack/movement patterns; recommended field metadata where approved.

## Context

- Game Design: «Враги, волны, элиты и боссы», «Структура забега и условия завершения».
- Content Design: полные карточки целевых BOSS и MIDBOSS IDs.

## Acceptance criteria

Каждый Approved boss/midboss соответствует card patterns; final boss death never causes victory; phase behavior triggers at stated thresholds.

## Проверки

Per-ID phase smoke; timer interactions.

## Out of scope

Field binding, если он всё ещё Draft/TBD — IP-23/IP-24.
