# Срез FIELD-002: реализация (F2-01…F2-05)

Дата: 2026-09-26. Основание: [DECISION-0063](../../decisions/0063-field002-slice-v1.md),
данные [field002-v1](../../balance/field002-v1.md). Статус — только [STATUS](../STATUS.md#field002-execution).

## Что сделано

- **F2-01:** `EnemyDashVolleyProfile/Controller` — кольцо в конце рывка и повторный залп каждый N-й рывок ниже
  порога HP; JSON `dashEndAttack`/`dashEndRepeat`, масштаб волн, `EnemyRuntime` выпускает снаряды.
- **F2-02:** BOSS-002 и MIDBOSS-002 в `ProductionBosses.json` (карточные числа, тайминги пакета, телепорт BOSS-001
  у BOSS-002). Каталог боссов проверяет уникальность ID, а не хука: каждое поле связывает своих боссов, хуки проверяет
  разрешение поля. Тела — явные placeholders (art gate).
- **F2-03:** поле FIELD-002 в `ProductionFields.json` (окружение на той же сцене, пул 9 врагов, свои боссы/шкала/
  расписание), 100 авторских препятствий в `ProductionFieldEnvironmentPresentation.json`. До арта тракта камни и
  колонны рисуются утверждённым спрайтом пня FIELD-001; коллайдеры строго по прямоугольникам пакета.
- **F2-04:** `ProductionWaveTimelineField002.json` — 24 фазы с модификаторами поля 2, ENEMY-008 в первой волне;
  каталог регистрирует шкалы всех полей.
- **F2-05:** `TravelerScheduleDefinition.Draw` с поиском роли — роли в забеге не повторяются, число ограничено числом
  ролей; расписание FIELD-002 на общем пуле с rank 2. При нынешних трёх Путниках (по одному на роль) выбор совпадает
  с прежним.
- Генератор синхронизирован с утверждённым артом set-снарядов (коммит b595f9e): без этого перегенерация затёрла бы
  его привязки в `ProductionSetAttacks.json`.
