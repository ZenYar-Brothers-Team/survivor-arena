# Results R1 — проверка браузерного макета, 2026-09-28

Объект: `proposals/ui-results-r1/index.html`. Порядок и gates — в STATUS.

В браузере проверены 8 состояний × 2 раскладки: победа, поражение, без сетов,
20 сетов, сохранение, ошибка сохранения, прерванный и остановленный забег.
DOM-геометрия: панель внутри игрового viewport, footer внутри панели,
факты и награда без переполнения во всех 16 сочетаниях.
Коллекция из 20 сетов имеет собственный scroll в обеих раскладках;
в 720p клавиша End доводит до конца (402.29 из 403 CSS px).
Все иконки длинной коллекции загрузились. В консоли нет error/warn.

Saving/error: обе кнопки перехода выключены, награда «—», открытия скрыты.
Клавиатурная активация «Повторить сохранение» возвращает демонстрационные
240 монет и доступность действий. «Ещё забег» показывает тот же выбор персонажа
и поля, «В меню» — соответствующий переход. Реальных переходов и записи нет.
Автоматизированный mouse-click по повтору в масштабированном/прокрученном
предпросмотре не активировал кнопку; проверка выполнена через Enter. Поэтому
полная mouse-interaction acceptance не заявляется.

Unity и профиль не изменены; Unity-тесты для HTML-макета не запускались.
Предыдущие результаты Entry R1 не являются проверкой будущего Results runtime.
