## Реализация

- `TravelerShapeSprites` создаёт три общих процедурных контура при первом использовании: барьер с лепестковым штрихом и шестью рунами, восемь лепестков для волн лечения, двенадцать вытянутых огоньков для ускорения. Размер 256² сохраняет тонкие линии на игровой дистанции; после генерации текстуры нечитаемые и не обновляются по кадрам.
- `TravelerPulseEffect` использует прежние четыре pooled renderer. Щит медленно вращает наружный узор, вращает второе кольцо обратно и меняет масштаб наружного только в пределах исходного радиуса. Лечебные волны сохраняют три фазы расширения; заливка ослаблена. Телепорт остаётся простым кольцом.
- `EnemyProtection` хранит начало каждого ускорения вместе с его deadline для полосы оставшегося времени. Сильнейший бонус по-прежнему определяет движение, источники не складываются. `SlowStatusPresentationDirector` за один проход по живым врагам показывает лёд/замедление и новый `SpeedStatusPresentationRuntime` независимо друг от друга. Молния и полоса ускорения создаются один раз на визуале затронутого врага; цвет, масштаб и период заданы валидируемым presentation JSON. На паузе используется неизменное время забега. При истечении, смерти, despawn и shutdown слои гасятся.
- Обе полосы имеют одинаковую ширину и высоту. Когда действуют оба состояния, жёлтая полоса касается нижнего края синей без наложения; когда действует только ускорение, она занимает верхнее место.

Предпросмотр композиции: `TestResults/traveler-aura-preview.png` (локальный, не runtime asset). Растрового импортируемого арта нет: `art_pipeline.py` и пакет source/master/runtime PNG к этому процедурному изменению не применяются. В `Assets` добавлен только C# источник с Unity `.meta`.
