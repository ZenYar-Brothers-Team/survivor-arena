# FIELD-003 «Пограничные руины»: реализация

Дата: 2026-09-27. Основание: [DECISION-0067](../../decisions/0067-field003-v1.md), данные
[field003-v1](../../balance/field003-v1.md). Статус — только [STATUS](../STATUS.md).

## Что сделано

- **Генератор** (`scripts/generate_field001_content.py`) читает утверждённый `field003-v1.json` и выпускает:
  - поле FIELD-003 и окружение `FIELD-003-ENVIRONMENT` в `ProductionFields.json`, на той же сцене Gameplay. Миниатюры
    пока нет, карточка выбора показывает текст;
  - `ProductionWaveTimelineField003.json` — 24 фазы с модификаторами третьего поля и ENEMY-010 в первой волне;
  - `FIELD-003-TRAVELERS` — общий пул, ранг 3;
  - `FIELD-003-PRESENTATION` — 107 авторских препятствий. Стены рисуются утверждённым плетнём FIELD-001, завалы —
    валуном FIELD-002, земля — FIELD-001.
- **Каталог.** `FixtureRuntimeContentCatalog` регистрирует шкалу волн FIELD-003.
- **Разблокировка.** Открытие FIELD-003 после FIELD-002 уже было в `MetaEconomy.json`.
- **Вертикальные стены.** `FieldEnvironmentArtRuntime`: для вертикального прямоугольника плетня (высота больше ширины)
  спрайт поворачивается на 90° и масштабируется по длине. Коллайдер точно повторяет прямоугольник пакета. Раньше спрайт
  масштабировался по ширине, и вертикальная стена 0.8×3.2 рисовалась крошечным плетнём.
- **Карточки** ENEMY-010 (контексты FIELD-003…008) и FIELD-003 (enemy pool, пул Путников) синхронизированы при approval.

  - граница живых врагов 248;
  - гончие следопыта и капканы ловчего.
- Арт руин, воды, миниатюры и тел двух боссов — per-ID gates.
