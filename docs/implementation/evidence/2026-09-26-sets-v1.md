# Сеты SET-002…020: реализация (IP-19)

Дата: 2026-09-26. Основание: [DECISION-0061](../../decisions/0061-sets-data-v1.md),
данные [sets-v1](../../balance/sets-v1.md). Статус — только [STATUS](../STATUS.md).

## Что сделано

- **Данные.** `scripts/generate_field001_content.py` читает утверждённый `sets-v1.json` и генерирует 15 сетов
  в `ProductionSets.json` и 6 шаблонов set-атак в `ProductionSetAttacks.json` (SET-013/015/016/018/019/020).
  Пять сетов baseline и шаблон SET-017 семантически не изменились (сравнение с HEAD).
- **Новый вид эффекта `SkillMechanics`** (`SkillMechanicBonus`, Game.Progression) — skill-specific бонусы, которых
  нет среди stat-каналов: скорость снаряда без роста дальности, обратный путь/отскоки, цепь (цели, jump range,
  падение урона), пробивание, скорость вращения орбиты, урон/радиус только взрыва, подмена каждого N-го снаряда.
  Путь тот же, что у SkillTransform: `SetEffectAbility` → `ISetEffectHost` → `PlayerActiveSkillSetRuntime` →
  снимок `ActiveSkillActivation` → executor. Бонусы нескольких сетов складываются; два владельца подмены
  одного умения — ошибка данных.
- **Executor:** снаряды (скорость/lifetime, пробивание, взрыв, отскоки диска), бумеранг (возврат: урон
  аддитивно к карточке, скорость), цепь, мина (радиус/урон взрыва вместе со вторичным), орбита.
- **SET-008 «тяжёлый мусор»:** каждый 8-й снаряд Разбрасывателя (счётчик на экземпляре умения) — радиус ×2,
  остановка ×1.5, сквозное пробивание, взрыв при остановке. Урон взрыва берётся без skill-specific set-трансформ
  (`SetTransformDamageNormalization`), поэтому +50% SET-015 его не усиливает (G-05).
- **SET-013** — `ChainEffect.FanOut`: удар по первой цели и одновременные разряды к ближайшим в радиусе, без прыжков.
- **SET-015** — `RewardProc` на подбор Зелья (существующая связка IP-28) с шаблоном области вокруг игрока;
  `RewardProc` теперь тоже может масштабироваться size/range, как задано в пакете.
- **Визуал:** set-атаки SET-016/018/019/020 используют спрайты копья, сферы, льда и камня (размер следует
  collision radius); SET-013 — процедурные дуги, SET-015 — процедурное кольцо (`SkillWorldEffects.json`).
  Set-оттенок спрайтов не реализован — framework не поддерживает tint для снарядов.
