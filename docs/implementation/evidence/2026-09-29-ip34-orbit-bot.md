# IP-34 AB-10 — wide-arc XP bot, 2026-09-29

`orbitExperience/v1` is a third, separately selectable movement policy. It
keeps one visible XP target and a persistent waypoint. When the direct path
has a hazard, it compares two arcs displaced sideways by
`arcOffsetWorldUnits` (2–10 world units, example 6). Arena bounds and
player-only obstacles invalidate routes. The current implementation checks
up to six distinct nearby XP positions and skips a candidate without a
viable route. The original `safePickup/v1` and `experienceFocused/v1`
coefficients remain unchanged. `randomLegal` draft and gameplay rules are
unchanged.
