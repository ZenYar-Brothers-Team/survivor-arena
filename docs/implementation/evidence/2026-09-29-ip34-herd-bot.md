# IP-34 AB-11 — herd-and-return bot, 2026-09-29

`herdLoop/v1` is a separately selectable, experimental movement policy. With
sparse enemies it forages for visible XP. It enters Lure only when a nearby
crowd contains at least three enemies obstructing the corridor to a distant
XP pickup; then it moves away, sweeps tangentially, and returns to a remembered
XP bank. The policy sees only the current observation. It samples short-term
threat exposure and increases its danger penalty at low HP. Existing bot
profiles and gameplay rules are unchanged. The sidecar records decisions by
Forage/Lure/Sweep/Collect mode.
