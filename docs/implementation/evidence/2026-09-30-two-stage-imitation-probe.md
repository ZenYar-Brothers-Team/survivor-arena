# 2026-09-30 — двухэтапная offline-проба движения

По поручению пользователя после [новой человеческой записи](2026-09-30-human-action-change-session.md)
проверена модель из двух решений: `change/keep`, затем направление при `change`.
Это исследование на тех же четырёх завершённых human JSONL (11 687 samples),
без изменения игровой policy. Пятый административно прерванный забег отвергается
скриптом и не использовался.

Воспроизводимый инструмент — `scripts/balance/probe_two_stage_imitation.py`.
Каждый раз один забег целиком удерживается вне обучения. Обе модели —
`HistGradientBoostingClassifier(max_iter=90, max_leaf_nodes=15,
l2_regularization=2.0, random_state=34)`; вторая обучается только на реальных
сменах направления. При предсказании старое направление исключается из её
распределения. Смена выполняется, только если совместная вероятность нового
направления выше вероятности оставить прежнее. Порог не подбирался по
удержанному забегу. Выход:
`TestResults/imitation-human-a568e9d-20260930/two-stage-evaluation.json`,
с SHA256 входных файлов и `selectedForGame=false`.

| `59081999…` | 65,45% / 65,34% | 6/626 | 0,563 | 61,98% |

| `eb28627a…` | 64,85% / 64,70% | 13/1 362 | 0,556 | 60,65% |

Всего предсказано лишь 74 смены при 3 870 реальных. На объединённых held-out
предсказаниях accuracy 66,929% против 66,886% baseline — выигрыш 0,043
процентного пункта, при провале на одном из четырёх забегов. 37/3 870 реальных
смен угаданы. Эти цифры не дают полезного улучшения управления. Oracle timing
показывает только диагностическое качество выбора направления, не результат
игровой модели: момент смены при нём подставлен из ground truth.

Решение: не сериализовать и не подключать эту модель к игре. Closed-loop прогон
не нужен для текущего кандидата. Данные позволяют лучше учить выбор направления,
но момент человеческого решения почти не выводится из текущего одиночного
snapshot (`previousAction`, положение, угрозы, XP и препятствия). Следующий
исследовательский scope — проверить временной контекст, затем оценивать новые
policy в замкнутом игровом цикле по наблюдаемым результатам: выживание, XP и
уровень. Внутреннюю цель игрока эти записи не содержат; waypoint нельзя
объявлять её измерением. Это гипотеза, а не утверждённое изменение игровой policy.

Проверки: `python -m unittest discover -s scripts/balance -p 'test_*.py'` —
31/31 PASS, включая две проверки decision rule и отбраковки administrative abort.
Unity tests не запускались: runtime и content не изменялись.
