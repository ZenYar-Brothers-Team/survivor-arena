## Реализация

- `ProductionEnemies.json` и `ProductionPickups.json` генерируются из baseline
  (`scripts/generate_field001_content.py`; генератор отказывает, если timing/aim/
  dash/reposition политика baseline не выражается runtime-полями).
- Framework: `EnemyAttackCadence.WindupStartToStart` (первый замах после cooldown,
  start-to-start, aim snapshot); `EnemyMovementKind.DistanceReposition` +
  `EnemyMovementPhase.Repositioning` (лучник). Fixture поведение по умолчанию
  не изменилось. Исправлен найденный тестом дефект каталога: «нейтральный» профиль
  для неиспользуемых полей теперь берётся из `Seek`, а не конструируется для
  нового kind с неполными данными.
- Каталоги: `ProductionEnemyCatalog` (только `ENEMY-###`), `ProductionPickupCatalog`.
- Визуал: тела ENEMY-001/002 (production sprite ID + motion профили villager/
  courier), снаряды ENEMY-004 (производная approved камня) и ENEMY-005
  (процедурная стрела) через `art_pipeline.py`, manifest `Prepared`.
  **Открытый art gate:** тела ENEMY-003/004/005/007 — нужен генератор изображений;
  до этого runtime показывает явный placeholder.
