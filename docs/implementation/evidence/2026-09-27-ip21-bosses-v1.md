# IP-21: боссы BOSS-003…010 и MIDBOSS-003…010 (bosses-v1)

Дата: 2026-09-27. Основание: [DECISION-0066](../../decisions/0066-bosses-data-v1.md), данные
[bosses-v1](../../balance/bosses-v1.md). Статус — только [STATUS](../STATUS.md).

## Что сделано

- **F1 «Зона», F2 «Луч», F3 «Призыв».** Чистая модель `BossHazardField` для одной жизни босса: размещение, заполнение,
  удар, горящая земля, лучи с поворотом, метки призыва. Профили `BossZoneProfile`, `BossBeamProfile`,
  `BossSummonProfile`; слот цикла `BossSpecialAttack` с таймером `BossSpecialTimer` (та же каденция
  «старт замаха → старт замаха», что у снарядов).
  - Зоны: AtPlayer, AroundPlayer (разнесённые круги), Trail (каждый круг ложится туда, где игрок в момент появления),
    AroundSelf, SafeCircles (бьёт вне всех кругов).
  - Лучи: углы от направления на игрока, снятого в начале предупреждения; урон один раз за активацию; поворот
    за время действия.
  - Призыв: метки по кругу вокруг игрока; лимит живых считает и ещё не вышедших.
- **`BossEncounterRuntime`** запускает особые атаки по событию `EnemyRuntime.SpecialRequested` и наносит урон игроку.
  - Урон приходит источником `EnemyProjectile` с id слота.
  - Смерть босса сразу снимает его зоны, лучи и метки.
  - Призванные враги — обычные (`EnemyCategory.Ordinary`), вне лимита обычных врагов. Награды — через
    `EnemyRewardSink` (XP и подбираемое), как у волнового спавнера. Переживают босса и убираются в конце забега.
  - Отрисовка — `BossHazardPresentation`, только процедурные формы (круг, кольцо, луч), цвета из JSON.
  - Строка наблюдения показывает число зон, лучей и призванных.
- **Расширения E1…E6:**
  - E1: `EnemyAttackProfile.FollowUps` — повтор залпа от направления основного; шаг цикла не завершается, пока повтор
    не вышел.
  - E2: веер взрывных снарядов.
  - E3: `BossPhaseDefinition.MovementOverride` — рывки фазы подменяются только между рывками.
  - E4: `EnemyDashVolleyProfile` — несколько действий после последнего рывка серии, ориентация
    TowardPlayer/AwayFromDash/Self, задержка, замена ниже порога HP. Прежние кольцо и повтор BOSS-002/MIDBOSS-002
    сохранены.
  - E5: `HoldAttacksDuringDash` — цикл атак стоит, как на паузе, во время подготовки и самого рывка.
  - E6: `WindupMovementMultiplier`.
- **Данные.** `scripts/generate_field001_content.py` читает утверждённый `bosses-v1.json` и выпускает 16 encounters
  в `ProductionBosses.json`.
  - Одинаковые слоты (крест MIDBOSS-005 дважды в цикле) выпускаются один раз.
  - Технические числа отрисовки, не входящие в пакет: цвета семейств, вспышка удара 0.45 s (как у телепорта),
    тик горящей земли 0.5 s. Урон горения в секунду — по пакету.
  - `ProductionBossCatalog` получает обычных врагов для призыва.
- **Каденция и случайность.** Серия BOSS-006 с разбросом получает детерминированный `System.Random` по id слота.
