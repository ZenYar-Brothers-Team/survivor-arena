- `Assets/Resources/Content/Passives/ProductionPassives.json` генерируется
  `scripts/generate_field001_content.py` (явная таблица baseline field → runtime
  channel; неизвестный канал — ошибка генерации; имена из заголовков карточек CD).
- `ProductionPassiveCatalog` — общий mapping `FixturePassiveCatalog.Load`, только
  `PASSIVE-###`, обязательная approved иконка. Новых stat channels не потребовалось:
  все 12 каналов уже поддержаны `CharacterStatModifier`/`CharacterStats`
  (DR cap 99%, KB resistance clamp 0…1, MaxHP ratio, replace-by-key).
- World sprites для passive не нужны; иконки 10 ID — уже approved и зарегистрированы.
  Gameplay composition остаётся на fixture до F1-03/F1-08.
