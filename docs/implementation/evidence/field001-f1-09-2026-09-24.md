# F1-09 — доведение и приёмка FIELD-001: подготовка (без прогонов)

Дата: 2026-09-24. Scope: `field-001-start-R1`, packet F1-09 (IP-27/12A/31/32).
Статус — только [STATUS](../STATUS.md#field001-execution).

F1-09 по определению ([milestone](../milestones/FIELD-001-start.md#f1-09)) требует
реальных 15-минутных прогонов в Unity, performance-измерений на reference machine и
отдельной приёмки пользователем целостного ощущения карты. В облачной среде этого
продолжения нет Unity Editor ([DECISION-0054 §2](../../decisions/0054-field001-autonomous-execution.md#2-проверки-без-unity)),
поэтому ни один сценарий ниже не исполнялся и результаты не заявляются.

## Предусловия перед первым прогоном

1. При закрытом Editor: `python scripts/check_project.py --scope full` — перевод
   F1-01…08 из `Implemented` в `Verified` (или список падений для исправления).
   Ожидаемо Unity-only: `ProductionSkillPatternTests`, `ProductionRunSmokeTests`,
   `ProductionFieldContentTests.ProductionComposition_…` и visual-resolve тесты.
2. Первый запуск Play создаёт новый production профиль `profile-v1.json`
   (изолированный от прототипного `fixture-profile-v1.json`).
3. Art gates ([список](../../art/field001-open-art-requests.md)) не блокируют прогон:
   тела без изображения показаны явными placeholders; их замена — отдельно.
