## Реализация

- **Данные.** `Assets/Resources/Content/ActiveSkills/ProductionActiveSkills.json`
  (10 ID × L1–6) генерируется `python scripts/generate_field001_content.py` из
  `docs/balance/field001-baseline-v1.json`; `--check` ловит ручной дрейф.
  Загрузка — `ProductionActiveSkillCatalog` (общий DTO mapping fixture-каталога,
  только `SKILL-###`, обязательная иконка).
- **Framework-дополнения** (нейтральны для fixture):
  `OrbitEffect.Persistent` + `PersistentOrbitState` (swept capsule hits,
  per-blade/target cooldown, сохранение фазы при upgrade, lease без refresh);
  `AreaEffect.ExpansionSeconds` + `ExpandingAreaState` (фронт, hit-once, radial KB);
  `StrikeEffect` (telegraph, deferred distinct random target каждого удара, skip без
  цели); `SkillWorldEffectPresenter` (pooled процедурные ring/segment/disc, пауза,
  Clear на terminal). Draft preview не показывает refresh persistent orbit как cooldown.
- **Презентация.** Иконки 10 ID и снаряды 001/003/006/014 — уже approved;
  снаряды 002/005/013 — производные approved иконок через `scripts/art_pipeline.py`
  (manifest `Prepared`); SKILL-004/007/010 — процедурные эффекты
  `Content/Presentation/SkillWorldEffects.json` (manifest `Procedural`, `Prepared`).
  `GameplayCompositionRoot` передаёт профили executor; gameplay пока на fixture
  каталоге — production binding в F1-03/F1-08.
- Новые `.meta` созданы в формате репозитория (свежие GUID) для C#, JSON, PNG
  (копия projectile import template) и папок; Unity может переимпортировать PNG.

## Unity-прогон 2026-09-24

Пользователь запустил `check_project.py --scope full` на ветке FIELD-001 (Unity
6000.6.0f1): EditMode 706/709, PlayMode не запускался после FAIL EditMode. Три падения:

- `ProductionSkillPatternTests.ExpandingArea_DamagesOnlyWhenFrontArrives_OncePerWave` —
  **дефект**: волна, запланированная внутри tick, стартовала с радиусом 0 и
  продвигалась только со следующего кадра, т.е. фронт зависел от длины кадра.
  Исправление: при старте фронт продвигается на overshoot задержки текущего tick
  (`SceneActiveSkillEffectExecutor.BeginExpandingArea`); тест — регрессионный.
- `FixtureRuntimeContentCatalogTests.Create_BuildsOneValidatedRegistryForEveryRuntimeDefinition` —
  устаревшее ожидание: общий файл motion profiles теперь содержит и production
  CHAR-001/ENEMY-001/ENEMY-002; тест проверяет точный набор ID.
- `CategoryImportTests.ApprovedSkillProjectiles_AllUseTheWorldProjectileImportProfile` —
  устаревшее ожидание 5 → 8 PNG (три производных снаряда F1-01); import-настройки
  новых PNG проверяются этим же тестом при повторном прогоне.
