# 2026-09-30 — первый кандидат обучения движения по человеческой записи

По поручению пользователя обучен **offline кандидат**, без изменения игровой
policy. Входы — три завершённых человеческих `demonstration.jsonl` из
[`human session`](2026-09-30-human-demonstration-session.md), 14 016 samples;
четвёртый пустой `.partial` исключён. Валидатор повторно проверил каждый файл:
controller=human, footer clean, 0 truncated/incomplete; SHA256 каждого записан
в локальном `model.json` и совпадает с human session evidence.

Команда: `python scripts/balance/train_imitation.py <три JSONL> --output
TestResults/imitation-human-v1`. Код и параметры: девять направлений включая
остановку; `human-movement-features-v1` (предыдущая команда, положение/скорость,
здоровье/время, ближайшие враг/XP и локальные секторы угроз/XP/препятствий);
StandardScaler + MLP 48/24 tanh, `random_state=34`, early stopping. Python
3.13, NumPy 2.3.2, scikit-learn 1.6.1. Для оценки каждый забег полностью
удерживался вне обучения; финальный кандидат обучен на всех трёх. Выходы локально
в `TestResults/imitation-human-v1/`: `evaluation.json`, `model.json` (SHA256
`998df1bec0e78f010981a48f5c3b57c8c764b047e8900ed69e44b40e0dddab40`).

Высокая общая точность обманчива: `previousAction` — команда предыдущего
физического шага, а человек меняет её редко. Простое повторение превосходит
модель на каждом held-out забеге. Эксперимент с пятикратным весом samples смены
направления поднял их распознавание примерно до 2–17%, но снизил общую
точность до 74–87%; без предыдущей команды общая точность также ниже.
Это диагностические пробы, не выбранные модели.

**Решение по кандидату:** не подключать его к игровому боту. Offline метрика
не подтверждает качество движения в замкнутом игровом цикле; нет проверки
выживаемости, XP и устойчивости на новой двухстрельной версии. Изменений
баланса, production content и игровых контрактов нет. Следующий reviewable
scope — собрать новую независимую человеческую запись на актуальной сборке,
отделять решения о смене направления от удержания клавиши и оценивать
кандидата в игре до выбора policy.

Проверки: `python -m unittest discover -s scripts/balance -p 'test_*.py'`:
28/28 PASS. Первая попытка в sandbox не смогла работать с временными папками;
успешный повтор запущен с разрешённым доступом. Unity tests не запускались,
поскольку игровой код и content не менялись.
