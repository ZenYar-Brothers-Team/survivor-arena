## Реализация

- `ProductionSets.json` и `ProductionSetAttacks.json` генерируются из baseline
  (рецепты с порогами, описания — строки «Эффект» карточек CD); каталоги
  `ProductionSetCatalog`, `ProductionSetAttackCatalog`. Content Design: строки
  «Параметры» пяти карточек заполнены значениями baseline.
- Combat: условные бонусы по уже замедленной цели в `CombatDamageRequest`
  (сохраняются через `WithAmount/WithDirection/Scaled`), применение в
  `EnemyRuntime.ResolveDamage`; `IEnemyControlReceiver.ApplyControl` для slow без урона.
- ActiveSkill: проброс бонусов активации в executor/persistent orbit/projectiles;
  `setScalesWithSizeAndRange` для set-атак; радиус живой орбиты наружу.
- Sets: семейства `SlowedTargetBonus`, `OrbitSlowAura`; `SetEffectHost` агрегирует
  бонусы (skill + player-wide), тикает ауру через `TickAttack(key)`, передаёт
  world-effect профили set-executor-у (telegraph SET-017).
