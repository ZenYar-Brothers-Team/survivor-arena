## Реализация

- **Данные** (генерируются `scripts/generate_field001_content.py` из baseline):
  `Fields/ProductionFields.json` (FIELD-001 «Деревенская окраина», difficulty 1,
  BOSS-001/MIDBOSS-001, FIELD-001-TRAVELERS, шесть ordinary IDs, сцена `Gameplay`);
  `Waves/ProductionWaveTimeline.json` (24 фазы, ровно 900 s, cap до 200, bursts
  12/18/18/24/24/20, hooks mid 450 / final 810, spawn radius 12, seed baseline);
  `Presentation/ProductionFieldEnvironmentPresentation.json` (принятые 2026-09-22
  environment art/decor + 64 authored obstacles, 16 в области ±20);
  `Run/ProductionRunSetup.json` (CHAR-001, draft 3 варианта / set chance 0.5 /
  rerolls/banishes/Book currency, XP thresholds).
- **Препятствия.** `FieldObstacleDefinition`/`FieldObstacleKind` и
  `FieldEnvironmentPresentationDefinition.ExplicitObstacles`; при их наличии
  `FieldEnvironmentArtRuntime` создаёт player-only `BoxCollider2D` точного размера
  прямоугольника и спрайт пня/плетня, прототипный `Obstacle_Fixture` скрыт и его
  collider выключен на время забега (восстановление при Dispose). Fixture-поле —
  прежний seeded-генератор (поведение не меняется).
- **Composition.** `FixtureRuntimeContentCatalog.CreateProduction()` — только
  стартовые production definitions (10 skills, 10 passives, 5 sets + SET-017-ATTACK,
  CHAR-001, 6 enemies, BOSS-001/MIDBOSS-001 с inline атаками, 3 Путника, PICKUP-001/002,
  FIELD-001), без fixture fallback. `GameplayCompositionRoot` выбирает каталог по
  экономике профиля (`MetaCatalog.IsFixture`); реальный `Start()` — production
  `MetaCatalog` и `profile-v1.json`. `SetEffectHost` получает set-атаки и world effects
  каталога; персонажи фильтруются `ProfileAccessProvider`.
- Results/save/retry, pause/draft/terminal ordering — существующие frameworks
  IP-13/25/26 без изменения контрактов; награды и unlock receipts идут через
  production mapping DECISION-0050 (F1-03).
