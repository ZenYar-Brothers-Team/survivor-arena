# Препятствия полей генерируются каждый забег (DECISION-0068)

Дата: 2026-09-27. Основание: [DECISION-0068](../../decisions/0068-per-run-obstacle-layouts.md), параметры
[field-layouts-v1](../../balance/field-layouts-v1.json). Статус — только [STATUS](../STATUS.md).

## Что сделано

- **Модель.** `FieldObstaclePiece`, `FieldObstaclePattern` и `FieldObstacleLayoutDefinition`. Валидация отвечает за
  три вещи: паттерн влезает в ячейку при любом допустимом повороте, куски внутри паттерна не пересекаются, повороты
  только кратные 90°.
- **Генератор** `FieldObstacleLayoutGenerator`:
  - ячейки по всей арене, одинаковое число паттернов в каждой;
  - случайный паттерн по весу, случайные поворот и точка внутри ячейки с отступом;
  - свободный круг у старта, зазор между паттернами одной ячейки;
  - детерминизм по сиду.
- **Данные.** `obstacleLayout` в `FieldEnvironmentPresentationData`/`Definition`; поле использует либо авторские
  препятствия, либо раскладку. Генератор контента выпускает раскладки FIELD-001…003 из утверждённого
  `field-layouts-v1.json` вместо фиксированных списков.
- **Рантайм.**
  - `FieldEnvironmentArtRuntime` строит препятствия раскладки при инициализации забега; `Obstacles` — список этого
    забега.
  - `GameplayCompositionRoot.LayoutSeed`: свежий сид на каждый забег, `referenceSeed` при `UseReferenceSeeds`.
  - Размещение подбираемых предметов и Путников, как и раньше, опирается на коллайдеры текущего забега.
- **Документы.**
  - Game Design «Поля» — общее правило;
  - карточки FIELD-001…003 — строка о раскладке;
  - в пакетах baseline v1, field002-v1 и field003-v1 фиксированные списки помечены как исторические.
