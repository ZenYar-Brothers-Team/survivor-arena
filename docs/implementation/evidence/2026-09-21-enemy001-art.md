## Runtime integration

Optional typed motionProfileId is validated by ContentRegistry and retained by
WaveEnemyScaler. The composition root resolves and role-checks the body, resolves
the profile and hands both to the spawner/factory.

EnemyRuntime creates one reusable VisualRoot/BodyRoot rig and uses the existing
SpritePresentationRuntime single pose writer. VisualRoot compensates collision
scale; physics stays on the gameplay root. The new fixture motion profile gives
restrained idle/movement, flip, spawn and hit reactions. The root placeholder
renderer is disabled while the body is active; the body uses neutral white tint.

Reinitialize, death, disable and pool return clear the writer; mixed reuse
restores the correct placeholder/body and prevents stale tint/flip/sprite.
Death does not wait for visual animation. No detached death effect or shadow
was added by this packet.
