# Content Design

## Статус и назначение

Content Design — канонический каталог конкретного игрового наполнения. Здесь фиксируются утверждённые сущности, их поведение в рамках правил Game Design и контентные/балансные параметры. Game Design остаётся source of truth по системным правилам; Content Design не должен молча вводить новую механику, которой нет в GDD.

## Что хранится здесь

• активные умения и их уровни;  
• пассивные предметы и их уровни;  
• сеты, рецепты, пороги компонентов и эффекты;  
• обычные враги, элиты, разновидности монстров и их параметры;  
• боссы и их конкретные способности/паттерны;  
• персонажи, их базовые параметры, стартовые умения и веса драфта;  
• поля, препятствия, конкретные наборы врагов/боссов и контентные особенности;  
• при необходимости — wave schedules и другие конкретные content definitions;  
• числовые параметры сущностей: размеры, HP, damage, speed, cooldown, radius и другие балансные значения.

## Что сюда не входит

Системные правила, общие для класса сущностей, остаются в Game Design. Например, правило «активные умения срабатывают автоматически» принадлежит GDD, а конкретное умение, его pattern и шесть уровней — Content Design. Порядок реализации и технические границы модулей принадлежат Implementation Plan. Архитектура, классы и файлы принадлежат к уровню Code/repository.

## Правило Design Gap

Если при описании конкретной сущности оказывается, что ей нужна новая системная механика, которой нет в Game Design, такую механику нельзя просто дописать внутрь сущности и считать реализуемой. Сначала фиксируется Design Gap и обновляется Game Design; после этого конкретная сущность может ссылаться на новое системное правило.

## Статусы и каноничность

Для записей используются как минимум статусы Draft и Approved. Draft допускает ещё не завершённые числа или детали и не является обязательным требованием для coding AI. Approved — каноническое описание конкретной сущности для реализации. AI-предложения не становятся Approved без явного принятия пользователем. Устаревшие записи при необходимости помечаются Deprecated, а не исчезают без следа.

## Идентификаторы

У каждой конкретной сущности должен быть стабильный ID, который можно использовать в Game Design, Implementation Plan, тестах, таблицах баланса и коде: например SKILL-001, PASSIVE-001, SET-001, ENEMY-001, BOSS-001, MIDBOSS-001, CHAR-001, FIELD-001. Название можно менять без потери трассируемости, ID — нет без отдельной миграции.

### Active Skills

Рекомендуемая карточка: ID и название; статус; роль/краткое описание; targeting и pattern; базовое поведение; параметры; уровни 1–6 с изменениями; качественные изменения механики; взаимодействия; участие в сетах; заметки по визуальному/аудио feedback при необходимости.

### Passive Items

Рекомендуемая карточка: ID и название; статус; изменяемая характеристика/эффект; уровни 1–6; формула или значения по уровням; stacking/ограничения; взаимодействия; участие в сетах.

### Sets

Рекомендуемая карточка: ID и название; статус; список active/passive компонентов; минимальные уровни компонентов; вероятность появления в draft после выполнения рецепта; дополнительная способность; параметры эффекта; связанные сущности.

### Enemies

Рекомендуемая карточка: ID и название; статус; игровая роль; размер/коллизия; HP; скорость; контактный урон и интервал его повторения; поведение движения; ranged attack/projectile при наличии; особые свойства; XP reward; допустимые wave/field contexts. Конкретные числа являются балансными параметрами и могут меняться без изменения системного GDD, пока не меняется сама механика.

### Bosses

Рекомендуемая карточка: ID и название; статус; поле/контекст появления; HP и размеры; фазы/поведение; контактный урон; projectile/attack patterns; особые способности; награды/XP при наличии. Финальное условие победы по таймеру задаётся GDD и не переопределяется карточкой босса.

### Characters

Рекомендуемая карточка: ID и название; статус; базовые характеристики; стартовое активное умение; базовый disappearing-XP recovery; веса или overrides для draft pool; условия разблокировки, если уже определены.

### Fields

Рекомендуемая карточка: ID и название; статус; окружение; geometry/obstacles; enemy pools; wave schedule reference; boss/final boss references; optional mid-boss; условия разблокировки, если определены.

## Числа и отдельная таблица баланса

На раннем этапе числовые параметры можно хранить прямо в Content Design. Когда сущностей и чисел станет много, массово редактируемые значения лучше вынести в отдельный Google Sheet с теми же стабильными ID. В таком случае Content Design остаётся source of truth по поведению и смыслу сущностей, а таблица становится source of truth по вынесенным числовым balance-data. Ссылка между ними строится по ID, а не по названию.

## Связь с Implementation Plan и Code

Implementation Plan не должен дублировать полный Content Design. IP-модуль описывает, что и в каких границах реализуется; если он реализует конкретный Approved-контент, он ссылается на соответствующие ID. При framework-разработке до готовности реального контента разрешены явно помеченные fixture/debug definitions, которые не считаются каноническими сущностями.

При реализации coding AI получает не только текст IP-модуля, а минимальный implementation packet по правилам [`implementation/WORKFLOW.md`](implementation/WORKFLOW.md): сам IP-модуль, релевантные секции Game Design, релевантные Approved-сущности Content Design, текущее состояние репозитория и локальные coding-инструкции. Все документы целиком читать не требуется, если они не влияют на текущий scope.

## Порядок ответственности при реализации

Game Design определяет правила систем. Content Design определяет конкретные сущности и параметры. Implementation Plan определяет текущий scope, порядок, зависимости и acceptance criteria. Repository/code показывает фактически реализованное состояние. Если появляется противоречие, coding AI не выбирает молча: системный конфликт возвращается в Game Design, контентный — в Content Design, конфликт scope/порядка — в Implementation Plan.

### Active Skills

Все пятнадцать записей ниже созданы AI по запросу пользователя и пока имеют статус Draft. Числа — стартовые балансные гипотезы, а не утверждённые значения. Все умения срабатывают автоматически и имеют уровни 1–6. Участие в сетах пока TBD. Я намеренно не добавляю сюда crit, заморозку, burn, stun и другие глобальные status-системы, которых нет в текущем Game Design.

#### SKILL-001 — Искровой болт

Роль: базовый точечный урон по ближайшим целям.  
Targeting / pattern: автоматически выбирает ближайшего врага и выпускает быстрый снаряд.  
База: 20 damage, cooldown 1.2 с, 1 projectile.  
Уровни 1–6: L1 базовая версия; L2 \+35% damage; L3 одновременно выпускает 2 снаряда по разным ближайшим целям; L4 каждый снаряд пробивает 1 дополнительного врага; L5 cooldown −25%; L6 выпускает 3 снаряда и \+25% damage.  
Взаимодействия: общий damage/cooldown модифицируются пассивными предметами. Сеты: SET-001.

#### SKILL-002 — Веер игл

Роль: ближне-средний массовый урон перед персонажем.  
Targeting / pattern: автоматически ориентируется на ближайшего врага и выпускает веер снарядов.  
База: 5 игл, 9 damage каждая, угол веера 60°, cooldown 1.8 с.  
Уровни 1–6: L1 5 игл; L2 7 игл; L3 \+30% damage; L4 угол расширяется до 90° и 9 игл; L5 cooldown −25%; L6 11 игл, каждая пробивает 1 врага.  
Взаимодействия: одна цель может получить урон от нескольких игл, если пересекает несколько траекторий. Сеты: SET-003.

#### SKILL-003 — Орбитальные клинки

Роль: постоянная защита ближней зоны и контактный урон вокруг игрока.  
Targeting / pattern: клинки непрерывно вращаются вокруг персонажа и наносят урон врагам при пересечении.  
База: 2 клинка, 14 damage за попадание, радиус орбиты 1.8.  
Уровни 1–6: L1 2 клинка; L2 \+30% damage; L3 3 клинка; L4 радиус орбиты \+25%; L5 скорость вращения \+35%; L6 4 клинка и \+20% damage.  
Взаимодействия: один клинок не может наносить повторный урон одной цели чаще заданного hit cooldown; значение является balance-data. Сеты: SET-002.

#### SKILL-004 — Импульсная волна

Роль: периодическая зачистка пространства вокруг персонажа.  
Targeting / pattern: через фиксированный cooldown создаёт круговую волну, расходящуюся от игрока.  
База: 28 damage, радиус 2.5, cooldown 4.0 с.  
Уровни 1–6: L1 базовая волна; L2 \+25% radius; L3 \+35% damage; L4 после основной волны через 0.35 с возникает вторая меньшая волна с 50% damage; L5 cooldown −25%; L6 обе волны имеют полный радиус, вторая наносит 70% damage.  
Взаимодействия: волна поражает каждую цель максимум один раз за проход. Сеты: SET-006.

#### SKILL-005 — Ветряное копьё

Роль: высокий линейный урон по плотной группе.  
Targeting / pattern: автоматически стреляет в направлении ближайшего врага длинным пробивающим снарядом.  
База: 34 damage, пробивает 3 врагов, cooldown 2.4 с.  
Уровни 1–6: L1 базовая версия; L2 \+30% damage; L3 пробивание увеличивается до 5 целей; L4 projectile width \+35%; L5 cooldown −20%; L6 пробивание становится неограниченным до конца lifetime и \+25% damage.  
Взаимодействия: projectile lifetime/range — balance-data; снаряд не меняет направление после запуска. Сеты: SET-004.

#### SKILL-006 — Бумеранг

Роль: двукратное поражение линии и контроль пространства движением снаряда.  
Targeting / pattern: запускается в сторону ближайшего врага, летит вперёд, затем возвращается к текущей позиции персонажа.  
База: 22 damage за проход, cooldown 2.8 с.  
Уровни 1–6: L1 один бумеранг; L2 \+30% damage; L3 увеличенная дальность \+30%; L4 одновременно 2 бумеранга под небольшим углом; L5 cooldown −20%; L6 возвращающийся проход наносит \+75% damage.  
Взаимодействия: одна цель может быть поражена на пути туда и обратно, но не несколько раз в рамках одного прохода. Сеты: SET-005.

#### SKILL-007 — Цепная молния

Роль: быстрый урон по группе рассредоточенных врагов.  
Targeting / pattern: ударяет ближайшего врага и мгновенно перескакивает на следующие ближайшие ещё не поражённые цели.  
База: 24 damage, до 3 целей, cooldown 2.2 с.  
Уровни 1–6: L1 3 цели; L2 4 цели; L3 \+30% damage; L4 6 целей; L5 cooldown −25%; L6 8 целей, каждый следующий переход теряет только 5% damage вместо базовых 15%.  
Взаимодействия: одна активация не поражает одну цель дважды; максимальная дистанция прыжка — balance-data. Сеты: SET-001.

#### SKILL-008 — Рикошетный диск

Роль: эффективный урон в средней плотности врагов.  
Targeting / pattern: летит к ближайшей цели и после попадания автоматически перенаправляется к другой ближайшей цели.  
База: 18 damage, 3 попадания, cooldown 2.0 с.  
Уровни 1–6: L1 3 попадания; L2 4 попадания; L3 \+35% damage; L4 6 попаданий; L5 cooldown −20%; L6 8 попаданий и \+20% projectile speed.  
Взаимодействия: в рамках одной активации диск старается не выбирать одну и ту же цель повторно, пока есть другие валидные цели. Сеты: SET-005.

#### SKILL-009 — Магматическая мина

Роль: урон по преследующим врагам и использование маршрута игрока.  
Targeting / pattern: автоматически оставляет мину в текущей позиции персонажа; мина взрывается при приближении врага или по истечении lifetime.  
База: 40 damage, blast radius 1.5, cooldown 3.0 с, одновременно максимум 4 мины.  
Уровни 1–6: L1 базовая мина; L2 \+25% radius; L3 \+35% damage; L4 максимум 6 активных мин; L5 cooldown −25%; L6 после взрыва создаёт второй меньший взрыв через 0.4 с с 60% исходного damage.  
Взаимодействия: постановка не требует ручного ввода; старейшая мина исчезает при превышении лимита. Сеты: SET-007.

#### SKILL-010 — Небесный удар

Роль: мощный периодический AoE по скоплению врагов.  
Targeting / pattern: выбирает позицию одного из ближайших врагов; после короткой задержки в точку ударяет область урона.  
База: 55 damage, radius 1.6, задержка 0.6 с, cooldown 4.5 с.  
Уровни 1–6: L1 один удар; L2 \+30% radius; L3 \+35% damage; L4 2 последовательных удара по двум разным целям; L5 cooldown −25%; L6 3 удара, третий имеет \+50% radius.  
Взаимодействия: выбранная точка фиксируется в момент telegraph, поэтому враг может выйти из зоны до удара. Сеты: SET-006.

#### SKILL-011 — Спираль осколков

Роль: равномерное покрытие пространства вокруг персонажа.  
Targeting / pattern: выпускает серию снарядов по кругу; направление каждой следующей активации немного поворачивается, формируя спиральный рисунок.  
База: 8 снарядов по кругу, 12 damage, cooldown 2.4 с.  
Уровни 1–6: L1 8 снарядов; L2 10 снарядов; L3 \+30% damage; L4 12 снарядов и \+20% projectile speed; L5 cooldown −25%; L6 две последовательные круговые очереди с поворотом второй на половину углового шага.  
Взаимодействия: manual targeting отсутствует; рисунок определяется только текущей конфигурацией умения. Сеты: SET-002.

#### SKILL-012 — Пульсирующий луч

Роль: фокусированный урон по ближайшему направлению с хорошим пробиванием.  
Targeting / pattern: короткий луч автоматически направляется на ближайшего врага и существует ограниченное время.  
База: 10 damage каждые 0.2 с в течение 0.8 с, cooldown 3.0 с.  
Уровни 1–6: L1 базовый луч; L2 duration 1.1 с; L3 \+30% damage per tick; L4 ширина луча \+40%; L5 cooldown −25%; L6 duration 1.5 с и луч медленно доворачивается вслед за текущей целью.  
Взаимодействия: луч поражает всех врагов на своей линии; частота tick является частью skill definition. Сеты: SET-003.

#### SKILL-013 — Ледяные осколки

Роль: направленный залп с высоким burst-уроном без отдельного status effect.  
Targeting / pattern: автоматически выпускает несколько крупных осколков в секторе в сторону ближайшего врага.  
База: 3 осколка, 18 damage, cooldown 2.5 с.  
Уровни 1–6: L1 3 осколка; L2 4 осколка; L3 \+35% damage; L4 каждый осколок пробивает 1 врага; L5 cooldown −20%; L6 6 осколков и центральный осколок наносит двойной damage.  
Взаимодействия: название не подразумевает замедление/заморозку — таких систем текущий GDD не фиксирует. Сеты: SET-004.

#### SKILL-014 — Взрывные сферы

Роль: медленные крупные projectiles с AoE при столкновении.  
Targeting / pattern: запускает сферу в сторону ближайшего врага; при первом столкновении с врагом или по окончании lifetime сфера взрывается.  
База: 18 impact damage \+ 32 explosion damage, radius 1.3, cooldown 3.2 с.  
Уровни 1–6: L1 одна сфера; L2 \+30% explosion radius; L3 \+35% explosion damage; L4 одновременно 2 сферы; L5 cooldown −20%; L6 сферы проходят сквозь первую цель и взрываются при втором попадании либо по lifetime.  
Взаимодействия: impact и explosion — части одного active skill; общий damage modifier применяется к обеим составляющим. Сеты: SET-007.

#### SKILL-015 — Крест клинков

Роль: периодический burst по четырём направлениям с сильным поздним покрытием.  
Targeting / pattern: центрируется на персонаже и выпускает четыре длинных режущих волны по взаимно перпендикулярным направлениям; ориентация креста автоматически направляет одну ось на ближайшего врага.  
База: 30 damage каждой волной, cooldown 3.5 с.  
Уровни 1–6: L1 4 волны; L2 \+30% range; L3 \+35% damage; L4 добавляются диагональные направления, всего 8 волн; L5 cooldown −25%; L6 после первой активации через 0.35 с повторяется второй крест, повернутый на 22.5°.  
Взаимодействия: каждая волна поражает каждого врага максимум один раз; пересечение нескольких волн может нанести несколько отдельных попаданий. Сеты: SET-002.

### Passive Items

Все десять записей ниже созданы AI по запросу пользователя и пока имеют статус Draft. Числа — стартовые балансные гипотезы, а не утверждённые значения. Общие правила: предмет занимает один пассивный слот, имеет уровни 1–6 и не может быть заменён в течение забега; указанное значение — итоговый эффект на соответствующем уровне, а не сумма предыдущих уровней. Участие в сетах для всех предметов пока TBD.

### Fields

Все десять полей ниже созданы AI по запросу пользователя и пока имеют статус Draft. Они образуют последовательную линию роста сложности от FIELD-001 к FIELD-010. Рост сложности предполагается не только через более высокие числовые параметры врагов, но и через более плотные волны, более опасные сочетания типов врагов, большую долю ranged/элитных угроз и более требовательную геометрию. Точные enemy IDs, boss IDs и wave schedules будут привязаны после заполнения соответствующих разделов Content Design. Препятствия пока считаются обычной геометрией/коллизией и не вводят дополнительных terrain-effect систем. Граница поля задаётся отдельно от препятствий: она блокирует только персонажа игрока и остаётся проходимой для врагов, снарядов, эффектов умений, опыта и остальных игровых сущностей.
